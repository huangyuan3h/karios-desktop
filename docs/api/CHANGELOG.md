## 0.1.0 — 2026-08-01

**Initial public release** — 8 endpoints under `/v1/*`.

### Added

- `GET /v1/version` — API version + min_compatible + released_at
- `GET /v1/schema` — OpenAPI 3.1 JSON (auto-generated by FastAPI)
- `GET /v1/errors` — Error-code dictionary with `recovery_hint`
- `GET /v1/changelog?since=X` — Interface changelog (Phase A: returns empty array)
- `GET /v1/market/snapshot?symbols=...` — N-symbol TrendOK / Score / current price
- `GET /v1/watchlist/items` — Current watchlist registry (read-only)
- `GET /v1/decision-journal/query?since=X&limit=N` — Recent decision-journal changes
- `GET /v1/explain/{symbol}` — Single-symbol comprehensive context pack

### Configuration

- `KARIOS_API_VERSION=0.1.0` (env var, default)
- `KARIOS_API_KEYS=...` (env var, comma-separated; empty = auth disabled)

### Seed error codes

- `SLEEVE_CAP_BLOCK` (HTTP 422) — satellite sleeve cap reached
- `SECTOR_CONC_BLOCK` (HTTP 422) — sector concentration cap reached
- `ENTRY_BELOW_STOP` (HTTP 422) — buy zone at or below hard stop

### Tests

- `tests/test_discovery_endpoints.py` — 17 tests
- `tests/test_v1_business_endpoints.py` — 18 tests
- `tests/test_v1_explain_endpoint.py` — 14 tests
- **Total: 49 v1/* tests, all green; 0 regression in existing 16 routers**
