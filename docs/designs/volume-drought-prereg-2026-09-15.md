# 预注册：地量后爆发「H-VOL-1」（2026-09-15 · B19 · 只读诊断）

> **何时看**：跑/审"缩量、地量见底、无量下跌后爆发"这类直觉时。
> **何时不看**：想拿它做 Live 规则时——本档只读，先诊断后回放、先预注册后动引擎。
> **一句话机制**：长期下跌趋势中成交量枯竭（250 日新低量）= **卖压耗尽**；供需失衡修复 → 后续出现正超额（"爆发"）。与已判死家族的区别：**同态对照**（下跌趋势但非地量）+ **剔最深跌幅档**后仍要有增量（K3）——否则就是"超跌反弹/低波"换皮。

**自查（first-principles）**：撞 §一.4 波动率非因子律 与 `bounce-rescue`（深度超跌本身有生命体征但 REJECT）→ 本档主门就是"地量 ≠ 低波/超跌代理"的增量检验。**预判死因**：#2 共线（低波/弱势/流动性代理）· #3 方向证伪（缩量阴跌=无量下跌，继续跌）· #4 单窗（只在一两轮熊末有效）。

## 判定线（跑前冻结）

- **K1（指数）**：000300 地量事件 fwd60 超额（vs 同态对照）> 0 于 **≥3/4 eras** 且全期 > 0。
- **K2（个股）**：全市场地量事件 fwd60 超额 > 0 于 **≥3/4 eras**。
- **K3（增量）**：个股 fwd60 超额在**剔除 `ret250` 最差十分位**后仍 > 0（不是"越超跌越买"换皮）。
- 结论：K1&K2&K3 → 开"地量择时/选股并入研究"下一档；任一不过 → **REJECT 记录**（不扫定义/N）。
- 覆盖门：事件数与每 era 分布随表印出；era 事件 <20 条置灰不参与 K。

## 结果（跑后补）

**H-VOL-1 → REJECT（K1/K2/K3 全 FAIL，且方向偏负）**：冻结定义（下跌态中 250 日新低量）下——
- **指数**：事件极稀（000300 全期 12 次；000001 13 次；000905 9 次），fwd60 超额全期 **−3.40 / −2.96 / +1.81**（000300−000001 为负，000905 弱正但不显著）。
- **个股**（2010–2026，10,986 个去重事件）：fwd60 超额按时代 **−6.60 / +0.13 / −2.38 / −1.66**，全期 **−1.65**；**只有 1/4 时代为正**。
- **K3（剔最深跌幅十分位，ret250 ≤ −0.42）**：四时代 **−6.78 / −0.10 / −2.81 / −2.11**，全期 **−2.05** → 不是"超跌换皮"能解释的，而是**独立地更差**。
- 读数：**"地量之后会爆发"在本口径下不成立**；缩量阴跌更接近"无量下跌→继续跌"。指数级 250 日新低量本身近乎不出现（覆盖门不过，K1 欠功效）。
