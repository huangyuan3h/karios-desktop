# 预注册：停车场再入场冷却（H-PARK-C · 2026-09-13）

> **单假设 · 门槛跑前冻结。** 给港湾的**停车场层**加一个**同一标的再入场冷却**：被因果 trail8 踢出某只 ETF 后，该标的（按 key，不是按代码——别名同经济暴露）在接下来 k 个交易日内**不可再买入**，资金改停当天的下一个合格候选；没有合格候选 → 留现金/REPO。**S-3 股票核心与 trail8 本身都不动。**
> **关键词**：停车场 再入场冷却 鞭打 trail8 港湾 预注册

## 0. 一句话机制（§四 S1）

停车场在噪声期被 trail8 踢出后，次日就把**同一只**刚跌 8% 的 ETF 买回来，形成 −8% 往返循环（B11 valid 2026-06/07 纳指两轮）；冷却期把"刚被止损的资产"从候选里拿掉，逼资金去次优合格资产或现金，从而**压低空仓期 ETF 的鞭打回撤**。代价：真实的 V 型反弹会被少赚。

## 1. 为什么开（背景）

- B11（`etf-parking-baseline-2026-09-13.md`）§3.3 已点名：「**trail8 出场后次日无冷却、立即再进** → 噪声期反复 −8% 往返」是 valid MDD −9.4→−23.1、Sharpe 2.44→1.91 的机制；并明确「再入场冷却/上限是候选改进，需另起预注册」。
- 本稿只测**冷却**一个机制（不做上限/冷却时长自适应等第二变量）。
- 这是首个**明确以风险指标为目标**的港湾层实验（不是再追收益）。

## 2. 口径（冻结）

- 基线/口径与 B11 P1 **逐字相同**：S-3 CN 引擎（`S3_CONFIG`，window-local）、`idle = 1 − min(1, Σ position_pct)`（t-1 快照）、14:30 卫星口径（回测=收盘代理）、因果 trail8（t-1 收盘触发）、0.05%/边、无 floor、无 STOCK gate、无候选→REPO。
- 数据：`data/etf/etf_daily.csv`（`close_adj`，41 只，已更新至 2026-09-11；窗口终点不变）。
- 窗口：OOS2 / train / valid / long（沿用 `run_walk_forward.WINDOWS`）。
- 唯一新参数：`cooldown_days = k`（trail 出场日索引 + k 之前，该 **key** 不可买）。
  - 冷却只由 **trail 出场**触发；rotation 到别的标的、无候选自然回现金不算。
  - 冷却按 **key**（GOLD/OIL/NASDAQ/BOND10）生效：纳指别名（513110/513100）视为同一暴露。
  - 冷却期内若次优合格候选存在 → 停次优；否则 → REPO（现金）。
  - `k=0` = 现行 P1（现任者），实现必须零行为变化。

## 3. 变体（预声明 · 平台扫描 S4）

| # | 规则 |
|---|------|
| **C0** | 现任者：B11 P1（无冷却），`k=0` |
| C1/C2/C3/C5 | 同 P1 + trail 出场后同标的冷却 `k ∈ {1,2,3,5}` 个交易日 |

- 结构参数开**声明式平台扫描**（S4），不做诊断、不事后加档；网格无全胜者 → 现任者赢。
- **明确不测（另一机制，不在本稿）**：全局冷却（出场后整体空仓 k 天）、月度再入场上限、冷却按别名/按 ts 区分、trail 阈值/MA/lookback/候选池任何改动。

## 4. 判定（冻结，跑前写死）

对每个 k（vs C0 同窗 P1）：

- **K1 不伤收益**：OOS2/train/valid 每窗 Δtotal ≥ **−0.5pt**。
- **K2 合计为正**：三窗 Δtotal 合计 > **0**。
- **K3 长窗不亏**：long Δtotal ≥ **0**。
- **K4 风险目标（本实验存在的理由）**：valid MDD 改善 ≥ **3.0pt**（如 −23.1 → ≤ −20.1）**或** valid Sharpe ≥ +**0.10**；且 long MDD 不比现任者差超过 **1.0pt**。
- **K5 平台**：入选 k 必须在网格里有**非零邻居**（k±1 ∈ 网格）且该邻居也过 K1/K2；否则按尖峰拒收。
- 裁决：全部 K1–K5 过 → 采纳该 k（多个过取**最小 k**）；否则 **C0 维持，方向关闭**（结论与数字照留档）。
- 通过 ≠ 进 Live：按 `todo.md` 纪律（paper 3/20），仅列**候选**，落地另拍板。

## 5. 死因预判（跑前写死）

- 主：**§三 #1 截断右尾**——冷却挡住的是急跌后 V 反抽，valid 改善而 OOS2/train/long 变差。
- 次：**#4 regime**——噪声市有效、趋势市是纯税；K5 平台若只在 valid 单点存活 → 按过拟合拒收。
