# 预注册：多资产稳健核心 · 结构实验（H-STABLE · 2026-09-12）

> **单假设 · 结构选择（非网格）· 门槛跑前冻结。** **独立于双子星**先找可用结构（用户 2026-09-12 要求）；结论无论是否结合都留档。
> **关键词**：稳健核心 多资产 波动率倒数 风险预算 趋势过滤 结构选择 预注册

## 0. 一句话机制（§四 S1）
在**低相关**资产（A 股 / 黄金 / 纳指 / 国债）间做**风险预算**（波动率倒数加权），组合 Sharpe 高于单一资产、MDD 显著更低；叠**组合波动率目标**进一步降波动，叠**趋势过滤**避开长期通缩资产——得到可独立持有的"稳健核心"。

## 1. 与现有工作的关系（防重复）
- [DH-2](../backtests/a1-voltarget-beta-2026-09-11.md)=**单指数**（中证500）+ 波动率目标；本稿是**多资产配置**，不同。
- `MULTI_TS`（GOLD/OIL/NASDAQ/BOND10）= **择强**（mom60+MA200 argmax）；本稿是**风险预算**，不同。
- [DH-1×S-3](../backtests/dh1-s3-hybrid-2026-09-11.md)：**不**给 S-3 加刹车；本稿为独立腿。

## 2. 口径（冻结）
- 宇宙（5，2021-01 起全有）：`510300.SH` 沪深300 · `510500.SH` 中证500 · `518880.SH` 黄金 · `513100.SH` 纳指 · `511260.SH` 十年国债（`data/etf/etf_daily.csv`，`close_adj`）。
- 日历：510300 交易日；**月度再平衡**（每月首个交易日），权重用 **trailing 60d** 日收益（**shift 无前视**）。
- 成本：每次调仓 `0.0005 × Σ|Δw|`（单边 5bp）。
- 窗口：OOS2/train/valid/**long 2021-01-04~2026-08-07**。

## 3. 结构（**预声明 6 个，A/B 对打，不开网格**）
| # | 结构 | 定义 |
|---|------|------|
| B0 | 300 买持 | 100% 沪深300 |
| B1 | 60/40 | 60% 沪深300 + 40% 国债，月度 |
| B2 | 等权 | 5 资产 EW，月度 |
| B3 | 波动率倒数 | w ∝ 1/σ60（5 资产），月度；无杠杆 |
| B4 | B3 + 组合波动率目标 | 目标年化波动 **8%**，`scale=min(1, 8%/σ_port)` |
| B5 | B3 + 趋势过滤 | 资产 close<MA200 则该资产权重并入国债，再按 1/σ60 分配 |

- B4/B5 的 σ 均用 trailing 60d、shift 无前视。

## 4. 指标 / 判定（冻结）
- 指标：CAGR、年化波动、Sharpe、MDD、Calmar（分窗口）。
- **"可用结构"门槛（long 窗）**：Sharpe **≥ 1.0** 且 CAGR **≥ +5%** 且 **回撤 ≤ 20%**（即 MDD ≥ −20%）且 **Sharpe 与 MDD 同时优于 B0**。
- 命中 → 记"可用独立结构"（可再议是否与双子星结合）；不中 → 记"不可用/仅参考"。
- **不扫**：资产清单、再平衡频率、目标波动、MA 窗。

## 5. 死因预判（跑前写死）

- 次：样本仅 2021+（5.6 年，含一轮熊+一轮牛）；成本/再平衡摩擦；纳指 ETF 溢价/跟踪。

## 结果（跑后补）
**可用结构 = {B3, B4, B5}**。最优 **B3 波动率倒数（风险预算）**：long **Sharpe 1.47 / CAGR +7.3% / MDD −7.3%**（300 买持 0.09/−42.2、60/40 0.27/−20.2、等权 0.91/−13.0）；三窗 Sharpe 2.64/4.15/0.82、MDD ≤3.3%。B4 的 8% 波动目标**从未触发**（实现波仅 4.9%）；B5 趋势过滤本区间不加分。见 [`stable-core-2026-09-12.md`](../backtests/stable/stable-core-2026-09-12.md)。边界：样本仅 2021+、regime 依赖（"股弱金债强"红利）、经典 ARP 在本宇宙验证。
