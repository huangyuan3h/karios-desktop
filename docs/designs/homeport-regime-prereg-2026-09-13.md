# 预注册：母港市况开关（H-MIX-DYN · 2026-09-13）

> **单假设 · 二值开关（S5 诊断通道）· 门槛跑前冻结。** 在两腿之间加一个**市况开关**：`沪深300 close > MA200`（t-1 收盘判定）→ **强市 100% 港湾**；否则 → **防守 50/50（港湾 × B3）**。即用户提案「进攻 100/0、防守 50/50」的唯一信号版本。
> **关键词**：母港 市况开关 沪深300 MA200 不对称配比 预注册

## 0. 一句话机制（§四 S1）

港湾的右尾集中在强市（valid 强市 CAGR 156%），而弱市里港湾空仓期回撤由 B3 更抗；用最稳定的**外生截面信号**（指数趋势）决定是否让 B3 上桌——强市不让分散腿稀释收益，弱市用它压回撤。

## 1. 为什么开（背景）
- 先例：`twin-stable-adaptive` A2（同构：300×MA200 切主动/稳健核心）在 OPT-177 修正后 **PASS**（long CAGR 8.79/SR 0.52/MDD −26.0 vs 静态 50/50 6.24/0.52/−17.9；valid 49.45 > 39.29）——但回撤更深、且是旧双子星语境。
- 反例（同族死法）：A1（策略 NAV 择时）REJECT；`dh1-s3-hybrid` REJECT（四窗不一致）；`index-trend-bigmoney` REJECT（指数趋势态无远期 edge）；TIP-016 A/W1/W2 REJECT（"水位计死于解除动力学"）。
- 本稿只测**一个信号、一对方位（100/0 ↔ 50/50）**，不做连续风险预算（T4 家族，另开）。

## 2. 口径（冻结）
- 两腿：港湾 = B11 P1 单源口径（S-3+停车场，因果 trail8、0.05%/边）；B3 = 现行冻结（5 资产逆波动率月度、5bp/边）。
- **状态**：`510300 close(t-1) > MA200(t-1)`（用窗口前历史预热，MA 含 t-1 当日）；t-1 判定 → t 日生效。
- **目标权重**：强市 `w_harbor = 1.0`；弱市 `w_harbor = 0.5`（另一腿 B3）。月内权重随收益漂移，状态切换时按 `5bp × |Δw|` 计费。
- 窗口：OOS2 / train / valid / long；另测 2022-01-01~2023-12-31 子窗。
- 对照组：静态 M50（B15）与 100% 港湾。

## 3. 判定（冻结，跑前写死）
vs 静态 M50（H-MIX）：
- **K1** long CAGR ≥ M50（+18.04）。
- **K2** long Sharpe ≥ M50（1.23）。
- **K3** long MDD ≥ M50 − 2.0pt（≥ −14.2）。
- **K4** OOS2/train/valid 每窗 CAGR ≥ M50 − 5.0pt。
- **K5** valid 强市 CAGR ≥ 0.8 × 港湾 valid（0.8×156.59 ≈ 125.3）。
- **K6** 2022–23 压测 MDD ≥ M50 压测 − 2.0pt。

- 报告必须附：两状态天数占比、状态切换次数、切换成本估算。

## 4. 死因预判（跑前写死）

- 次：弱市信号滞后（MA200 迟滞），防守来得晚、解除来得慢。
