## 1. 机制（一句话）

S-3 信号层（score/regime/flow/mainline/大小盘/国家队…）**一字不改**；只把成交语义从
「T+1 开盘」改成「**T+1 的 14:30 print**」，出场从「决策日收盘」改成「**决策日 14:30 print
（同 print 决策+成交）**」——与卫星/停车一致。

### 1.1 入场（`entry_mode="next_1430"`）

- 信号日 T 收盘产出名单（不变）→ 成交 = **T 下一交易日的 14:30 raw print**，
  按该日 `daily` qfq 基期换算（`qfq = raw × adj_day / adj_latest`，或同日的
  `qfq_close / raw_1500` 比值；两者在非除权日等价）。
- 零前视：14:30 print 只在**成交日**被读取；信号日只看 T 收盘。
- **无 14:30 print → 当日不成交**（与 `next_open` 缺下一根 bar 同构，不猜价、不回退开盘）。
- 14:30 print 触涨停（买）→ 不成交；`_at_limit(base_day=信号日收盘)` 判定，锚点同 `next_open`。
- A股 T+1：成交日（`holding==1`）禁卖，最早出场 `holding>=2`（不变）。

### 1.2 出场（同 print）

- `stop` / `trail`：触发判定用**当日 14:30 print**；trail 峰值 = **此前收盘**峰值
  （不含当日，避免用当日收盘回看）；成交价 = 当日 14:30 print。
- `score_floor` / `max_hold` / `max_hold_env_shorten` / `time_stop` / `flow_exit` / `delisted`：
  触发条件不变（日期/逻辑），**成交价改为当日 14:30 print**（原为当日收盘）。
- 跌停卖不出：14:30 print 触跌停 → 不成交（顺延）。
- 窗口末日未平仓：仍按最后可用收盘 mark（记 `end_of_window`），不进 NAV 的成交腿。

### 1.3 明确不改

- NAV 记号仍按**收盘**（盯市约定不变，停车/卫星也是 close-to-close）。
- 组合层：现金约束、熔断、pyramid、swap 逻辑不动（swap 若启用，其候选入场沿用同一 fill 解析）。
- **HK 腿**：`bar_5min` 无 HK 行 → HK 腿保留 `next_open`（**文档化例外**；港湾 Live 是
  CN 股票 + ETF 停车，不受影响）。

## 2. 裁决（沿用 B11/验证门控 v2 的 Live 血统口径）

记 `next_1430` vs 现冻结 `next_open` 的 Δ（均含成本；同一引擎、同一窗口、同一 universe）：

- **K1 收益主门**：三窗（OOS2/train/valid）每窗 **Δtot ≥ −1.0**（容忍带）。
- **K2 兑换**：三窗 Δ 均值 **> 0** 且 long **Δ > 0**。
- **K3 一致性**：long MDD ≥ base −1pt 且 valid MDD ≥ base −2pt（风险不劣化）。
- **L 门**（挂一条 = VOID）：L1 universe/信号冻结 ✓ · L2 成交因果（14:30 print 只在成交日读）·
  L3 基期单一（raw→qfq 单源）· L4 日历双市场 ✓ · L5 独立报告文件（不覆盖冻结 JSON）· L6 可复现。
- 受影响档：**港湾 / 母港 / 星港 / 双子星**（含 S-3 CN 腿）；**星舰不受影响**（卫星 + H2 停车，
  已 14:30），列为对照不重跑。
- PASS → 成为候选新基线（进 Live-track：paper + 用户授权后切换）；任一挂 → 维持 `next_open`，
  Live 仍按 14:30 人工执行并**记录跟踪误差**（口径差 ±0.7%，见
  [`core-entry-execution-2026-09-10`](../backtests/core/core-entry-execution-2026-09-10.md) §2.A）。

### 死因预判（写在前头）

1. 开盘 → 14:30 的日内漂移为正（该档实测 open→close **+1.17/+0.60/+1.88%**）→ 入场价系统性略差，
   三窗可能贴 −1.0 线。
2. 出场改成同 print 会移动 trail/stop 的**触发日**（14:30 价 vs 收盘价），弱窗（valid）易翻。
3. 若 K1 挂：结论 = 「14:30 只是执行纪律，不是回测口径」，Live 侧仍统一 14:30 操作，
   但引擎维持 `next_open` 作为代理（已有 ±0.7% 证据），漂移项（§7.1）就此结案。
