# 预注册：星舰资金配比价目表（H-SAT-SPLIT · 2026-09-15）

> **价目表 · 跑前冻结网格/口径。** 问：**限制给星舰的资金 c**，其余 `1−c` 走其他策略（港湾 / 母港 M50 / B3 / ETF 套筒 / REPO），四窗的**收益、回撤、Sharpe** 如何权衡？
> **关键词**：星舰 资金配比 静态月度再平衡 价目表 预注册

## 0. 一句话机制

`port = c × 星舰 + (1−c) × 其他腿`，**月度再平衡**回 c（house 惯例 = 母港 M50 口径：`_blend_monthly`，5bps/边，按成交 fraction 计）。星舰腿仍是 100% 名义 4×25% 槽冻结口径（给它的 c 里未满槽 = 现金，不额外泊出——本档只测"资金上限"）。

## 1. 为什么开（背景）

- H-SAT-IDLE（2026-09-15）刚证：闲置现金停放死路（港湾核心在卫星空仓日 ≈ −4%/yr；套筒虽有 long +152.6 但双窗稀释 + MDD×3.6）。
- H-SAT-W 是**港湾锚**的曝露曲线（REJECT）；H-B3-SAT 是**母港锚**的（PASS 1/3）。**星舰锚 + 显式资本上限**（c 网格）从未测过——这正是"少给卫星钱、其余走别的策略"的价格表。
- 已知锚点：星舰 100% long +463.6/MDD −8.4/SR 3.50；港湾 +201.5/−22.8/1.00；母港 M50 +116.3/−11.6/1.18；套筒 +89.1/−28.7/0.68；REPO +3.4/0.0。

## 2. 口径（冻结）

- **星舰腿** = habit 冻结（`amp_1430` + C1 3% + `same_1430` + `gate_1430` + 30bps RT，4×25%），`replay_sgap_from_context`，0 改动。
- **其他腿**（5 个，冻结）：**港湾**（`_harbor_nav`，P1 单源）· **母港 M50**（港湾×B3 月初再平衡 5bps/边）· **B3 风险预算**（`_rp_nav`，月度）· **ETF 停车场套筒**（`parking_replay` idle=1，5bps/边）· **REPO**（0.7%/yr）。
- **配比网格（7 点，预定）**：`c ∈ {0, 0.20, 1/3, 0.50, 2/3, 0.80, 1.00}`（c=星舰资金占比）。
- **混合** = `_blend_monthly(sat, other, c, dates, 5bps)`（月度再平衡；c=0/1 即纯腿）。
- **窗口** = OOS2 / train / valid / long；**holdout 只描述**。
- **不扫**：星舰/其他腿口径、c 的细网格、再平衡频率（月频冻结）、成本档（5bps 冻结）。

## 3. 判定（跑前冻死 · 价目表，非产品裁决）

- 本档**不设 K 门**（价目表性质；落地必须另起预注册 + 资本结构拍板）。
- **声明读数（跑前写死，只做这三种汇总）**：
  1. **收益前沿**：每个其他腿下，long total 最大的 c（及该点四窗 total/MDD/Sharpe）。
  2. **风险调整前沿**：每个其他腿下，long Sharpe 最大的 c。
  3. **换手价格**：相对 100% 星舰，每点 c 的 long total/MDD/Sharpe 变化（线性性检验）。
- 全部 35 格四窗数字入档（表），不做选择性汇报。

## 4. Robustness（预声明，只报告）

- long 年度分解（c=0.5 的两条主力组合：星舰×港湾、星舰×母港）。
- 两腿 long 日收益相关（全窗）。
- 月度再平衡的成本占比（c=0.5：5bps/边 × 12 次/年 × 换手 fraction）。

## 5. 死因预判（跑前写死）

- 主：**#2 共线/regime 预算冲突**——星舰的收益集中在 2024–25 与 2025，港湾/母港集中在别的时段；静态配比的 long 可能接近线性混合，**不会出现"免费午餐"点**（除了风险分散带来的 Sharpe 提升）。
- 次：**#5 尺度错配**——月度再平衡下滞后一个月捕捉 regime 切换，可能两头挨打（valid）。
