# 预注册：B3 单资产权重上限（H-B3-CAP · 2026-09-13）

> **单假设 · 声明式双点平台 · 门槛跑前冻结。** 在 B3 冻结口径（5 资产、60d 逆波动率、月度再平衡、5bp/边）上只加一个机制：**单资产权重上限**（超额按比例水填给未触顶资产）。目的：修复逆波动率的 **capsize**——长期均值 64% 在国债、当前 86%，组合已退化为"债+金 carry"（股性贡献仅 ~9%）。
> **关键词**：B3 逆波动率 capsize 单资产上限 水填 预注册

## 0. 一句话机制（§四 S1）

逆波动率把 1% 波动的国债推到 60-86% 权重，风险预算名存实亡；给单资产设上限后，多余风险预算被迫分配给黄金/纳指/股，恢复"多资产分散"本意。代价 = 组合波动/回撤上升（低波资产被削）。

## 1. 为什么开（背景）
- B13/H-MIX 诊断：B3 long（2021-08~2026-08）平均权重国债 **64.0%**、最高 82.6%，当前 **86.3%**；收益贡献债券 40.8% + 黄金 35.9%，股性（300+500）仅 8.7%。
- 原 stable-core 预注册明确"不扫资产清单/频率/目标波动/MA 窗"；本稿不开这些，只开**上限**一个机制（用户 2026-09-13 要求打磨 B3）。

## 2. 口径（冻结）
- 基线定义与 `service`/脚本现有实现逐字相同（`eval_harbor_riskbudget._rp_nav`）：5 资产 `510300/510500/518880/513100/511260`、`close_adj`、月度首个交易日、trailing 60d 日收益、前 60 日等权、5bp/边。
- **唯一新参数**：`cap ∈ {0.50, 0.60}`（声明双点）；实现 = 迭代水填（超限资产封顶，剩余权重按 1/σ 比例再分配，直到无超限）。
- incumbent = 无上限（现行 B3）。
- 窗口：OOS2 / train / valid / long；另测 2022-01-01~2023-12-31 子窗。
- **母港层嵌入测试**：同一港湾腿 + capped B3，月初 50/50（5bp/边），对比现行 M50。

## 3. 判定（冻结，跑前写死）

**独立腿（capped B3 vs incumbent B3）**：
- **K1** long Sharpe ≥ incumbent。
- **K2** long CAGR ≥ incumbent − 0.5pt。
- **K3** long MDD ≥ incumbent − 3.0pt。
- **K4** OOS2/train/valid 每窗 Sharpe ≥ incumbent − 0.15。
- **K5 平台**：{50%, 60%} 两档都过 K1–K4（否则按尖峰拒收）。

**母港层（capped B3 的 M50 vs 现行 M50）**：
- **K6** long Sharpe ≥ 1.23 且 long MDD ≥ −13.2；四窗 CAGR ≥ 现行 − 3.0pt。
- **K7** 2022–23 压测 MDD ≥ 现行 M50 压测 − 2.0pt。

- 全过 → 采纳（两档都过取**更小 cap**）；任一不过 → incumbent（无上限）维持，方向关闭。
- 通过 ≠ 进 Live（paper 3/20 + 产品层拍板）。

## 4. 死因预判（跑前写死）
- 主：**#4 regime**——2021–26 债牛 + 金/纳强，cap 在这段可能"反而更赚"，需警惕结论只在样本内成立。
- 次：**#2 共线**——月度换手低、权重迁移集中在债→金/纳，可能只是把 beta 换成另一种 beta。
