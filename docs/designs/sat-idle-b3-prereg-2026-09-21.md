# 预注册：星舰空闲现金停「风险预算组合」（H-SAT-IDLE-B3 · 2026-09-21）

> **单假设 · 门槛跑前冻结。** 问：把**星舰（卫星 standalone）**的空闲现金，从当前
> 「mom60+MA200 argmax 集中套筒」**换成「5 资产逆波动率风险预算（B3）分散组合」**，
> 能否在**保留实质收益**的同时，把组合回撤从套筒的 −28.5% 量级**大幅收窄**？
> **关键词**：星舰 空闲现金 停车 风险预算 分散化 回撤 预注册

## 0. 一句话机制

卫星腿 100% 名义、4×25% 槽（冻结不动）；空闲现金 `w_t`（T−1 收盘因果，真实现金份额）
不再停 argmax 单腿，而是停 **B3 风险预算组合**（5 资产逆波动率、月频、因果、含 5bp 换手）：
`port_ret_t = sat_ret_t + w_t × b3_ret_t − transfer × |w_t − w_{t−1}|`。

## 1. 为什么开（背景）

- H-SAT-IDLE（2026-09-15）已证：卫星闲置现金停 **A1 港湾核心** REJECT（regime 冲突）、
  **A3 REPO** REJECT（摩擦反噬）；价目表 **A2 argmax 套筒** long +152.6（A2_true +421.3）
  但 **组合 MDD −8.4 → −28.5、SR 3.50 → 2.09**。归因（§4c）：**前 6 大回撤段 100% 由停车腿驱动**，
  套筒自身 long **MDD −28.7 / SR 0.68**。
- 死因 = **停车资产本体的风险**（集中押一条趋势腿），不是"停车"这件事。
- B13（ETF 买持基准）已证：**分散的风险预算组合 long SR 1.71 / MDD −5.0** vs 集中 argmax 套筒
  **0.54 / −30.2**——同数据下，**分散化把回撤砍到约 1/6**，代价是收益。港湾×风险预算 50/50（母港）
  已 PASS。
- **但从未有人把 B3 当作卫星闲置现金的停放资产**（sat-idle 只测了 A1/A2/A3）。本档补这个空白。
- 目标变化：H-SAT-IDLE 前提是"只追求收益"（returns-only）；本档前提是**用户要回撤**——
  判据因此改为**收益不劣 + 回撤显著优于现有套筒**（见 §3），并**跑前冻结**。

## 2. 口径（冻结）

- **卫星腿** = `replay_sgap_from_context`（habit：`amp_1430` + C1 3% + `same_1430` + `gate_1430`
  + body=3 + 30bps RT，100% 名义、4×25% 槽，0 改动）。
- **停放权重（因果）**：主行用**真实现金份额** `w_true_t = cashShare[t−1]`
  （`_true_cash_share`，与 A2_true 同口径）；`w_naive_t = clamp(1 − 0.25×pos[t−1],0,1)`
  作价目行（与 A2 同口径）。**不使用同日 label。**
- **转移成本**：`transfer = 5bps/边`（对齐停车场 0.05%/边）× `|Δw|`；敏感性 15bps/边只报告。
- **X = B3 风险预算**（`homeport.risk_budget_nav`，5 资产 `510300/510500/518880/513100/511260`，
  60 日 `pstdev(日收益)` 逆波动率、当月首个交易日调仓、月内漂移不再平衡、5bp/边，**全因果**）。
- **臂（冻结，不扫）**：
  - **A4_true（主判定）** = 卫星 + `w_true` 停 B3，5bps/边；
  - A2_true（**现有套筒对照**，同口径重算 parity）；
  - A4（`w_naive` 停 B3，价目）；
  - A4_true_15bps（成本敏感性）；
  - A5_true（**部分停车**：idle 的 50% 停 B3、50% REPO）；
  - A6_true（**部分停车**：idle 的 50% 停 argmax 套筒、50% REPO）。
- **窗口** = OOS2 / train / valid / long；**holdout 只描述、不裁决**。
- **不扫**：卫星口径、B3 资产/回看/调仓频率、部分停车比例（只报 0.5 一档）、窗口切分。

## 3. 判定（跑前冻死 · 回撤口径）

- **K1（不劣化任何窗）**：A4_true 三窗 `Δtotal` vs **星舰 standalone** 全部 **≥ 0**。
- **K2（收益实质）**：A4_true long `Δtotal` vs standalone **≥ +100pt**。
- **K3（回撤——本档的目的）**：A4_true long **MDD 比 A2_true 浅 ≥ 10pt**
  （`Δmdd = A4_true.max_dd − A2_true.max_dd ≥ +10`）。
- **K4（效率）**：A4_true long **Sharpe > A2_true long Sharpe**。
- **裁决**：**PASS = K1∧K2∧K3∧K4**；否则 REJECT。A2_true/A4/A4_true_15bps/A5/A6 为**价目表**（不裁决）。
- **锚点披露（写死）**：本档 = **卫星锚 + 换停放资产**的新资本结构，**不等于**给港湾加卫星
  （H-SAT-W 仍 REJECT）。PASS 只作**产品候选**，落地需用户拍板 + 预注册（含 Live 口径）+ paper 前瞻。

## 4. Robustness（预声明，只报告不选参）

- 转移成本 15bps/边下的四窗 Δ。
- `w_naive` vs `w_true` 两条权重口径的差（量化"少停"的价格）。
- 部分停车 A5/A6 的收益-回撤折中（价目）。
- 每窗 idle 占比 / 无仓日占比 / 平均槽位 / fills；B3 与卫星日收益相关（全窗 + idle 日切片）。
- long 年度分解（2021–2026 逐年 Δ）。

## 5. 死因预判（跑前写死）

- 主：**#4 收益不足**——B3 自身 CAGR ~8–10%（防御），换掉套筒的 +32.8%/yr（原油）/黄金 +27.8%/yr，
  K2（long Δ ≥ +100）可能挂。
- 次：**#2 regime**——B3 在卫星空仓日（弱广度）若同样不给钱（A1 的教训），K1 挂。
- 再次：**#7 样本**——holdout 仅描述、n 小。
