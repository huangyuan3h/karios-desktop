# 预注册：三腿组合「母港 + 卫星」（H-B3-SAT · 2026-09-14）

> **单假设**：把核心腿从港湾换成**母港 M50**（港湾×B3 50/50），卫星机会型 overlay 的 valid 拖累会不会被 B3 吸收到「低权重可过闸」？
> **关键词**：三腿 母港×卫星 B3 缓冲 曝露曲线 预注册

## 0. 机制（唯一的变量：核心腿）
- **核心腿 = M50**（B15 冻结口径：港湾 × B3 逆波动率 50/50、月初再平衡、5bp/边），其余**与 H-SAT-W 完全一致**：卫星有仓日 `M50 + w × (卫星 − M50)`，无仓日 100% M50（`blend_nav_opportunity`）。
- 网格（同 H-SAT-W，7 点）：`w ∈ {0.10, 0.15, 0.20, 0.25, 1/3, 0.40, 0.50}`；窗口 OOS2/train/valid/long（+holdout 只描述）。
- 卫星腿 = `replay_sgap_from_context`（amp_1430 + C1 + 14:30 买卖 + gate_1430 + raw 基期，30bps），冻结 0 改动。

## 1. 为什么值得测（与 H-SAT-W 的唯一区别）
- H-SAT-W 两腿版：valid 稀释 ≈ −42.4×w（有仓日核心 +45.8% vs 卫星 +14.3% 的结构性 regime 缺口）→ K1/K2 死区无解。
- **B3 在 valid 与港湾负相关（−0.35）**，且卫星拖累的机制是「有仓日核心太强、卫星跟不上」——B3 把核心腿的部分强势日收益稀释后，**卫星的相对缺口可能线性变小**；同时 M50 的 Sharpe 基数（1.18）低于港湾（1.00 long 除外），低相关卫星对 Sharpe 的边际可能更大。
- 这是**换基座**，不是「调卫星参数」，不违反 H4/诊断的「不再动闸/调参」约束。

## 2. 判定（跑前冻死；门槛与 H-SAT-W 同数值，保证可比、不因换基座而放宽）
- **K1（保护）**：四窗每窗 Δtotal ≥ **−5pt**（vs M50）。
- **K2（目标）**：long Sharpe ≥ M50 **+0.10** 且 long Δtotal ≥ **+25pt**。
- **K3（风控）**：long ΔMDD ≥ 0（不劣于 M50）且 valid ΔMDD ≥ **−2pt**。
- **裁决**：全过的 w 取**最大者** → 「母港 + 卫星」产品候选（仍需资本结构拍板 + paper 3/20）；无 w 全过 → **REJECT，家族扩展全关**（港湾/母港维持，卫星不再以任何权重进组合）。

## 3. Robustness（只报告不选参）
- 全网格 total/CAGR/MDD/Sharpe + Δ（vs M50；港湾参考行）。
- M50 × 卫星日收益相关（全窗/有仓日）；与两腿版 H-SAT-W 的 Δ 曲线对照。
- holdout 描述一行。

## 4. 死因预判（跑前写死）
- 主：**#2 共线/regime 未改良**——卫星与港湾/M50 的相关同源（都受 CN 股强 regime 支配），B3 只稀释核心、不改变有仓日的 regime 结构 → K1 斜率改善有限，仍与 K2 冲突。
- 次：**#3 换基座损失**——M50 的 long 基数低（+116.3），即使 w=0.1 的 long 增量也可能到不了 +25pt。
