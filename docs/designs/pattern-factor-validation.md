# 形态因子有效性验证（独立于 S-3）

> 状态：设计草稿（未落地）。与 `docs/designs/ml-n-day-trend-forecast.md`（旧：ML 并入 S-3）不同，
> 本文档主张 **形态 / ML 完全独立于 S-3**：只回答"某形态本身有没有 edge"，不做"并入 S-3 回测"式判定。

## 0. 定位与原则

1. **与 S-3 解耦**：S-3 是"1 日入场 + 风控"的执行层（score/RS/主线/熔断）。形态识别与 ML 是
   **因子研究层**——验证"某种价格结构本身是否存在可获利的一致性"。两层正交，互不替代入场。
2. **先证存在，再证有效**：不预设"形态能增强 S-3"。而是：
   (a) 全市场扫描，确认**确实有大量票在大量时间呈现某形态**；
   (b) 假设该形态存在，定义一套买卖规则，**直接验证这套规则能否获利**（独立小回放，不碰 S-3 引擎）。
3. **多因子判断**：形态只是因子之一。验证时还要看它在 量能确认 / RS 强度 / 行业主线 分层下是否
   稳定——避免"单因子伪信号"。
4. **判据**：pattern-conditional 胜率 / 盈亏比 vs 同域**无条件 base rate**（同期随机入场的期望）。
   显著为正 = 有效；不显著 = 该形态无独立 edge（不是加进 S-3 也没用，是本身没用）。

## 1. 验证方法论（与 S-3 无关的小回放）

对每种形态，独立跑一遍，不复用 S-3 的 `simulate`：

1. **扫描出现集** `O = {(day, ts)}`：2021-08 起全部 A 股日线，逐日逐票检测该形态。报告
   `|O|`、占全部 (day,ts) 的比例、分布（是否普遍 / 是否集中某些行业）。
2. **形态内标准交易**（出现即按规则下单，非 S-3 入场逻辑）：
   - 入场：形态确认的触发价（如箱体下沿 / 突破收盘价）
   - 目标：形态度量的目标位（如箱体上沿 / 双底颈线+形态高度）
   - 止损：结构破位价（如跌破支撑 / 二次底）
   - 最大持有期 `M` 天（到期限价平仓）
3. **统计**：命中率（先触目标）、胜率、平均盈亏比、平均持有天数、单笔均值。
4. **base rate**：同时间窗、同流动性域，随机入场的同指标 → 差异显著才有效。
5. **多因子分层**：在 `O` 内按 `量能确认 / RS 前50% / 是否主线行业` 切分，看 edge 是否稳定。
6. **A 股结构注意**：T+1、±10% 涨跌停、最小变动单位 → 目标/止损用收盘价近似；箱体目标通常
   <10% 可达，避免被涨跌停截断。

## 2. 形态目录（假设存在 → 如何获利）

> 每种：定义（可检测规则）→ 获利假设（入场/目标/止损/持有）→ 多因子增强 → 验证指标。

### 2.1 箱体震荡（Box / Rectangle）
- **定义**：过去 `K=20~40` 日价格在 `[L, H]` 间震荡，振幅 `(H-L)/L < 15%`，当前价距 `L` ≤ 2%。
- **获利假设**：在区间内**低买高卖**。入场 = 触 `L` 附近；目标 = `H`；止损 = `L×0.97`（破下沿）；
  最大持有 `M=20` 日；先触 `H` 即胜。
- **核心问题（用户提出）**：若大量票真在箱体，低点买入是否大概率到高点？→ 验证"箱内均值回归"胜率。
- **多因子增强**：箱体末期**缩量** + 突破前**放量** 视为有效；RS 不破位（非下行箱体）。
- **验证指标**：箱内触 `H` 命中率 vs 随机；盈亏比。
- **验证结论（2026-08-23 一检 · 全市场独立扫描）**：
  - **存在性**：911 万 (日×票) 60 日窗中 **4.07% 是箱体**（band<15% + 平坦 + ≥2 周期），约 37 万窗口 → 结构**普遍**。
  - **周期数**：2 周期 96k / 3 周期 94k / 4 周期 75k / 5 周期 51k … 典型 **2–4 个完整周期**（每周期 ~15–30 交易日），确为"类正弦、几个周期"。
  - **振幅**：中位 12.7%（p25 10.8% / p75 14%），箱内空间充足。
  - **套利（低点买→高点卖）**：下沿入场 / 上沿目标 / 下沿止损 / ≤20 日，56,235 次 → **命中率仅 11%**，mean R +0.55% / median R **−1.35%**。价格到箱底后 **89% 先破位（−1%）而非反弹到顶（+12%）**。
  - **结论**：箱体**普遍且结构清晰，但"买低卖高"非套利**——震荡只是弱均值回归，破位远快于上摸。可行 edge 须换玩法（破位方向跟随 / 箱体内更短周期来回 / 上沿 fade），非无脑低买等高等。
  - **突破行为（2026-08-23 二检 · 全市场独立）**：362k 箱体中 上破 126k / 下破 152k / 30日内未破 85k（23% 始终箱体）。
    - 上破后 N 日**中位数收益为负**（5d −0.3% / 10d −0.4% / 20d −0.7%），仅 **44.4%** 继续上行；
    - 下破后 N 日**中位数为正**（5d +0.4% / 10d +0.4% / 20d +0.7%），仅 **44.5%** 继续下行。
    - 即**突破是均值回归而非动量**：上破更常回落、下破更常反抽。
    - 跟随突破交易：上破 命中 23.0% / meanR +0.2%（≈0）；下破 命中 9.7% / meanR −0.8%（亏）。
    - **综合结论：箱体在三种朴素玩法（低买等高 / 跟涨破 / 跟跌破）下均无正 edge**；仅有极弱的"反做突破"痕迹（上破后微跌、下破后微涨，幅度 ~0.5%，扣除成本后不可靠）。箱体形态本身**不构成可套利因子**，下一形态照此独立验。
  - **反做突破 + 成本（2026-08-23 三检 · 全市场独立）**：上破→做空 / 下破→做多，目标/止损各 1.5%、≤5 日、往返成本 0.6%。
    五种模式（全量 / 低量能破 / 低量能+成熟箱体 / 低量能+cyc≥4 / 极低量能）：**胜率全部 45–48%（<50%）、净收益 −0.5~−0.6%/笔**（n 均 ≥2.4 万）。
    即二检的"反做突破"微信号在含成本+严格止损下**不成立**，跌破/上破后回归不足以覆盖成本。
    - **最终结论：箱体形态在所有测试的玩法与子模式下均无任何 ≥80% 置信度的可获利模式**，彻底关闭该形态研究，转下一形态。

### 2.2 双底 / W 底（Double Bottom）
- **定义**：60 日内两个相似低点 `d1,d2`（`|d1-d2|/min ≤ 3%`），两底间有颈线 `N`（区间高点）；
  当前价收复 `N×0.99`。
- **获利假设**：突破颈线做多；目标 = `N + (N - bottom)`（形态高度度量）；止损 = 第二底下方 2%。
- **多因子增强**：第二底**缩量**、突破**放量**；整体处上升趋势（MA60 向上）。
- **验证指标**：突破后 `M=20` 日到达目标位概率 / 平均涨幅 vs base。
- **验证结论（2026-08-23）**：0.87% 罕见，突破多 命中 38.7% / R −0.03% → 无 80% 置信度。

### 2.3 杯柄（Cup & Handle）
- **定义**：30~60 日圆底（深度 `≥12%` 后收回至颈线 95% 内），其后 5~10 日**窄幅手柄**（振幅 <5%）。
- **获利假设**：手柄上沿突破做多；目标 = 杯高 + 杯深；止损 = 手柄低下方。
- **多因子增强**：杯部缩量、柄部更缩量、突破放量。
- **验证结论（2026-08-23）**：1.82% 存在，突破多 命中 6.0% / R +0.92% → 无 80% 置信度。
- **验证指标**：突破后度量目标达成率。

### 2.4 勺型 / 浅回调（Scoop，上升趋势中的圆回踩）
- **定义**：主升中（价 > MA60 且 MA20 > MA60）出现 5~15% 圆滑回调至 `MA20/MA60` 附近，末段勾头向上。
- **获利假设**（用户提出"回调买入就能到"）：在勺底首根转阳入场；目标 = 前高；止损 = 勺底下方 2%。
- **多因子增强**：回调**缩量**、勾头日**放量**；RS 仍前 50%。
- **验证指标**：回到前高概率 / 平均涨幅 vs base。
- **验证结论（2026-08-23 深研 · 全市场独立）**：
  - **存在性**：4.29% 的 (日×票) 是勺型（比箱体还常见），中位深度 11.5%、底→确认中位 10 日 → 结构普遍。
  - **原假设"回调买入就能到"被证伪**：
    - 全样本：低位买→前高 命中 34%、R −4%；即便小目标（收复 30% 跌幅）也仅 62% 命中、R −1.6%。
    - **按动量分层反转**：弱股（60d 收益 <10%）勺型 → 48% 命中 / −1% R（近公平）；**强股（60d>30%）勺型 → 18% 命中 / −9% R（最差）**。
    - **量能分层**：回调缩量（健康回踩）命中 45% / −1.6%，远好于无缩量 28% / −5%。
    - 即"强股里的勺型"是**顶部**而非买点——原"低买"假设在强股彻底反号。
  - **🔴 高置信度模式（用户阈值 ≥80% → 着重关注）**：**强股勺型 = 做空信号**。
    在强股（60d 收益高）的勺型回踩、且破位日**放量派发**时做空（目标=勺底下方、止损=前高上方、≤20 日）：
    | 模式 | n | 命中% | R% |
    |---|---|---|---|
    | 60d>30%（基） | 98,555 | 78.7 | +7.96 |
    | 60d>40% | 59,615 | **83.0** | +10.25 |
    | 60d>50% | 37,366 | **86.5** | +12.65 |
    | 60d>30% & 放量 | 39,647 | **85.4** | +10.66 |
    | 60d>40% & 放量 | 24,426 | **89.4** | +13.55 |
    | 60d>50% & 放量 | 15,460 | **92.2** | +16.53 |
    - **业务故事（非数据挖掘）**：强动量 + 圆滑回踩 + 破位日放量 = 派发/耗尽顶；止损在前高上方，逻辑闭合。
    - **实践约束**：A 股做空受券源/标的限制，更多用作**"强股勺型 = 禁止追多 / 持仓减仓"风险信号**；若券源允许则开空袖。
    - **结论**：勺型本身不是买点信号，而是**动量耗尽的分层信号**——弱股无意义，强股是明确的顶部/做空模式（≥80% 置信度，n 万级）。
  - **反勺型 / 倒勺型（镜像：下跌趋势中的圆弧反弹 · 2026-08-23 同法验证）**：
    - **定义**：下跌趋势中（MA20<MA60）5–18% 圆弧反弹至 MA 附近后勾头向下。
    - **存在性**：1.60% 的 (日×票) 是反勺，约 14 万窗口，中位反弹 13.3% → 比勺型更挑剔、更少见。
    - **做空反勺（破前低）**：全部 52.2% 命中 / R −0.20%；强下跌 `ret60<-0.30` 56.2% / −0.88%；极强 `<-0.40` 55.7% / −0.89%（`n≈3k/700`）。
    - **原报告 80.5% 命中为入场下界过松（允许跌破前低后才入场，立即"命中"但 R 为负）；加入 `c[t]≥pre_low*1.03` 下界校正后降至 52%，无正期望。**
    - **结论**：反勺型作为独立形态亦**无简单套利**；与勺型不同，它没有分层出高置信度模式。

### 2.5 旗形 / 三角旗（Flag / Pennant，强势中继）
- **定义**：一波 `≥10%` 急涨后，5~10 日窄幅（振幅 <3%）横盘或微倾斜整理。
- **获利假设**：整理上沿突破做多；目标 = 急涨段高度叠加；止损 = 旗形下沿。
- **验证指标**：中继延续率（突破后继续原方向概率）。
- **验证结论（2026-08-23 · 全市场独立）**：918 万窗中旗形 19,045（**0.21% 罕见**），突破多 命中 **10.2% / R +0.85%** → 无 80% 置信度，中继延续率极低，旗形本身非高胜率套利。

### 2.6 三角收敛（Triangle）
- **定义**：20~30 日高点下移 + 低点上移，波幅收窄至末端。
- **获利假设**：沿突破方向（上破/下破）入场；目标 = 收敛高度；止损 = 反方向破位。
- **验证指标**：突破方向正确率（是否真有方向性 edge，还是随机）。
- **验证结论（2026-08-23）**：14.17% 很常见，突破 命中 37.4% / R +5.36% → 虽 R 为正但胜率远低于 80%，无高置信度套利。

### 2.7 突破（Breakout）
- **定义**：价格放量（`vol ≥ 1.5×20日均`）创 `N=60` 日新高。
- **获利假设**：突破日收盘做多；目标 = 度量涨幅（或 trailing）；止损 = 突破位下方 2%。
- **验证指标**：突破后 `N` 日续涨率 / 是否被假突破打止损。
- **验证结论（2026-08-23）**：0.72% 存在，突破多 命中 22.2% / R +1.03% → 无 80% 置信度，假突破多。

### 2.8 （可选）头肩顶/底 — 反转结构

## 3. 形态 × 多因子组合

单形态可能是噪声；稳定 edge 通常来自 **形态 + 量能 + 强度 + 主线** 的组合：
- **量能**：突破放量 / 回踩缩量（确认结构有效）。
- **RS**：相对强度前 50%（强势股的结构更可靠）。
- **行业主线**：是否处于当时主线行业（行业资金流正向）。
验证时对每个形态做 `O × {量能确认, RS, 主线}` 的 2×2×2 分层，挑出稳定的子组合。

## 4. 与 ML 的关系（ML 也独立于 S-3）

ML（TCN/LSTM/Transformer/XGBoost）**不应作为 S-3 的门控**（已证 AUC≈0.55 on S-3 入场，无增益，
见 `archive/2026-08-23-ml-s3-lift-verify.md`）。ML 的正确定位是：

- **独立的多因子 edge 判别器**：输入 = 形态标记 + 量价 + 衍生基本面（财务/筹码/两融/北向），
  输出 = `N` 日方向概率；验证其 **AUC/IC** 在各形态子域是否稳定高于 base。
- 与规则形态**互为印证**：规则形态给可解释结构，ML 给连续概率；两者在样本上相关性高 = 结构有效。
- 验证判据同 §1：pattern-conditional 分布 vs 无条件 base，显著为正才采用。

## 5. 印证顺序（一个一个来，先证存在再证有效）

1. **箱体震荡** — 最普遍、最易验证"低点买→到高点"假设；先跑存在性扫描 + 箱内回放。
2. **双底** → **杯柄** → **勺型** → **旗形** → **三角** → **突破**。
3. 每验完一种，出一张表：`|O|`、命中率、胜率、盈亏比、vs base、多因子分层结论。
4. 有效的形态进入"可交易因子库"；无效的标注"无独立 edge"，不再纠缠。
