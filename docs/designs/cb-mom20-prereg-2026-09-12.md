# 预注册：CB 20 日横截面动量（H-CB2 · 2026-09-12）

> 跑前冻结。单假设、零网格。来源：CB 因子电池里 `mom20` 是唯一四窗全正的 lead（[cb-daily-factors](../backtests/cb/cb-daily-factors-2026-09-12.md)），扩到 2021+ 长窗正式验。

## 假设

**H-CB2**：转债 20 日横截面动量（按过去 20 交易日收益取最高 20%）跑赢转债等权宇宙，扣成本后成立。

**一句话机制**：CB 底层是正股趋势 + 转债自身 T+0/低费/资金关注；与 A 股个股「短期反转」不同，CB 横截面中期动量可能延续（债底限制下行、情绪资金推动上行）。

**最可能死因**：#2 共线（CB 动量≈正股 beta，非独立 alpha）/ #4 单窗（2021-22 池薄）/ 换手成本（周频）。

## 冻结口径（跑前写死，不改）

| 项 | 值 |
|----|----|
| 宇宙 | `data/cb/cb_daily.csv`（2021-01~2026-08，1-min 聚合）；每券当日 amount ≥ 40 分位；close>0 |
| 信号 | 过去 20 交易日收益（`ret20`），取**最高 20%**；`ret20` 不足 20 日不入选 |
| 权重 | 等权，周频（每 5 交易日）再平衡 |
| 执行 | 主口径 close-to-close；稳健口径 next-open（再平衡次日开盘入） |
| 成本 | 主 20bp 往返；压力 40bp |
| 基准 | 同日同流动性门的**等权全宇宙** |
| 窗口 | OOS2/train/valid/past_year + **long（2021-01-01~2026-08-07）**；另按日历年分年 |

## 拒收线（跑前冻结）

- **K1**：long 窗 `mom20 − EW` 总收益 ≤ 0 → REJECT。
- **K2**：三窗 walk-forward 不足 ≥2 窗为正 → REJECT。
- **K3**：40bp 成本下 long 窗转负 → REJECT（不稳健）。
- **K4**：若正收益集中在 1–2 个日历年、其余年 ≤0 → 标"成分/regime 依赖"，不采纳。
- 邻域（lookback 10/40、next-open）**只用于平台形状检查**，不得用来挑最优参数。

## 结果（跑后补，不改上面）

**REJECT**（K1 −76.0 / K2 1/3 / K3 −97.3 / K4 0/6 年正）。见 [`cb-mom20-2026-09-12.md`](../backtests/cb/cb-mom20-2026-09-12.md)。
