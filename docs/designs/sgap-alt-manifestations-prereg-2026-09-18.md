# 预注册：S-gap 层的其他表现形式「H-SGAP-ALT-1」（2026-09-18 · 只读诊断 Stage 1）

> **何时看**：想找「第二个 S-gap」、或想换卫星桶内排序维度时。
> **何时不看**：想拿它做 Live 规则时——本档只读，先诊断后回放、先预注册后动引擎。
> **一句话机制**：S-gap 的 alpha 长在**「隔夜跳空信息事件 × 14:30 可执行的日内微结构排序」**这一层。
> 现任排序 `amp_1430`（≤14:30 振幅升序 = 买「最没被追高」的缺口票）是这个层的**一个**表现形式；
> 本档问：同层是否还有其他 **14:30 可得、零前视**的微结构排序，能给出与 `amp_1430` 同量级或更好的净 edge。
> **关键词**：S-gap 层 表现形式 微结构排序 日内位置 回踩深度 零前视 Stage-1 诊断

**自查（first-principles，跑前）**：撞 §一.1 尺度匹配律（信号与 3 日持有同层，OK）；§一.13 换手摩擦（4 槽 × 3 日，与基线同，不算新税）；§五 维1/维6（本档**不碰** K 线形态，换的是**执行层排序**，非已吸收的动量/形态维度）。
已有邻域死档：[`sat-rank-hhmm`](../backtests/sat/sat-rank-hhmm-2026-09-04.md)（`gap_asc` 永不重开、`absrunup_asc` 拒）、`10:00→14:30 drift`/有符号 runup（诊断平坦，弃）。**本档只测从未测过的日内「位置」类排序**（低点恢复度 / 高点回吐度），不重开上述两条。
**预判死因**：#3 方向证伪（日内位置 = 噪声或与 amp 共线）· #2 共线（与 amp_1430 高度相关，增量≈0）。

## 冻结口径（跑前写死、零网格）

| 项 | 值（唯一定义） |
|----|----------------|
| 事件池 | 冻结 S-gap：`open/pre_close − 1 > 3%`；R-wide `breadth > 0.5` 开闸；CN A、`_load_rows` 内建 market/ST/退 过滤（L1/L6 继承） |
| 执行 | 14:30 print 买 → 第 3 交易日 14:30 print 卖（T+1 合规）；30bp 往返；skip_t1_limit + C1 3% 同基线 |
| 候选特征（14:30 可得） | F1 `range_pos = (p1430 − lo1430)/(hi1430 − lo1430)` · F2 `low_recovery = (p1430 − lo1430)/lo1430` · F3 `high_giveback = p1430/hi1430 − 1` |
| 方向 | 每个特征**双向**都测（升序/降序，共 6 臂）——跑前不知道买低位还是高位，双向即诚实，非方向钓鱼 |
| 对照 | `amp_1430`（现任）· `gap_pct`（已知死，仅作标尺） |
| 数据/窗 | `load_sgap_context`（`bar_5min` raw）· dev 窗 **OOS2 + train**；**valid 不进 Stage 1**（留作 Stage 2 确认） |

## 判定线（跑前冻结）

- **Stage 1（本档）**：某臂要求在 **OOS2 且 train 两窗**的**顶部 1/3 桶**平均净 3 日收益，均**高于 `amp_1430` 同桶**，且每窗优势 **≥ +0.20%/笔**。
  - 命中 → 只带该臂（若多臂命中取优势最大者）进 **Stage 2**（加 `rank_key`、完整引擎 4 槽回放，v2 门控；valid 复用计数 ≥4 → 上限条件PASS）。
  - 无臂命中 → **REJECT**（本方向关闭，不扫更多特征、不换定义）。
- **覆盖门**：每窗事件数 <500 或开闸日 <50 置灰不判定。
- **多重检验披露**：6 臂 × 2 窗；Stage 1 只做筛选，任何 Stage 2 结果按 v2 G3e（valid 复用税）封顶条件PASS。

## L 门前视自检（挂一条 = VOID）

- **L1 时点宇宙**：`_load_rows` 的 market/listed 过滤继承；事件只用 T 日 open/pre_close 与 ≤14:30 bar。
- **L2 成交因果**：特征全部来自 ≤14:30（`px_hl_1430` / `px_1430`）；出场用第 3 日 14:30 print；无当日收盘信息进特征。
- **L3 数据不倒灌**：只读 `bar_5min`/`daily`，不写库。
- **L4 基期单一**：特征与前向全用 `bar_5min` raw 比值；gap 用同日 qfq open/pre_close **比值**（尺度不变）。
- **L5 口径冻结**：脚本落 JSON，记录窗/事件数/参数。
- **L6 日历市场**：CN 日历 + `_load_rows` market 门。
- **L7 可复现**：一命令 + JSON。

## 结果（跑后补 · 2026-09-18）

**Stage 1 诊断 → VOID（口径不自洽，未用作裁决）**：tercile 桶均值 ≠ 引擎选择。诊断里 `amp_1430`
顶部 1/3 桶 OOS2 均值 **−1.8%**，而引擎真实 fills 是 **+3.14%/笔（295 笔，胜率 65.8%，total +208.9%）**——
引擎只买**最低振幅的 4 只**（不是整桶等权），tercile 均值是错的代理。故改走**真引擎 A/B**。

**Stage 2（真引擎 A/B）→ REJECT**：把每个候选特征按日内百分位注入 `ctx['px_hl_1430']`（代理振幅），
跑冻结 habit 参数；基线用原始 hl，复现 **OOS2 +208.9% / train +36.9%**（= 直接引擎调用，harness 自检通过）。

| 臂（14:30 排序） | OOS2 total | train total |
|---|---|---|
| **amp_1430（现任）** | **+208.9%** | **+36.9%** |
| high_giveback:desc（买最贴日内高点） | +81.1% | +25.6% |
| range_pos:desc（买日内高位） | +92.7% | +11.1% |
| gap_pct:asc（最小缺口） | +16.0% | +4.9% |
| low_recovery:asc | +12.6% | +13.1% |
| high_giveback:asc（最大回吐） | −75.5% | +21.6% |
| low_recovery:desc | −59.9% | −24.7% |
| range_pos:asc（买日内低位） | −11.0% | +22.9% |

- 无任何臂在 OOS2 接近基线（最好的 `range_pos:desc` 差 −116pt），更谈不上两窗都超基线 → **REJECT**。
- 唯一方向性读数：买**日内强势侧**（贴高点）优于买**回踩侧**（贴低点）——但两端都被 `amp_1430` 碾压。
- **valid 未触碰**（无 survivorer，未进确认；valid 复用计数不变）。
- **诚实边界（未测）**：需 bar 级量/额的特征（VWAP 偏离、午后来量占比）不在 ctx 内，未测；若要重开须新预注册 + 新数据通路。

**结论**：S-gap 这一层的「另一个表现形式」在本族候选中不存在；`amp_1430`（振幅升序 = 买「最没被追高」的缺口票）
是这条腿专属的、不可替换的排序。详见 `../backtests/factors/sgap-alt-manifestations-2026-09-18.md`。
