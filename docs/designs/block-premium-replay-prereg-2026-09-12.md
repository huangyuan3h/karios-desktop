# 预注册：大宗溢价腿组合级回放（H-BLK-C · 2026-09-12）

> **单假设 · 零网格 · 拒收线跑前冻结。** H-BLK-B 交易级 PASS/REVIVE 后的**上升门**：把"溢价大宗"做成**可实现的日频 EW 组合**，看扣除成本、逐票去重、组合复利后是否仍有增量。
> **关键词**：大宗溢价 组合回放 引擎 成本 三窗 预注册

## 0. 一句话机制（§四 S1）
溢价大宗 = 有信息/战略买方高于市价接货 → 该票后续正漂移。做成**持有 N 日的 EW 多头篮子**，应跑赢中证500、且显著优于"大折价"篮子。

## 1. 与 H-BLK-A/B 的区别（为什么必须做）
- A/B 是**事件级（trade-level）均值差**：忽略**重叠/资金占用/复利/成本/集中度**。
- 本实验把它们还原成**日频 NAV**：每个信号买入并持有 N 日，组合每日 EW 再平衡，逐票去重（持有期内不重复开仓）。

## 2. 口径（冻结）
- 信号：`premium`（prem>0）与对照 `big_disc`（prem≤−5%），来源 `data/block/block_trade.csv`（A 股）。
- 入场：信号日 T 的**下一交易日开盘**；持有 **N=10** 交易日，末日在收盘卖（与 H-BLK-A/B 主口径一致）。
- 组合：每日对**所有活跃持仓**（entry≤d≤exit）等权再平衡；无持仓日空仓（收益 0）。
- 基准：中证500（`510500.SH` ETF，close-to-close 日收益）。
- 窗口：OOS2/train/valid/long（同前）。
- **成本**：每次开仓按 **单边 15bp**（买卖合计 ~30bp，含冲击）从当日组合收益扣；对照另报 0 成本。
- 逐票去重：同一票持有期内再出信号**不加仓**（保持 EW 不重叠）。

## 3. 指标
- 年化收益、Sharpe、最大回撤（组合与基准）。
- **超额**：组合年化 − 基准年化；**胜率**（日超额>0 占比）。
- **有效宽度**：日均活跃持仓数、日均新开仓数（覆盖/可交易性）。
- F2 对照：premium 组合 vs big_disc 组合（Δ年化 / ΔSharpe）。

## 4. 判定（冻结）
- **覆盖门**：long 内日均活跃持仓 **≥ 5**，否则 #7/#5 集中 → REJECT。
- **K1（可行增量）**：premium 组合 **超额**（vs 中证500，扣 30bp）long **> 0** 且 OOS2/train/valid **≥2/3** 为正。
- **K2（信号非纯 beta）**：premium 组合年化 > big_disc 组合年化，且 **Sharpe 更高**（long 及 ≥2/3 窗）。
- **K3（风险）**：premium 组合 maxDD 不劣于基准 maxDD + 10pt。
- K1&K2&K3 → **候选 sleeve**（可进组合级/引擎拼接；仍**不自动进 Live**）。
- 任一不过 → **REJECT/park**；不扫 N/桶界/成本/N。

## 5. 死因预判（跑前写死）
- 主：**#1 截右尾/中位负**（事件级 median 负 → 组合靠右尾，Sharpe 可能低）。
- 次：**#5 集中**（有效宽度小）、**#6 成分**（牛/熊年篮子不同）、成本吞掉薄 edge。

## 6. 产出
- 脚本：`scripts/replay_block_premium.py` → `data/backtest_reports/block_premium_replay_2026-09-12.json`
- 结论落 `docs/backtests/inst/block-premium-replay-2026-09-12.md` + SUMMARY 一行。

## 结果（跑后补）
**REJECT / park**：覆盖 ✅（日均活跃 178.5）、K2 ✅（premium 年化 0.89 > disc −6.86、Sharpe 更高）、K3 ✅；**K1 ❌**（long 超额 **−1.33%**，仅 valid +6.62 正，1/3 窗）。→ 溢价>折价在组合层成立，但价值在**空头腿**（不可做空的价差）；多头腿扣成本跑输指数。见 [`block-premium-replay-2026-09-12.md`](../backtests/inst/block-premium-replay-2026-09-12.md)。
