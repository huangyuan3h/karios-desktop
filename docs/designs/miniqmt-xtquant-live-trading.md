# miniQMT / xtquant 低费率实盘方案（L4-P1 券商研究）

> **状态**：未落地 / 待拍板。L4（执行闭环）的前置调研稿 —— 对应 [`l3-l4-evolution-roadmap.md`](./l3-l4-evolution-roadmap.md) **L4-P1 券商研究**。
> **拍板前置**：找到支持 miniQMT 的线上量化渠道 → 客户经理**文字确认**费率与 xtquant 权限 → 才能进入开户 / 架构验证。
> **注意**：券商费率、miniQMT 权限、xtquant 开通渠道会随时间和渠道变化，本文档结论以最新文字确认为准。

## 1. 方向摘要（一句话版）

> 找**国金证券 / 中泰证券 / 国投证券 / 华鑫证券**这类支持 miniQMT 的线上量化渠道，谈到股票万 1 左右、ETF 万 0.5 左右、miniQMT 免费开通；Mac 通过远程连接一台 Windows 云电脑，用 Python + xtquant 跑实盘。
>
> 这是目前个人做 A 股程序化交易里**费率、稳定性、开发效率最均衡**的方案。

---

## 2. 券商选择

不要直接去线下营业部开默认佣金账户；优先找**支持 miniQMT / xtquant 的线上量化渠道**。

| 优先级 | 券商 |
|--------|------|
| 首选 | **国金证券**（线上量化渠道） |
| 备选 | 中泰证券 · 国投证券（原安信）· 华鑫证券 |

> 执行方向：优先国金证券线上量化渠道开通 miniQMT / xtquant；哪家费率更低、开通更快就选哪家。

---

## 3. 费率目标（按此标准谈）

开户前直接问客户经理，目标是：

| 项目 | 目标费率 |
|------|----------|
| A 股股票佣金 | **万 1 左右 / 万 1.2 全包** |
| ETF 佣金 | **万 0.5 - 万 0.6** |
| 可转债佣金 | 接近成本价（沪市约万 0.02，深市约万 0.5 或更低） |
| 两融利率（如需） | **4.5% - 5.5%** |
| miniQMT / xtquant | **免费开通、免费使用**（收"接口费/软件费"的要谨慎） |
| 行情 | Level-1 基础行情免费；Level-2 是否收费 / 可赠送另行确认 |

需要问清楚的口径：

- 股票佣金是「净佣万 1」还是「全包万 1」？是否含规费？过户费是否单独？
- 最低 5 元能否豁免？（"免五"不一定合规，以券商当前合规口径为准；不能免则小单成本明显变高）

## 4. 开户前文字确认清单（可复制给客户经理）

> 你好，我想开通 miniQMT / xtquant 实盘权限，请确认以下几点：
> 1. 贵司是否支持个人客户开通 miniQMT？
> 2. 是否支持 xtquant Python 库实盘下单？
> 3. 开通 miniQMT / xtquant 是否有资金门槛？需要多少入金或资产？
> 4. miniQMT 是否免费？是否有软件费、接口费、流量费？
> 5. 股票佣金是否可以做到万 1 左右？是净佣还是全包？
> 6. 是否包含规费？最低 5 元是否可以豁免？
> 7. ETF 佣金多少？可转债佣金多少？
> 8. 是否支持程序化交易报备？流程怎么走？
> 9. 是否提供 miniQMT 下载链接、账号、客户端认证码？
> 10. 是否支持模拟盘测试？

对方含糊不清时不要急着开户。

## 5. 技术架构：Mac 怎么跑

miniQMT / xtquant 主要在 Windows 上运行，Mac 侧远程连接：

> Mac → 远程连接 → Windows 云电脑 → 安装 miniQMT → Python + xtquant 跑策略 → 实盘下单 / 撤单 / 查询

### Windows 云电脑配置

- CPU 4 核以上；内存 8G 以上（推荐 16G）；硬盘 80G - 100G
- 系统：Windows Server 2019 / Win10 / Win11；带宽 3M - 5M 起步
- 云厂商：阿里云 / 腾讯云 / 华为云 / 京东云 / 无影云电脑
- 成本参考：约 60 - 150 元 / 月；包年约 800 - 1800 元 / 年

## 6. 软件栈

1. **miniQMT 终端**（券商提供）：安装包、资金账号、交易密码、客户端认证码 / 授权码、行情/交易服务器地址
2. **Python 环境**：Python 3.8 - 3.11，venv / conda，安装 xtquant（`pip install xtquant`，不同券商版本可能有指定包，按券商文档来）
3. **策略程序**（xtquant 提供的能力）：登录、订阅行情、获取 tick / kline、下单、撤单、查询委托 / 成交 / 持仓 / 资金、接收回调

---

## 7. 实盘前验收清单

不一开始就跑大资金。

### 7.1 模拟盘测试

Python 连接 miniQMT、订阅行情、获取最新价、查询资金 / 持仓、买入 / 卖出 / 撤单、查询委托状态、接收成交回调、断线重连、重启恢复、日志完整。

### 7.2 小资金实盘测试

100 股买 / 卖、限价单、市价单（谨慎）、撤单、部分成交、废单处理、涨跌停价格处理、停牌处理、资金不足处理、持仓不足处理。

---

## 8. 风控（必须自建）

xtquant 灵活，风控要靠自己，至少加：

1. **单笔最大下单金额**：如单笔买入 ≤ 10000 元，防止代码写错下成大单
2. **单日最大交易次数**：如每日最多下单 100 次、最多撤单 50 次，防死循环下单/撤单
3. **价格偏离保护**：委托价不能偏离最新价 ±5%，防 fat finger 或行情异常
4. **白名单股票池**：只允许交易策略内股票
5. **黑名单**：ST / *ST、新股、停牌股、退市整理股、高波动妖股、流动性极差股票禁止交易
6. **强制日志**：每笔操作记录时间、代码、方向、价格、数量、委托号、策略名、触发原因、返回状态

## 9. 最终可执行版本

**方案名称**：国金证券 / 中泰证券线上量化渠道 + miniQMT + xtquant + Windows 云电脑

**目标费率**：A 股万 1 左右 · ETF 万 0.5 - 0.6 · 可转债成本价附近 · miniQMT 免费 · L1 行情免费 · 两融 4.5% - 5.5%（如需要）

**执行步骤**：

1. 找支持 miniQMT 的线上客户经理
2. 文字确认费率和 xtquant 权限
3. 开户 → 入金满足门槛 → 申请 miniQMT / xtquant 实盘权限
4. 完成程序化交易报备
5. 购买 Windows 云电脑 → 安装 miniQMT → 安装 Python + xtquant
6. 先跑模拟盘 → 小资金实盘 → 逐步放大资金
