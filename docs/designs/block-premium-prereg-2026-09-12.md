# 预注册：大宗交易折溢价 / 机构席位（H-BLK-A · 2026-09-12）

> 跑前冻结。只读诊断。三条"深层次"里最后一条（前两条：龙虎榜机构 REJECT、股东户数 REJECT 耳语级）。

## 假设

**H-BLK-A**：大宗交易**溢价成交**（买方愿高于市价接货）→ 正向超额；**折价**（卖方让价，常见）→ 负/弱。**机构专用买入** → 正向。

**一句话机制**：溢价大宗 = 买方（常为机构/产业资本）愿意付出高于市价的对价 = 强信号（信息链首）；折价大宗是常态减持（链尾）。

**预判死因**：`#2 共线`（机构行为被动量吸收）；`#6 样本`（溢价大宗占比低）；折溢价与"当日涨跌"共线。

## 冻结口径

| 项 | 值 |

## 判定线（跑前冻结）

- **K1**：溢价组 long `excess_10 > 0` 且 OOS2/train/valid **≥2 窗 >0**。
- **K2**：**溢价 − 折价大** 差值 long > 0 且 ≥2 窗 >0。
- **K3**：机构专用买入 − 机构专用卖出 差值 long > 0 且 ≥2 窗 >0。
- **结论**：K1&K2&K3 → 开"大宗信号并入"预注册；任一不过 → **REJECT 关线**（不扫阈值/N）。

## 结果（跑后补）

**REJECT（按冻结线），但含三条深源最强生命体征**：折溢价梯度单调、溢价组三窗全正（K1 ✅ +0.40/3 窗；K2 ✅ 溢价−大折价 N20 +1.44%）；**K3 机构席位 ❌（买−卖 −0.28，方向反）+ median 全负**。复活条件=溢价大宗动量中性化三窗仍正。见 [`block-premium-2026-09-12.md`](../backtests/inst/block-premium-2026-09-12.md)。
