# 预注册：S-gap 层 bar 级量额特征「H-SGAP-ALT-2」（2026-09-18 · 只读诊断 Stage 2）

> **何时看**：想继续在「隔夜跳空 × 14:30 微结构」层找 `amp_1430` 之外的表现形式时。
> **何时不看**：想拿它做 Live 规则时——本档只读，先诊断后回放、先预注册后动引擎。
> **一句话机制**：ALT-1 已证「位置类」排序全输 `amp_1430`（振幅升序）；本档补 **bar 级量/额**维度
> （价格相对 VWAP 的位置、午后参与度、量价重心），问这层是否还有 `amp_1430` 之外可用的排序。
> **关键词**：S-gap 层 VWAP 偏离 午后量占比 量价重心 bar 级 代理振幅 A/B

**自查（first-principles，跑前）**：承接 [`H-SGAP-ALT-1`](sgap-alt-manifestations-prereg-2026-09-18.md)——其 REJECT 关闭了「位置类」，**未覆盖 bar 级量/额**，故不是重复。撞族风险：`sat-churn`（T-1 换手过滤）、`sat-c3-fade`（盘中跌过滤）已被桶+槽吸收；本档是**排序**而非过滤，且用 bar 级量分布，机制不同。
**预判死因**：#2 共线（量分布与 amp 高度相关）· #3 方向证伪（无稳定方向）· #7 覆盖（bar 数据不足）。

## 冻结口径（跑前写死、零网格）

| 项 | 值（唯一定义） |
|----|----------------|
| 事件池 / 执行 | 同 ALT-1 / 冻结 S-gap：gap>3%、R-wide 14:30 闸、skip_t1 + C1 3%、14:30 买 → 第 3 日 14:30 卖、4 槽 × 25%、30bp |
| 数据通路 | 新增只读 `bar_5min` 聚合查询（**不改核心 loader**）：bars `trade_time <= '1430'`，`vol>0`、OHLC 非空 |
| F1 `vwap_dev` | `p1430 / VWAP − 1`，`VWAP = Σ((h+l+c)/3 × vol) / Σvol` |
| F2 `pm_vol_share` | `Σvol(trade_time > '1130') / Σvol(<=1430)`（午后参与度） |
| F3 `vol_weighted_pos` | `Σ(vol × (c−l)/(h−l)) / Σvol`（量价重心，0..1） |
| 方向 | 每特征**双向**（升/降序），共 6 臂 |
| 对照 | `amp_1430`（现任） |
| A/B 方法 | 特征按**日内百分位**注入 `ctx['px_hl_1430']`（`hi−lo=pct·px`），跑真引擎；基线用原始 hl（复现直接调用）。**禁用桶/分位均值代理**（ALT-1 §3.1 教训） |
| 窗口 | dev = OOS2 + train；valid 仅留给幸存者确认（触碰则复用计数 +1，上限条件PASS） |

## 判定线（跑前冻结）

- 某臂要求在 **OOS2 且 train** 的引擎 `total` 均**高于 `amp_1430` 基线 ≥ +5pt**。
  - 命中 → 只带该臂（多臂取最差窗优势最大者）进 valid 确认 + long/v2 门控。
  - 无臂命中 → **REJECT**（本方向关闭，不扫更多 bar 特征）。
- 覆盖门：任一窗事件数 <500 或开闸日 <50 置灰不判定。
- 多重检验披露：6 臂 × 2 窗；Stage 2 只做 dev 筛选，valid 复用税封顶条件PASS。

## L 门前视自检（挂一条 = VOID）

- **L1 时点宇宙**：`_load_rows` market/ST/退 过滤继承；事件只用 T 日 open/pre_close + ≤14:30 bar。
- **L2 成交因果**：F1–F3 全部来自 `trade_time <= '1430'` 的 bar；出场用第 3 日 14:30 print。
- **L3 数据不倒灌**：只读 `bar_5min`/`daily`，不写库。
- **L4 基期单一**：F1–F3 用 bar 内比值/量权重（尺度不变）；gap 用同日 qfq 比值；引擎成交沿用既有 raw 路径。
- **L5 口径冻结**：脚本落 JSON，记录窗/聚合口径/参数。
- **L6 日历市场**：CN 日历 + `_load_rows` market 门。
- **L7 可复现**：一命令 + JSON。

## 结果（跑后补 · 2026-09-18）

**REJECT**。基线复现 **OOS2 +208.9% / train +36.9%**（harness 自检通过）；7 臂全跑：

| 臂（14:30 排序） | OOS2 | train |
|---|---|---|
| **amp_1430（现任）** | **+208.9%** | **+36.9%** |
| vwpos:asc（量价重心低 = 量堆在 bar 下沿） | +134.4% | +43.4% |
| pm_share:asc（午后量占比低 = 上午放量） | +129.1% | +45.9% |
| vwpos:desc / pm_share:desc | +9.7% / −62.2% | −18.7% / −19.4% |
| vwap_dev:asc（低于 VWAP） | −81.4% | +14.2% |
| vwap_dev:desc | −69.8% | −22.4% |

- 无一臂在 **OOS2** 接近基线（最好是 `vwpos:asc`，差 −74.6pt）；`pm_share:asc`/`vwpos:asc` 在 train 小胜
  基线（+9.0 / +6.5pt）但 OOS2 大输——典型的「train 好看、选参窗崩」，按冻结线 **REJECT**。
- 方向读数：**上午放量 / 量堆在 bar 下沿** 略优于午后放量，但都被 `amp_1430` 碾压。
- **valid 未触碰**（无幸存者；复用计数不变）。
- 覆盖：OOS2 243 个有 bar 特征的事件日 / train 123 个。

**H-SGAP-ALT-1 + ALT-2 联合结论**：S-gap 层经两轮独立预注册（位置类 + bar 量额类，共 12 臂）无第二形态；
`amp_1430` 是专属、不可替换的排序。详见 `../backtests/factors/sgap-alt2-bar-features-2026-09-18.md`。
