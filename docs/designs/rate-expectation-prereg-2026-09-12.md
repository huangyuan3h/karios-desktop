# 预注册：美国利率「预期差」→ 次日资产（H-RATE-B · 2026-09-12）

> 跑前冻结。只读诊断。**测对维度**：不是"加息/降息"动作（H-RATE-A 已否），而是**预期差**——用美国 2Y 国债收益率的**隔夜跳变**当市场隐含路径的重新定价代理。

## 假设

**H-RATE-B**：`ΔUS 2Y 收益率`（隔夜，bps）对次日 A 股/久期资产收益有**负预测力**：收益率跳升（鹰派意外）→ 黄金/纳指/恒科/成长次日跌；反之涨。

**一句话机制**：2Y 收益率 = 市场隐含的政策路径；其日间跳变 = 预期差（含决议、措辞、数据）。预期变鹰 → 贴现率上 → 长久期资产承压。

**为什么比 H-RATE-A 对**：H-RATE-A 只测离散"加/降"（且加息=熊市 regime 混淆）；本版用**连续的收益率跳变**当预期差，全样本、去 regime 水平。

**预判**：`#8 市场状态被吸收` + `#2 共线`（金/纳指已在择强 mom60 里）+ A 股开盘即 price in → 大概率仍无 edge，但这是测对维度。

## 冻结口径

| 项 | 值 |
|----|----|
| 数据 | `data/macro/us_yields.csv`（akshare `bond_zh_us_rate`，1990~2026-09）；`ΔUS2Y` = us2y 日间变化（bps，自身序列） |
| 对齐 | A 股交易日 `t` 用**之前最近一个美债交易日的 ΔUS2Y**（隔夜，无前视） |
| 资产 | ETF 面板：黄金 / 纳指100 / 恒科 / 创业板 / 科创50 / 沪深300 / 中证500 / 十年国债 |
| 度量 | `corr(ΔUS2Y_prior, r_asset(t))`；ΔUS2Y 五分档的平均资产收益（单调性）；分窗 OOS2/train/valid/**long** + 分年 |
| 子集 | FOMC 决议日（`data/macro/fomc.csv`）的 ΔUS2Y 跳变单独报 |
| 期望符号 | 黄金/纳指/恒科/创业板/科创50 → **负**；国债 → 观察 |

## 判定线（跑前冻结）

- **K1**：≥1 久期资产 `corr < 0` 且 `|corr| ≥ 0.05` 且 OOS2/train/valid **≥2 窗同号**。
- **K2**：五档单调——最高档（收益率跳升最多）资产收益 − 最低档 < 0，量级 > 0.3%/日。
- **结论**：K1&K2 → 开"利率预期差并入择强/择时"预注册；任一不过 → **REJECT 关线**（不扫窗/阈值/资产）。
- 分窗/分年只读；不做组合优化。

## 结果（跑后补）

**REJECT（关系真、不可交易）**：黄金 corr −0.18（valid −0.29、FOMC 日 −0.51）、五档单调价差 +0.62% → K1/K2 ✅；**但成交语义门 FAIL——效应全在隔夜跳空（gap corr −0.19），盘中 open→close 仅 −0.03**，开盘已 price in 抓不到。见 [`rate-expectation-2026-09-12.md`](../backtests/event/rate-expectation-2026-09-12.md)。
