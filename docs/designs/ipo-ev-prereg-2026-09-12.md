# 预注册：打新收益层 EV（H-IPO-A · 2026-09-12）

> 跑前冻结。只读诊断 / 收益层评估（非 alpha，不改 Live）。回答"打新值不值得作为低风险正期望收益层"。

## 假设

**H-IPO-A**：网上打新（中签后按发行价买入、上市卖出）是**正期望收益层**，年化期望收益/底仓市值可观。

**一句话机制**：发行价相对二级市场折价 → 中签即锁定一个正期望的"彩票"；期望收益 = 申购额度 × 中签率 × 每股收益，随底仓市值放大（规模换收益）。

**预判**：**#6 样本/regime**——2022/2023 破发潮可能让 EV 转负；2024+ 注册制后首日大涨但 IPO 数骤减。（描述性风险层，非 alpha，`§三` 死因不完全适用。）

## 冻结口径

| 项 | 值 |
|----|----|
| 宇宙 | `data/ipo/ipo_perf.csv` 沪深 A 股（**排除北交 bj**），窗口 2021-01-01~2026-08-07 |
| 收益 | `sell_ret`：主板=**开板日**收盘/发行价−1；注册制(30x/688)=**首日**收盘/发行价−1 |
| 底仓 | 总市值 `M` 万元，沪深各半（沪额度=`M/2`×1000 股，深同）；`limit_amount`=申购上限(万股) 封顶 |
| 期望中签 | `quota_shares × ballot%`（股）；`quota_shares = min(市值×1000, limit_amount×10000)` |
| 期望收益 | `期望中签股数 × price × sell_ret`；窗口内加总 / 市值 = EV% |
| 场景 | M = 10 / 20 / 50 / 100 万元（A/B 结构对照，非扫参） |
| 窗口 | OOS2/train/valid/**long(2021-01~2026-08)** + 分年；IPO 按 `ipo_date` 归属 |
| 背景 | 破发率、中签率、年均 IPO 数；不建底仓收益（另层） |

## 判定线（跑前冻结）

- **K1**：long 总 EV%（M=20万）**> 0**。
- **K2**：OOS2/train/valid 三窗 EV ≥2 窗 > 0。
- **K3**：近两年（2025、2026）EV 均 > 0（政策/注册制后仍成立）。
- **结论**：三项全过 → 值得建"打新收益层"（另设计：底仓来源/权限/自动化）；任一不过 → 标注失效年份，**只作已知年份的存量操作**，不进产品线。
- 分年/分板块只读；不扫卖出规则、不做多签/多账户假设。

## 结果（跑后补）

**PASS（K1 ✅ long +21.48%；K2 ✅ 3/3 窗；K3 ✅ 2025 +4.70%/2026 +5.29%）→ 值得建打新收益层。** 年化 EV/底仓市值 ≈ 3–7%（M=20万），2022 打平。见 [`ipo-ev-2026-09-12.md`](../backtests/ipo/ipo-ev-2026-09-12.md)。
