# 预注册：游资解剖（Hot-Money Anatomy · 2026-09-15）

> **何时看**：执行本程序、或有人再提"跟游资/学龙头战法"时。
> **何时不看**：想改 Live 参数时——本程序**只读**，不产出任何实盘规则。
> **一句话**：不是重开打板（那个线已关，见 [limitup-do-not-redo](../backtests/limitup-do-not-redo-2026-09-12.md)），而是回答用户的好奇：**头部游资的钱是在哪一段赚的、为什么我们接不到**。用席位级龙虎榜 + 全天 5min + 精确涨停价，把他们的行为分解成 gap / 盘中 / 多日漂移，并交叉封板质量与情绪周期。

**关联档案**：
[limitup-do-not-redo-2026-09-12](../backtests/limitup-do-not-redo-2026-09-12.md)（打板死因：逆向选择）· [lhb-inst-netbuy-2026-09-12](../backtests/inst/lhb-inst-netbuy-2026-09-12.md)（**机构**席位 REJECT：公开拥挤链尾）· [intraday-microstructure-2026-09-11](../backtests/factors/intraday-microstructure-2026-09-11.md)（5min 稀疏、成本吃光）· [first-principles-2026-09-05](../backtests/first-principles-2026-09-05.md)（§二.1 成交语义 / §三死因 / §五结构吸收）

**与既有结论的边界（跑前说明，不是重复开刀）**：
1. 已测的是**机构席位**（jgmmtj）与"次日开盘追板"的**股票级**结果；**营业部级（游资候选席位）**从未落库、从未测。
2. 打板死因是"排队成交不可建模 + 逆向选择"——本程序**不测排队买入**；E5 只测**可执行**缝隙（开板回封后入场、非一字次日），这正是旧档说的"未测的唯一缝"的诚实子集（无 level-2，封单量历史不可得，见 §1）。
3. 全部诊断允许"REJECT"结局——那本身就是答案：**他们的钱在哪一段、那段我们能不能碰到**。

## 3. 实验（每个单假设 · 零网格 · 判定线跑前冻结）

### E1 · H-FLOW-1：席位净买的次日分解（gap vs 盘中）

**假设**：头部游资席位 T 日净买的股票，T+1 **开盘 gap 为正**（他们卖给跟风盘的位置），而 T+1 盘中 `open→close` 为负；机构/拉萨/对照组的 gap 更小。→ "游资的钱在隔夜，接的人买在盘中"。

**口径（冻结）**：

| 项 | 值 |
|----|----|
| 事件 | T 日 `lhb_seats` 中分组净买 > 0：`游资-头部` / `游资-非头部` / `机构` / `拉萨` / `沪深股通`；对照组 = 当日上榜但无上述净买的股票 |
| 分解 | `gap = open(T+1)/close(T) − 1`；`intraday = close(T+1)/open(T+1) − 1`；`d3 = close(T+3)/close(T) − 1`（可执行口径从 T+1 开盘计）|
| 超额 | 各组均值 − 中证500（510500）同窗；分年 + OOS2/train/valid/long |
| 成交语义 | 剔除 T+1 一字/涨停开盘（`open == up_limit`）后重算（K3）；记录不可买占比 |
| 宇宙 | 沪深个股，剔 ST/BJ/退市/上市 <60 日；金额门：T 日成交额 ≥ 0.7 亿（可交易门）|
| 数据 | D1 + `stk_limit` + `daily`（后复权）|

**判定线（跑前冻结）**：
- **K1**：`游资-头部` 组 `gap` long > 0 且 OOS2/train/valid **≥2 窗 >0**。
- **K2**：`游资-头部` gap − `机构` gap > 0（≥2 窗）——排除"上榜本身"的共性。
- **K3**：剔除 T+1 一字后 K1 不翻号；且 `游资-头部` 的 `intraday` ≤ 机构组（"卖给盘中接盘"的不对称）。
- 结论：K1&K2&K3 → "隔夜溢价 = 头部游资利润来源" 成立 → E2/E5 深化；任一不过 → **REJECT 记录**（他们的钱不在上榜后可见段）。

**预判死因**：`#2 共线`（席位买入≈动量/涨停代理）→ K2 是主门；`成交语义`（次日一字不可买）；`#4 单窗`。

**脚本/输出**：`scripts/diag_hotmoney_seat_flow.py` → `data/backtest_reports/hotmoney_seat_flow.json`；报告 `docs/backtests/hotmoney/flow-*.md`。

### E2 · H-FLOW-2：席位时间结构——隔夜型 vs 接力型

**假设**：头部席位内部有两种人：**隔夜型**（T+1 卖出席位再现 ≥50%，钱=隔夜 gap）与**接力型**（T+1 同席位继续净买，钱=多日漂移）。T+3/T+5 的正收益集中在接力型席位上；隔夜型在 T+1 盘中已走。

**口径（冻结）**：
- 事件：E1 样本中，同席位 S 与股票 X 的 T 日净买；跟踪 `S@X` 在 T+1..T+3 的 `top_inst` 再现（买入/卖出、金额）。
- 指标：`sell_through(S,X) = 1[S 出现在 T+1 卖出席位]`；`add_on = 1[S 出现在 T+1 买入席位]`；按席位聚合得席位分型：隔夜型（sell_through ≥ 0.5）、接力型（add_on ≥ 0.3）、混合/其他。
- 前瞻：T+1 gap / intraday、`close(T+1)→close(T+3)`、`close(T+1)→close(T+5)`；按席位分型 × 连板高度（首板/2板/3板+）分组。
- 窗口/宇宙/成本：同 E1。

**判定线**：
- **K1**：头部席位 `sell_through` 显著高于机构组（≥2 窗）；即"隔夜了结"是游资普遍行为。
- **K2**：接力型席位的 `close(T+1)→close(T+3)` 均值 > 隔夜型（≥2 窗）——钱在多日漂移上的分型真实。
- **K3**：剔除 T+1 一字后结论不翻号。
- REJECT 也留档：**分型不存在** = 席位行为同质，赚钱靠选股不靠节奏。

**预判死因**：`#6 样本不足`（单席位事件数少）→ 先做"头部席位池"聚合，不逐席出结论；`#4 单窗`。

**脚本/输出**：`scripts/diag_hotmoney_seat_timing.py` → `.../hotmoney_seat_timing.json`。

### E3 · H-BOARD-1：封板质量梯度（5min 微观）

**假设**：涨停股内部，**封板质量**（首封早、炸板少、封板占比高、尾盘封住）单调预测 T+1 gap；游资头部席位的股票集中在高质量档，散户/拉萨集中在低质量档 → 质量=他们与跟风盘的分界线。

**口径（冻结）**：
- 样本：日线封板（`close == up_limit`，`stk_limit` 精确价），剔 ST/BJ/上市<60 日，2021+。
- 质量特征（全天 5min；定义写死）：
  - `first_seal` = 首个 `low == up_limit` 的 bar 时间（保守封死判据：全 bar 在板上）；
  - `sealed_share` = `low == up_limit` 的 bar 数 / 总 bar 数；`reopen` = 封住后出现 `high < up_limit` 的切换次数；`tail_sealed` = 15:00 bar `low == up_limit`；
  - 阶段一（**2024–26，单 regime**）只出**描述统计，不给 verdict**；阶段二（D4b 后，2021–23 全时段）才进三窗判定。
- 前瞻：T+1 gap / intraday / T+1..T+3；分组 = 每特征**跑前定义的三分位**（不扫描）。
- 交叉：E1 的席位组别 × 质量档（描述）。

**判定线（阶段二才判）**：
- **K1**：`first_seal` 早 → T+1 gap 高的梯度单调，且 ≥2/3 窗同向。
- **K2**：最高质量档 T+1 gap 扣 30bp 后仍 > 0（先看不可买占比——一字档大概率直接死）。
- **K3**：剔除 T+1 一字后梯度保留。
- 结论：**K1&K3 过 = 质量是真实分界**（无论我们能否吃）；K2 另算"可吃性"。

**预判死因**：`#7 覆盖/逆向选择`（优质板=一字不可买）；`#2 共线`（质量 ≈ 连板高度/情绪代理）；`#4 单窗`（2024 崩盘 vs 2025 牛市）。

**脚本/输出**：`scripts/diag_limitup_board_quality.py` → `.../limitup_board_quality.json`。

### E4 · H-CYCLE-1：情绪周期相位——钱在哪个相位

**假设**：头部游资净买事件的前瞻 gap 高度依赖**情绪相位**（赚钱效应 ON/OFF）；他们的正收益集中在 ON 相位，OFF 相位亏钱或不做 → 其 skill 含择时。

**口径（冻结）**：
- 相位变量（T 日收盘可得，全部来自 D5）：`昨日涨停溢价`（T−1 涨停股 T 日收益均值）、`涨停家数 5 日变化`、`broken_proxy 率`、`连板高度 max`。
- **三相定义（跑前写死）**：ON =（昨日涨停溢价 > 0 且 涨停家数 ≥ 其 60 日 50% 分位）；OFF =（昨日涨停溢价 < 0）；其余 = MID。**不做阈值扫描**。
- 事件：E1 的 `游资-头部` 净买组；前瞻 T+1 gap、T+1→T+3。
- 窗口：OOS2/train/valid/long + 分年；2024-08 前用 D5 重建变量、之后与 `market_cn_sentiment_daily` 对账。

**判定线**：
- **K1**：ON 相位 `gap` − OFF 相位 `gap` > 0（long 且 ≥2/3 窗）。
- **K2**：ON 相位的正收益贡献占比 > 50%（描述，不设闸）且 OOS2/train/valid 同号。
- **K3**：与 E1 全样本对照，相位分层后 gap 的"全样本正值"不消失（= 不是靠全样本混合）。
- REJECT = 相位不解释 → 他们的钱跨相位（更"选股"而非"择时"）。

**预判死因**：`#3 方向证伪`（相位与指数 regime 共线，`#2`）；`#4 单窗`；相位定义自由度 → 已跑前冻结三相。

**脚本/输出**：`scripts/diag_hotmoney_cycle.py` → `.../hotmoney_cycle.json`。

### E5 · H-EXEC-1：可执行缝隙探针（**先声明大概率 REJECT**）

**假设（两条独立小假设，各自冻结）**：
- E5a 回封入场：T 日 14:30 前炸板、14:30–15:00 重新封住（5min 判定）→ 次日开盘卖 / T+3 收盘卖，净成本后有正期望。
- E5b 非一字次日：T 日高质量封板（E3 特征），T+1 非一字开盘买入 → T+3 收盘卖，净期望 > 0。

**口径（冻结）**：成交=次日开盘/收盘价（`daily`）；成本 30bp/边（卖出含印花税已计入 30bp 假设，敏感性 15/50bp 描述）；容量门 T 日成交额 ≥0.7 亿；剔除 ST/BJ/上市<60 日；分年 + 三窗。基线 = 中证500 同窗 + 同期 S-gap 卫星对照。

**判定线**：K1 净期望 > 0（long 且 ≥2/3 窗）；K2 超额（vs 中证500）> 0；K3 剔除一字/最小市值分位后不翻号。**任一子实验全挂 → 缝关闭，不再补网格**。

**预判死因**：`#7 覆盖`（回封样本少）；`#1 截右尾`（早卖丢脉冲）；`成交语义`（炸板瞬间滑点，5min 无法刻画真实成交价 → 结论按"上界"解读）。

**脚本/输出**：`scripts/diag_hotmoney_exec_probe.py` → `.../hotmoney_exec_probe.json`。

## 4. 纪律与不做

**纪律**（同 P0-12/P0-13）：
1. 单假设、零网格、判定线跑前冻结；诊断 →（必要时）回放，一门不过即关。
2. 成交语义优先：一字/涨停开盘剔除后重算；回封成交按上界解读；T+1 制度约束（当日买不可当日卖）。
3. 成本最低 30bp 往返；任何日内信号先算毛收益 vs 成本（`intraday-microstructure` 教训）。
4. 宇宙声明：ST/BJ/退市/上市<60 日四项每次印；0.7 亿金额门；raw（5min）vs qfq（daily）基期混用禁止（OPT-182 教训）。
5. 三窗（OOS2/train/valid）+ long；单窗好看 = 过拟合。
6. 每刀结果落 `docs/backtests/hotmoney/*.md` + `SUMMARY.md` 一行；预注册档即本文件（跑后 §5 补结论，原文不改）。
