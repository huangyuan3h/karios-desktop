## 1. 假设与机制

**H-CHAIN**：产业链**龙头（anchor）**的基本面事件（出货量↑、资本开支↑、订单/业绩超预期）会沿**供应链**向上游/下游传导，相关公司在**数周~数月**出现业绩预期上修与股价漂移。

- 例：NVIDIA 服务器出货/资本开支 → 上游（光模块 CPO、液冷、铜连接、电源、服务器代工）采购与营收上修 → A 股对应公司漂移。
- 例：Apple 新机/备货 → **果链**（组装/结构件/声学/面板）量价上修。
- **一句话**：anchor 的量 → 链上公司的价（`量价传导`），且市场对二线/三线供应链的定价滞后。

**为什么这是 KOL 的"深"**：散户关注/人气是链尾（负）；KOL 的护城河是**产业链推理 + 渠道/专家调研**——即把 anchor 的公开量数据，手工映射到 A 股链上公司。我们要用**可回填的数据**把这个映射自动化。

## 2. 可测的三种形态（择一预注册，单假设零网格）

1. **Anchor 事件 → 链上漂移（EVENT）**：anchor（海外龙头）财报/出货/发布会后，A 股概念板块成分在 N 日（N=5~40）的超额。
   - **命门**：海外 anchor 事件多在美股时段 → A 股开盘即 gap（`first-principles §一.14 宏观信息消费端律`）。**必须**用 open→close 或更长窗，区分 gap 与**慢漂移**。
2. **概念板块相对强度 → 链内选强（THEME-MOM）**：板块指数 mom → 成分股轮动。
   - 撞 `维5 行业/主题 全吸收`（主线闸已吃）→ 预判 #2。价值在"跨市场 anchor 领先"而非板块内动量。
3. **上游 vs 下游 lead-lag（LEAD-LAG）**：同链内"上游采购数据（anchor 量）→ 中游公司"的领先滞后；用主营构成（`stock_zygc_em`）界定上下游位置。

**建议先做 1（EVENT）**：机制最干净、数据最全、且直接检验"链首 vs 链尾"。

## 4. 预判死因（跑前自查）
- **`§一.14 宏观信息消费端律`**：海外 anchor 事件 → A 股概念**隔夜 gap** → 日线级不可交易。**这是头号风险**；只有"慢漂移"部分可交易。
- **`#2 共线`**：概念板块动量可能被主线闸/RS 吸收（维5 全吸收）。
- **`#4 单窗`**：主题行情 regime 依赖极强（如 2023 AI、2024 果链）。
- **`#6 样本/成分`**：anchor 事件稀疏；概念成分非 PIT → 幸存者偏差。

## 5. 预注册骨架（真要开时冻结）
- 事件：anchor 清单（如 NVDA/AAPL/TSMC…）的一类事件（财报超预期/出货上修/发布会）× 概念板块（成分）。
- 度量：**gap（T+1 open/prev_close）vs 盘中（open→close）vs 慢漂移（T+1..T+20）**分列——**只有慢漂移 >0 且跨窗一致才算**。
- 拒收线：慢漂移 long ≤0 或 <2/3 窗 → REJECT；gap 若占全部效应 → 同 `§一.14` 判死。
- 宇宙/PIT：声明成分快照偏差；不扫 anchor/窗口/概念。
