## 2. 极简设计原则（先立规矩，再动刀）

1. **一屏一问**：每页顶部只有一个"主问题 + 主答案"（Watchlist=今天做什么；回测=这套配方行不行；Dashboard=系统健不健康）。主答案用大数字（`text-4xl` tabular-nums），其余全部降级。
2. **三级信息层级**：`主数字/主结论` → `次级标签（小写灰）` → `辅助明细（默认折叠）`。卡片只允许承载一级或二级，三级一律进折叠/抽屉。
3. **去装饰**：默认无边框、无阴影、无卡片底色；用**留白 + 分隔线**分组。只有"需要用户行动"的块（红条、待办、告警）允许边框+底色。
4. **颜色配额**：中性灰为底，语义色只留四种——涨/跌（红涨绿跌中国市场习惯，全局统一）、告警（橙）、阻断（红）、成功（绿，仅确认态）。品牌色（accent）只用于交互焦点。
5. **术语统一**：中文优先；英文只留 symbol/ETF 代码/专有名词（S-3、C1、clip4）。侧栏全中文。
6. **动效克制**：只有状态切换过渡（150ms ease-out），无装饰动画。

## 3. 设计 Token（Tailwind v4 `@theme` 层）

在 `globals.css` 定一组 token，全部页面只准用 token 不准写裸值：

```
色板:   --bg（近白/近黑）、--surface、--line（分隔线灰）、--ink 1/2/3（三级文字灰阶）
语义:   --up / --down / --warn / --block / --ok
字号:   --fs-display(28-32) / --fs-title(16) / --fs-body(14) / --fs-label(12)
间距:   4 的倍数；页边距 24、卡片内 16、组间 32
圆角:   6px 统一（卡片 8px 上限），禁大圆角
```

现有 shadcn `ui/chart.tsx`、红涨绿跌已有约定 → token 直接映射，不重造。
