# 预注册：星舰稳健版 = a25 停车配比（H-SAT-A25 · 2026-09-21）

> **单假设 · 门槛跑前冻结。** 问：把星舰停车资产定为 **a25 = 25% 套筒 + 75% B3**，
> 是否**支配**纯 B3（A4_true）——即**每个窗收益更高、回撤不劣化**，从而成为可采纳的「星舰稳健版」？
> **关键词**：星舰 · 稳健版 · 停车配比 · a25 · 支配检验 · 预注册

## 0. 机制（冻结）

停车资产 = `0.25 × argmax 套筒 + 0.75 × B3 风险预算`（日频恒定权重，无再平衡成本）；
`port_ret_t = sat_ret_t + w_t × park_ret_t − 5bps × |w_t − w_{t−1}|`，`w_t = cashShare(T−1)` 因果。
卫星腿冻结（同 A4/A2 口径）。

## 1. 为什么开（背景 + 诚实披露）

- H-SAT-PARK-FRONT（同日价目表）发现**拐点 a≈0.25**：a25 long **+728.4% / CAGR 55.0% / MDD −6.9% / SR 3.49**，
  在**所有窗口**收益 ≥ 纯 B3（A4_true），回撤几乎相同。用户拍板把它作为「星舰稳健版」**并列**在现行星舰旁。
- **过拟合披露**：a25 来自价目表拐点（已见数）。缓解：判据按**"支配 A4_true"的机制先验**设定（见 §3），
  不按观测值反推；**加 holdout 描述**（不裁决）；结论**不覆盖**任何既有裁决。

## 2. 臂（冻结）

- **a25（主判定）** = 卫星 + `w_true` 停 `0.25×套筒 + 0.75×B3`，5bps/边。
- **A4_true** = 纯 B3（对照基准）。
- A2_true（纯套筒，上界参照）。

## 3. 判定（跑前冻死 · 支配检验 vs A4_true）

- **K1（每窗不劣）**：a25 三窗 `Δtotal` vs **A4_true** 全部 **≥ 0**。
- **K2（收益实质）**：a25 long `Δtotal` vs A4_true **≥ +50pt**。
- **K3（回撤不劣化）**：a25 long `MDD ≥ A4_true long MDD − 1.0pt`。
- **K4（效率不显著劣化）**：a25 long `Sharpe ≥ A4_true long Sharpe − 0.30`。
- **K5（仍属低回撤档）**：a25 long `MDD ≥ −10pt`（"稳健版"必须留在低回撤区）。
- **裁决**：**PASS = K1∧K2∧K3∧K4∧K5**；否则 REJECT。A4/A2 为对照。
- **锚点披露**：PASS = **产品候选（星舰稳健版）**，与现行星舰（A2_true 激进档）**并列展示**；
  **不进 Live**；落地需用户拍板 + Live 口径预注册 + paper 前瞻。

## 4. 死因预判（跑前写死）

- 主：**#7 单窗过拟合**——a25 若只在 long 加分、三窗挂 = 拐点是噪声。
- 次：**#4 regime**——25% 套筒把套筒的 regime 依赖带回一部分。
