# 预注册：稳健双子星 · 不对称择时版（H-ADAPT · 2026-09-12）

> **单假设 · 结构选择 · 门槛跑前冻结。** 用户目标：**强市保留双子星收益，弱市显著降回撤**。做法：按市况在"100% 双子星"与"转 B3 稳健核心"之间**不对称切换**。
> **关键词**：不对称 择时 回撤控制 强市保留 稳健双子星 预注册

## 0. 一句话机制（§四 S1）
双子星在**弱/震荡市**回撤大、强市收益高 → 用**缓慢外生/自身趋势信号**判断"强/弱"：强市 100% 双子星（不错过），弱市切 B3（低波对冲）→ 拿强市收益、削弱市回撤。

## 1. first-principles 自查（跑前，必答）
- **`§一.3 门稳定性律`**：外生门（市场截面）稳定；自指涉快门翻面。→ A2 用**外生**沪深300 门（稳）；A1 用**自身 NAV 趋势**（慢变量，`§四 S3` 允许但须长窗验证）。
- **对口反例 `DH-1×S-3`（REJECT）**：给 S-3 加"波动刹车"= 弱年帮、强年伤，无稳健三窗增益（双重减仓）。**本实验正是要正面回答：换"趋势开关 + 低波核心"是否也能过。** 若同一形状（强市伤、无三窗一致）→ 判死。
- **`#4 regime`**：切太勤会鞭打（强市回调误切）。

## 2. 口径（冻结）
- 两腿同 H-COMBO：T=双子星 clip4 opp_50，S=B3；共同日、日收益。
- **每日**判定目标权重（用 t-1 及之前，causal），**变动即计成本** `0.0005×2×|Δw|`。
- 窗口：OOS2/train/valid/**long 2021-01-05~2026-08-07**。

## 3. 结构（预声明 5 个）
| # | 规则（目标 w_T = 双子星权重） |
|---|------|
| T0 | 100% 双子星（基线） |
| T3 | 静态 50/50（参照） |
| **A1** | T 自身 NAV > 其 MA60(t-1) → w=1；否则 w=0（切 B3） |
| **A2** | 沪深300(t-1) > MA200 → w=1；否则 w=0 |
| **A3** | 同 A2 条件，但弱市 w=0.5（**软**切换，0.5 双子星 / 0.5 B3） |

## 4. 判定（冻结 · 用户目标）
- **K1 强市保留**：`valid` CAGR ≥ **0.8 × T0.valid.CAGR**（不能把强市收益砍没）。
- **K2 弱市降回撤**：`long` MDD **≥ T0.long.MDD + 10pt**（更浅 ≥10pt）**且** `OOS2` MDD 浅于 T0。
- **K3 全周期不劣**：`long` Calmar ≥ T0.long.Calmar **且** Sharpe ≥ T0.long.Sharpe。
- K1&K2&K3 → **可用不对称结构**；任一不过 → REJECT（同 `DH-1×S-3` 形状）。
- **不扫**MA 窗/阈值/软硬。

## 5. 死因预判（跑前写死）
- 主：**强市伤**（`DH-1×S-3` 同形）——趋势开关在强市回调里误切、错过反弹。
- 次：`#4 regime`、切太勤的鞭打成本。
