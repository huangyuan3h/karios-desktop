# 预注册：股东户数 / 筹码集中（H-GDHS-A · 2026-09-12）

> 跑前冻结。只读诊断。测最"深"的一层——**低频、滞后、少人交易**的筹码结构。

## 假设

**H-GDHS-A**：股东户数**环比下降**（筹码集中，散户离场/大户进场）→ 个股后续**正向超额**；户数上升（分散）→ 负/弱。

**一句话机制**：户数下降 = 筹码从分散散户集中到大户/机构，供给收缩 → 后续上涨（经典筹码集中因子）。它季度披露、几乎没人做事件交易 → 更接近信息链**首**。

**预判死因**：`#6 样本`（季度、滞后）；`#2 共线`（户数下降常发生在前期上涨后 = 动量代理）；`#4 单窗`。

## 冻结口径

| 项 | 值 |
|----|----|
| 事件 | `data/gdhs/gdhs.csv`（tushare `stk_holdernumber`，2021-01~2026-08，253,503 行；含 **ann_date 公告日** + end_date + holder_num） |
| 信号 | `chg = holder_num / prev_holder_num − 1`（prev = 同股上一 end_date）；桶：**强降 ≤−5% / 弱降 −5~0% / 升 >0** |
| 执行 | **ann_date 后首个交易日 T+1 开盘买**；持有 N=10/20/60 收盘卖 |
| 超额 | 个股 T+1open→close(T+1+N) − 中证500(510500) 同窗同期 |
| 宇宙 | 沪深（剔 BJ）；缺 prev 或缺 T+1 数据剔除；股本变动（送转）未单独剔除（声明） |
| 窗口 | OOS2/train/valid/**long** + 分段；对照组 = 户数上升 |

## 判定线（跑前冻结）

- **K1**：强降组 long `excess_20 > 0` 且 OOS2/train/valid **≥2 窗 >0**。
- **K2**：**强降 − 上升** 差值 long > 0 且 ≥2 窗 >0（剔除"前期上涨"共性后的净集中效应）。
- **K3**：三桶单调（强降 > 弱降 > 升）。
- **结论**：K1&K2&K3 → 开"筹码集中并入 S-3/核心"预注册；任一不过 → **REJECT 关线**（不扫阈值/N）。
- 分档/分段只读。

## 结果（跑后补）

**REJECT（耳语级正向）**：户数下降相对上升略好（N20 超额差 mean **+0.18%**、median 差 +0.40%），方向符合机制；但**绝对超额为负**、**不单调**（弱降>强降）、**60 日反转 −0.19** → K1/K3 FAIL。三条深源里唯一出现机制方向，但力度不够。见 [`gdhs-concentration-2026-09-12.md`](../backtests/inst/gdhs-concentration-2026-09-12.md)。
