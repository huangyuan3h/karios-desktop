# 预注册：H-SAT-AMP-CAP「14:30 窄幅进场」收紧（2026-09-24 · B22 · 只读诊断→引擎回放）

> **机制（S1）**：卫星要求 gap>3%，但**到 14:30 能否窄幅收住**决定后续 2 日——`gap-and-hold`（窄幅）继续走，`gap-and-chop`（宽幅甩动）fade。诊断证据（`diag_sat_entry.py`）：`corr(amp1430, contrib) = −0.175`，Q1（最低振幅）**+1.09%/胜率 74%** vs Q3–Q5 ≈ 0%/44%；分窗 −0.31/−0.29/−0.17；**同日截面去均值 −0.165**（非大盘时点效应）；与 gap 不共线（−0.05）。
> **现有策略已按 `amp1430` 升序取 top-1/3，残余梯度说明桶可再收紧。**
> **身份**：研究/展示档优化；Live 仍=港湾，本实验不改 Live。

## 判定线（跑前冻结）

- **K1 收益主门（G1a）**：臂的 `OOS2+train+valid` 合计 total ≥ 基线合计，且单窗不破 **−5pt**。
- **K2 长窗**：long total 不低于基线 **−5pt**，且 long MDD 不劣于基线 **+1pt** 以上，且 long Sharpe ≥ 基线 −0.15。
- **K3 右尾保留（G2）**：卫星**胜率下降 ≤3pt** 且**赢家均值贡献下降 ≤20%**（不能靠砍赢家换来"少亏"）。
- **裁决**：某一臂 K1&K2&K3 全过 → 该臂 **PASS（候选）**，取两臂中较优者；否则 **REJECT**。
- **L1–L7 前视门**：amp 用 `bar_5min ≤14:30`（无前视）；`max_amp_1430_pct=None` 为默认（Live 不传）；基期单一（raw/复权由引擎既有处理）；口径跑前写死。

## 结果（跑后补）

**H-SAT-AMP-CAP → 两臂均 REJECT（按冻结门），但臂 B 是明确的"降风险换降收益"选项。**

星舰 B 合成 NAV（卫星+停放）：

| 窗口 | base | A bq4 | B cap1.0% |
|---|---|---|---|
| OOS2 | +231.7 / −4.0 / 6.65 | +215.7 / −4.3 / 6.30 | +160.8 / **−2.7** / **7.19** |
| train | +51.8 / −8.2 / 4.02 | +51.8 / −8.2 / 4.02 | +57.7 / **−2.6** / **6.67** |
| valid | +4.1 / −10.0 / 0.54 | +4.1 / −10.0 / 0.54 | **+11.0** / −10.0 / **1.64** |
| long | +644.0 / −5.1 / 3.79 | +642.9 / −8.2 / 3.86 | +575.8 / −6.4 / 3.89 |
| 卫星 fills / 胜率 / 赢家均值 | 1080 / 54% / +1.46 | 972 / 56% / +1.46 | **628 / 60% / +1.60** |

- **臂 A（bucket_q 4）≈ no-op**：train/valid 逐数不变（池子小时 1/3 已取尽）、OOS2 **−16pt** → K1 FAIL；**REJECT**。
- **臂 B（amp≤1.0%）**：**K3 右尾保留 ✅**（胜率 54→60%、赢家均值 +1.46→+1.60 反升）、**valid/train/OOS2 回撤与 Sharpe 全面改善**（valid +4.1→+11.0、train dd −8.2→−2.6、OOS2 sr 6.65→7.19）；**但 long total −644→+576（−68pt）→ K1/K2 FAIL**。原因是**成交数腰斩**（1080→628），跳过的 amp>1% 那批均值仍微正，主要是"少下注 → 少复利"。
- **裁决**：按冻结的收益主门 **双 REJECT**。但 B 的性质是**降波动/降左尾换 ~11% 长期收益**（不是免费午餐）；若目标是"少亏/更稳"而非最高收益，B 是可讨论的防守档（须用户拍板风险偏好，不进 Live）。
