> 第一刀选 regime 配置腿。**定位 = 研究平行轨**，Live 双子星冻结，任何结果不改 Live 参数。
> 先过 `backtests/first-principles-2026-09-05.md` 自查（§0），再跑诊断（Phase 0），PASS 才谈回放（Phase 1）。
> **一句话**：不是给 S-3 加 gate，是换发动机——在两条不同收益源（趋势腿 / 慢价值腿）之间按慢市况配置。

**与已杀直觉的区别（必须成立否则不开）**：A1 / W1 / index-trend 都是"给 S-3 或指数本身加择时"；

若 Phase 0 证明"任何慢市况都分离不了 T/V 两腿"，则按 #3 关闭，不补网格。

## 1. 机制假设（原生一句话）

> 趋势腿赚 beta 扩张段（动量/小盘年），慢价值腿赚均值回归/防御段（价值/震荡年），
> 两者收益源互补；一个**外生、慢变**的市况信号能把资金切到当下更占优那条腿，
> 使 blended 风险调整后收益 **超过任何固定比例混合**。

依据：V1 价值 120/250d IC 为正（+0.14/+0.17）；V2 价值 excess 在 2021/2023 价值年为正、2025 牛年 −24pt，
与趋势腿 beta 依赖（trading-system §7.2 #8：Q2 +62% 超额 / Q3 −22%）形成互补形态。

## 2. 两腿定义与口径（跑前冻结，零网格）

- **宇宙**：A 股（SH/SZ），上市 >250 日、非 ST、非停牌、成交额 ≥ 0.7 亿（沿用 S-3 流动性门，切幻觉区）。
  **一律用 A 股 session 日历**（≥3000 家有 bar），禁用 `daily` DISTINCT date（V2 混合日历坑）。
- **趋势腿 T**：截面 `mom60` 排序 top decile 等权，**月末**调仓，持有下月。纯 factor portfolio，
  **不是 S-3/择强引擎**（刻意用最简代理，避免把生产选股栈混进来）。
- **慢价值腿 V**：V1 同款价值复合（EP/BP/SP/FCF-yield 等权 rank，PiT `ann_date` + 信号日总市值），
  top decile 等权，**季末**调仓，持有下季。四腿缺数据 fail-open（缺数票剔除，报告覆盖率）。
- **市况信号 R（单一，冻结）**：主口径 = `000300.SH` 收盘 vs 自身 MA200（月末 as-of）。
  `close ≥ MA200` → 风险偏好（T）；否则防御（V）。**MA 长度/指数不扫网格**。
- **禁用期**：`stock_dailybasic` 2023-12-29→2024-08-01 空洞段，市值中性相关口径必须回看或显式标注。

## 3. 阶段门（先诊断后回放，一门不过即关）

### Phase 0 · 风格分离诊断（本次唯一要跑的东西）

- 造 T、V 两条月度/季度收益序列（信号日收盘→下一调仓日收盘，含成本 T=30bps 双边、V=30bps 双边）。
- 计算 `spread_t = V_t − T_t`；按 R 状态分组，看 spread 的组间差是否有**方向一致**的分层。
- 输出：T/V 相关系数、各状态 n 与 spread 均值、三窗 + 长窗分段表、覆盖率、每期持仓只数。
- **Phase 0 PASS 线（跑前冻结）**：
  1. `corr(T,V) < 0.5`（两腿真不同源，否则 #2 共线）；
  2. `R=off` 段的 V−T 均值 > 0，且 `R=on` 段 ≤ 0（方向如机制所述）；
  3. 上述 2 在 `OOS2 / train / valid` 中 **≥2 个窗同向**，长窗（2018+）不反向；
  4. 两腿每期持仓 ≥15 只（覆盖过门，防 #7）。
- **任一不过 → REJECT/方向证伪**，关闭方向，不建 allocator、不扫 R 定义。

### Phase 1 · 配置回放（Phase 0 全过才开）

- Arm A（动态）：`R=on → 100% T`，`R=off → 100% V`。
- 静态基线：100%T、100%V、50/50、60/40、等权买持（A 股全市场）。
- 判据：动态 NAV **同时在 ≥2/3 窗跑赢最强静态基线**，且任一窗 tot 不劣于 −5pt、maxDD 不劣于 +5pt；
  长窗 Sharpe ≥ 最强静态。任一触发拒收即 REJECT。
- 只读 post-hoc 重混，**不改 S-3/twin 引擎、不加 `BacktestConfig` 字段**。

## 4. 必报审计数（第一行永远是覆盖）

两腿各期覆盖只数 / 财务四腿齐全率 / `stock_dailybasic` 空洞段影响行数 / corr(T,V) /
T/V 各自换手与夏普 / spread 按状态的 n 与均值 / 三窗与长窗分段 / 成本敏感性（30bps 与 60bps）。

## 5. 不做清单（防过拟合与扩 scope）

- 不扫 MA 长度、不枚举市况定义（触发/解除都写死单口径）；不调 decile、不调混合权重。
- 不给 S-3/卫星/择强任何现有引擎加 gate；不碰 Live 参数；不新建 S-3 三窗基线判长持有。
- 不用 `trade_calendar`（SSE 2023 起）做 2018+ 算术；不用 `daily` DISTINCT date。
- 财务只做价值腿输入，不做"质量+价值+动量"多腿拼装（那是后续独立假设）。

## 6. 裁决（Phase 0 已跑 2026-09-11 · REJECT/方向证伪）

脚本 `services/data-sync-service/scripts/incubate/regime_alloc_diag.py`（只读）。窗口 2021+。
**修正记录**：首跑把 regime 记在**持有月**且受 `stock_dailybasic` 空洞影响（OPT-156）；补洞 + 改为**信号月**
as-of（符合预注册"月末 as-of"）后重跑，结论翻转，以本版为准。

**结果（68 个月）**：
- `corr(T,V)=0.391 < 0.5` ✓（两腿不同源）——check 1 PASS。
- 分市况：`R=OFF` n=39 → spread(V−T) **+1.66%/月**；`R=ON` n=29 → **+0.15%/月**。
  → **两态都为正，ON 并未 ≤0**；regime 只"放大"V−T，不"翻转"它，机制所述互补切换**不成立**。
- 三窗：`OOS2`/`train` 无 OFF 样本（2024-09 起 300 一路在 MA200 上）；`valid` off −13.85 / on +4.22
  **反号**；`full` off +1.45 / on +0.15（同为负 check）。
- check 2（各窗 off>0 & on≤0）：**0/3**；check 3（≥2/3 窗同向）：**不成立**。

**结论**：`REJECT — 方向证伪`（比首跑的"样本不足"更强）。**T 在 2021–2026 两态都亏**（与动量毒性一致），
V 略优但两态同号，说明"按 300/MA200 切 T/V"没有可交易的 regime 翻转。
不建 allocator、不扫 R 定义、不进 Live。如需再验，须换**独立慢变量**（非 300/MA200）且有长市值史；本档关闭。
