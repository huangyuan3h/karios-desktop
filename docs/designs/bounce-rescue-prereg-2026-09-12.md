## 0. 一句话机制（§四 S1 必填）
国家队（汇金/证金经宽基 ETF）真金白银净申购 = 托底 + 情绪拐点 → 超跌区出现**数日**反抽；故"超跌 ∩ 国家队在买"日的**未来 3–5 日**指数收益应优于"超跌但国家队没买"。

## 1. first-principles 自查（跑前）
- `§一.14 宏观信息消费端律`：**不适用**（国家队=本地资金/政策，A 股时段兑现，属律中明列例外边界）→ 不因此自动否决。
- `§一.3 门的稳定性律`：本信号基于**市场截面**（指数+全市场 ETF 份额），非自指涉 → 地基成立。
- `§五 维8 市场状态`：已判"无 Live 级残余"→ 上限**候选级**，需 PASS+。
- 既有反证据（必须正视）：`candidate-c`（TIP-017 C）测 **20d/60d**：国家队加仓最狠 25% → 未来 60 日 **−2.95%**；份额 20dΔ 低分位（上涨中撤退）跑输；**唯一三窗同正 = 背离（两融↓+国家队↑）fwd20 +6.50/+3.30/+7.97（n=71/6/13，未过线）**。→ **几天（1/3/5/10d）尺度从未测**，本稿补这一格。

## 2. 宇宙 / 数据（冻结）
- 标的：**沪深300 指数 `000300.SH`**（`index_daily`，含 OHLC；ETF 代理退场，取指数收益）。
- 国家队份额：`cn_etf_share` **4 码**（`510300.SH/510500.SH/510510.SH/159915.SZ`），**逐码 forward-fill 后求和**（与 gate 一致，避免单码缺行假缩水）。
- 窗口：OOS2 2024-08-01~2025-08-01 / train 2025-08-01~2026-02-01 / valid 2026-03-01~2026-08-07 / **long 2021-01-01~2026-08-07**（份额 2018-06 起，20dΔ 已暖）。

## 3. 定义（冻结 · 全部信号日 T 用 ≤T 数据）
- `ma200(T)` = 000300 收盘 200 交易日 MA（用 T 及之前）。
- `below(T)` = `close(T) < ma200(T)`（超跌区 = 破年线，与 gate 同一市场条件）。
- `natD20(T)` = 总份额(T) − 总份额(T−20 交易日)。
- `nt_buy(T)` = `natD20(T) > 0`（国家队在买）。
- `crash(T)` = `below(T)` 且 `ret20(T) ≤ −5%`（次级口径，仅报告）。
- **入场语义**：T+1 **开盘**买 → T+1+N **收盘**卖（事件 T 盘后可知）；`ret_N(T) = close(T+1+N)/open(T+1) − 1`。
- N ∈ {1,3,5,10}，**主 N=5**（其余仅上下文，不选参）。

## 4. 分组
- **A = below & nt_buy**（用户说的"超跌 + 国家队救"）
- **B = below & !nt_buy**（超跌但没救）
- **增量 = A − B**（剥离"超跌"本身的均值回归，隔离国家队贡献）
- 参考：全样 A/B；`crash` 版 A/B（次级）。
- 另报**救市起手**事件（`natD20` 由 ≤0 翻 >0 且 `below`）的前瞻收益（描述性，样本极少）。

## 5. 判定（冻结）
- **覆盖门（§一.5）**：A 在 long 内事件天数 **≥ 30**，否则 #7 覆盖不足 → REJECT。
- **K1**：mean `ret_5(A)` long **> 0** 且 OOS2/train/valid **≥2/3** 为正。
- **K2**：mean `ret_5(A−B)` long **> 0** 且 **≥2/3** 为正。
- K1 & K2 皆过 → **候选**（市场级择时，仍需引擎回放 + 成本，不自动进 Live）。
- 任一不过 → **REJECT**；**不扫** N/超跌阈值/份额窗/ETF 清单/组合。

- 次：`§一.1 尺度匹配`（事件 vs 3–5 日噪声）、交易成本（事件级买卖）。
