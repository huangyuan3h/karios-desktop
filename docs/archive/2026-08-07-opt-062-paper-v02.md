# OPT-062：Paper v0.2 —— HK 接入 + 成本/滑点建模（todo §16 L3-P1）

> **完成日期**：2026-08-07
> **目标**：L3-P1 度量基座第一步——把 paper 从「理想口径」升级到「实盘可实现口径」。

## 决策要点

| 维度 | 决策 |
|------|------|
| 成本模型 | 分市场固定参数（单点可调）：CN 往返 30 bps（万2.5 佣金×2 + 卖出印花税 5bps + 滑点 10bps×2）；HK 往返 60 bps（0.05% 佣金×2 + 0.1% 印花税×2 + 滑点 15bps×2） |
| 口径重定义 | `pnl_pct` = **净盈亏**（gross − costs），仅平仓时一次性落地；open 行保持当日毛盈亏 |
| 触发口径 | stop/target 按**净盈亏**判定（保守，贴近实盘） |
| HK 接入 | HK bars 复用 `daily` 表（ts_code 如 `00700.HK`）；score_floor 对 HK 天然 fail-open（TrendOK 仅 CN） |
| 汇率 | **不做** FX 转换（系统无汇率数据源）→ L3-P3 精化项；HK PnL 按港币口径 |
| ETF | **不做**（TrendOK/评分语义未定义）；intake 记录为 out-of-scope skip |

## Schema（Alembic 0022）

- `market TEXT NOT NULL DEFAULT 'CN'`（legacy 回填 'CN'）
- `gross_pnl_pct`（legacy 回填 = pnl_pct）、`costs_pct`（legacy 回填 0）
- 索引 `idx_paper_trades_market`

## API 变更（向后兼容增量）

- `GET /v1/paper-trades`：新增 `market=CN|HK` 过滤；行模型新增 `market/grossPnlPct/costsPct`
- `GET /v1/paper-trades/stats`：新增 `market` 参数 + `byMarket` 分市场分桶
- `GET /api/decision/analysis`：`paper.byMarket` 分市场净胜率（决策 Agent 页展示）
