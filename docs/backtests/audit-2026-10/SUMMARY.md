## 2. 四份都没覆盖、但主人没想到的风险（第二审计员补位）

1. **策略拥挤（别人也在做同样的交易）。** S-gap>3% + 低波前 1/3 + 3 天持有是典型的短线反转/低波拥挤区；B22 已证“同日 4 只≈一个赌注”（n=4 全亏 2.6×独立、组内 std 0.49），但 A–D 都没讨论拥挤与 alpha 衰减。valid 起走平 + holdout 两腿同亏与“好做的钱变薄了”一致，但**无订单簿/换手拥挤指标，属假说**。**证据强度：弱。不确定。**
2. **监管与规则变化（涨跌停、印花税、T+1、首日不限涨跌）。** C 算了历史费率静态化 <1pt（`paper_cost_model.py:13` 印花 5bp since 2023-08、前身 10bp；`strategy-params.md:163` 佣金万2.5→万3），但没提**未来**：印花税再上调、T+1 交收冻结（A P2 已提示另计）、ST 5% 板两引擎**明确不建模**（`backtest_engine.py:96` 注释 "ST 5% is not modeled"）、BJ 30% 靠剔除免疫（一旦宇宙扩到北交所即失效）、注册制**上市首 5 日无涨跌幅未建模**且引擎无 `list_date` 年龄过滤（grep 零命中；DB 只读 `list_date>='2021-08-01'` 共 3132 只，扣 BJ 294/HK 516 后 **2322 只 CN 次新**，与 C P2-2 的 2322 互证）。gap>3% 天然偏好次新剧烈波动票，首日效应不可复制、可正可负。**规则缺口存在：强；影响多大：弱。不确定。**
3. **极端行情流动性（跌时卖不掉、14:30 print 本身被吃掉）。** C/D 讲了容量（≤500 万可用、2000 万过大）与 14:30 print 非 VWAP，但没讲极端日：冻结口径默认跌停可卖（`exit_skip_limit_down=False`，`state_bucket_track.py:820` 默认；HABIT 未设该键），603125（−14.67%，journal 实盘那只）注释里就是跌停实例；holdout −7% 市场里 −19% 说明跌时 14:30 流动性折扣与跌停顺延会被同时触发。小 utterances：日常尾部小、极端周单笔可差 −10% 级（C P1-3 原话，E 同意）。**证据强度：中。**
