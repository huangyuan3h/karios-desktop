# 舰队组合回测与防线分析（只读研究，2026-10-03）

## 摘要（5行）
1. 舰队从120万起步，长窗+163.6%，跑赢基地+27pt、沪深300+168pt，但输星舰B长窗约567pt（分散代价）。
2. 持有窗-8.4%，比星舰B的-19.1%浅10.7pt，和基地一样（复活闸全程关闭），略输沪深300的-7.3%。
3. 四条防线一共只收2.7pt长窗保险税，L1/L4从没触发过，L2/L3一年只触发几次，成本很小。
4. 港湾和母港相关0.998是同一个东西，不能各配一半；舰队和星舰只有0.16相关，是真分散。
5. 无条件中位378天到200万，弱市延续就到不了；结论是持有窗可以当缓冲垫，长窗别指望跑赢星舰B。

## 口径（先看这段，避免误读）
- 窗：OOS2 2024-08-01~2025-08-01（243天）、valid 2026-03-02~2026-08-07（110天）、holdout 2026-08-10~2026-09-30（37天）、long 2021-08-02~2026-08-07（1216天），和H2d日历一致，成本卫星32.28bp+月调5bp/边+50M过滤+sqrt150bp，起始120万。
- 舰队是单条长路从120万A档起步滚出来的，OOS2/valid/holdout是这条路上切出来的（valid起点已涨到287万C档偏保守，和H2j独立 fresh A档不同，差约17pt，已声明）。
- 星舰腿用50M信号日过滤（PIT，kept长592/1078、持有41/52，和H2b一致），120万套筒槽6万，引擎单腿槽30万，缺23笔用入门日兜底。
- 复活闸是H2k中间规则N40/X75（滚动40笔分位≥75且净>0给10%，再确认一次给20%，<50或熔断直接回0%，按比例从底仓扣，月执行，T-1无未来）。
- 防线：L1滚动60天-15%降一档，L2单笔-8%暂停新开一天，L3近5天-5%减半一天，L4-25%转现金直到窗末，外加已有50M/C1/涨停锁/跌停顺延（国家队闸休眠、数据链健康）。
- 百分比是窗首到窗尾总共赚亏多少，MDD是中途最深下跌，Sharpe是收益除波动，分位100%=打败全部随机。
