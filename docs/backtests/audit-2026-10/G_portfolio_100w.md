## 第一页结论（给非量化读者，一页看完）

**如果你只有一分钟，看这7行：**

1. **星舰 B 过去5年确实很赚钱（+730%，年化约55%），但最近7个月已经不赚钱甚至大亏。** 2026年3~8月只赚 +3.5%（和瞎买一样，50分位），8月8日之后 37天亏 −19.1%，比历史上任何37天都差（100%历史都比它好），也比同期大盘（−7.3%）多亏约12个点。老黄历很好，新答卷很差。
2. **“未来回撤10%以内、年化50%”作为未来预期，基本不可能。** 如果历史会原样重演，数学上回撤超10%的概率只有 0.02%~0.6%（`g_bootstrap.json`）；但历史不会原样重演——最近的 valid 已触及 −10%、holdout 已 −19.8%，也就是说**过去7个月里“超10%回撤”已经发生了两次**。条件概率（最近是熊/震荡+两腿同亏）下，未来1年再出现超10%回撤的概率大于 80%，年化50%的中位预期应下调到 **10%~20%（乐观）或 −20%~+10%（延续弱势）**。详见 §0.7。

4. **本次试的5个新方向（小市值、ETF动量、低频择时、业绩预告事件、可转债）没有一个能进推荐组合。** 小市值 OOS2 +276%但 valid −38%（崩盘）；ETF动量最好一档 valid 仅 +3.5%（5个月样本，Bonferroni后 p≈1.0）；择时3档全负；业绩预告 OOS2 每笔 +2.6%（t=23）但 valid 每笔 −4.3%（t=−21，反向）；可转债双低数据缺失（DB无转债表，只有 `pg_conversion` 内部表），指数调入缺权重表，都没法跑——缺什么、怎么补见 §2。

## 2. 适合100万的新方向（每个先预注册假设与网格再跑，train/valid/holdout+多重校正+随机/基准对比）

### 2.1 小市值/微盘因子（含流动性门槛）

- 预注册假设： circ_mv最小 quintile + 日成交≥阈值，月频等权，下月持有，能跑赢中证500 BH且扣费后正期望。网格：topN {30,50} × 日成交 {2000万,5000万}（4试验，`stock_dailybasic.circ_mv` + `daily.amount` PIT月末截面，信号T收盘→下月持有，成本32bp/月）。
- 结果（`g_small.json`，26个月）：N30_A2000 OOS2 +276.0%/2.48、train −1.9%/−0.07、valid **−38.5%/−4.96**、holdout −5.4%；N30_A5000 +227.4/train −3.4/valid −44.8/holdout −5.5%；N50两档同向（OOS2 +179~+233%、valid −37~−39%、holdout −0.1~−3.2%）。Bonferroni N=4：valid负向显著（t≈−3.2，p≈0.02但为负）、正向p=1.0。vs基准：OOS2超500（+30.6%）但valid跑输500（−7.8%）30pt、holdout与500（−7.4%）相当。
- 裁决：**REJECT（观察）。** OOS2的高收益是2024-08~2025-08微盘反弹窗口的单 regime 产物，train即归零、valid崩盘，邻域（30↔50、2000↔5000万）同向崩，holdout未改善。失效条件：月频等权在valid式 −30%ail再现即确认不可用。数据缺口：无（`stock_dailybasic` 2021-01-04起可用），但需补停牌/涨跌停过滤（本 pilot 未做，上偏，不确定）。

### 2.3 ETF动量/行业轮动
