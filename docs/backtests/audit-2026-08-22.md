## 5. 验证过程（四阶段）

### Phase 0 — 冻结与基建（1-2 天，不改数字）

4. `walk_forward_*.json` 输出 `Wilson CI / bootstrap CI` 与 `⚠️ n<100`

### Phase 1 — 执行可复制性重固化（2-3 天，三窗重跑）
1. 分支 `fix/execution-realism` 依次合入：`sum<=1.0` → `min_avg_amount 0.7亿` → `trading-day` → `entry next_open`
2. 每步 `PYTHONPATH=src python3 scripts/run_walk_forward.py --windows OOS2,train,valid,holdout,long` 三窗+holdout+长窗同屏，`>5pt` 拒收
3. 预期：`totalNet` 下修 10-25%，`DD` 下修，`Sharpe` 回落至 3-5 区间，更贴近 `rolling_oos` 近期 `-0.6%`

### Phase 2 — 数据可信度补丁（并行，1-2 周）
1. 行业 `as_of` 或至少周度快照；universe 加 `delist_date` 过滤或分段披露
2. `long` 拆 `long_price_only(2021-08~2024-07)` vs `long_full(2024-08~2026-08)`，env 仅后者考核
3. HK 基线统一 qfq 后 `270.2/26.9/60.6`，旧 `86.9` 归档

### Phase 3 — 统计纪律与 hold-out 确认（3-6 个月，自然等待）
1. `holdout` 积累 `n≥100` 前不调参，`neutral_block/auto/D2/D3` 在 hold-out 复验（leave-one-regime-out：去电子训/电子测）

### Phase 4 — B-T1 TrendOK 配方扫描（hold-out 通过后）
1. 限 `w_ema/w_macd/w_vol/flow/momentum` 5 旋钮×3 值≤15 次，业务故事先行
