# DH-1 × S-3 股票腿：波动率刹车叠加（Phase 0 · 2026-09-11）

> **问题**：能否把 **定海（DH-1）** 的优势（组合级波动率刹车）接到 **双子星 S-3 股票腿**上？
> **脚本**：`scripts/incubate/dh_hybrid_s3.py`（只读）。**定位**：Phase 0 诊断，不改引擎、不进 Live。

## 1. 方法

- 取 S-3 引擎日频 NAV（`BacktestRun.nav_curve`），对日收益叠加：
  `scale_t = clip(target / realized_vol_{<t}, 0, cap)`，`cap=1.0`（只减不增，无杠杆）。
- 已实现波动只用 **t 之前** 的历史（无前视）；`win∈{20,60}` 日、`upd∈{1,5,21}` 日更新一次；
  暴露变动按 `2×10bps×|Δscale|` 计成本。
- **判据**：Sharpe 与暴露缩放无关（常数缩放不改 Sharpe），故 **ΔSharpe>0 = 真有择时价值**，非单纯降杠杆。

## 2. 结果（三窗 + 长窗；ΔSharpe vs S-3 基线）

S-3 基线：OOS2 **+46.5%**/vol34.6%/DD−15.4%/sr1.26 · train **+34.4%**/27.2/−9.7/2.26 ·
valid **+38.7%**/32.4/−9.4/2.41 · long **+94.5%**/25.4/−28.1/0.64。

| 配置 | OOS2 ΔSh | train ΔSh | valid ΔSh | long ΔSh | 备注 |
|------|----------|-----------|-----------|----------|------|
| win60/upd1/t10 | **+0.71** | −0.38 | −0.19 | +0.16 | 弱年大赚，强年亏 |
| win20/upd1/t10 | +0.56 | **−0.87** | −0.03 | −0.05 | 最不稳 |
| win20/upd21/t10 | +0.11 | +0.50 | +0.37 | +0.01 | **全窗非负**，但=大降杠杆 |
| win20/upd21/t15 | −0.00 | +0.50 | +0.16 | +0.03 | 同上 |

完整 48 组见运行输出。**方向在窗口间翻转**：日频更新在弱年 OOS2 大赚、在强年 train 大亏；
月频（upd21）虽四窗非负，但总收益被砍（OOS2 46.5→28.9、长效），Sharpe 增益 +0.1~0.5 在 ~90 笔样本内属噪音量级。

## 3. 裁决：**REJECT（Phase 0）—— 不与 S-3 股票腿结合**

1. **无稳健三窗增益**：没有任何单一配置在三窗同时改善；效果随市况在正负间翻转（弱年帮、强年伤）。
2. **"全窗非负"那条只是降杠杆**：`target=0.10` 把平均暴露压到 0.7×，绝对收益几乎腰斩；
   而 S-3 的三窗验收闸是**绝对收益（±5pt）**，降杠杆必然"劣化"，不可能过闸。
3. **机制重叠**：S-3 已有 regime 闸门 + 回撤熔断 −25 + `env_position_scale`（D3）——弱市本就降仓，
   再叠一个市场波动刹车是**双重减仓**，正是弱年有效/强年失效的来源。
4. 与既有结论一致：S-3 的 `atr_size_*`（个股波动率目标仓位）此前已 **三窗一致劣化、弃用**（`strategy-params.md` §4）。

## 4. 更合理的"结合"方向（若继续）

不是给 S-3 加刹车，而是**两条腿做组合**：定海 DH-1 当**低波 beta 核心**（+7%/yr、DD−28%、
与 S-3 相关性低），S-3 当** alpha 卫星**，在**总组合层**做风险预算/波动率目标。
这属于新的 sleeve 组合设计，需单独立预注册三窗验证——本档只否定"直接叠加"。

**状态**：REJECT（Phase 0）· 脚本保留 `scripts/incubate/dh_hybrid_s3.py` · 见 [SUMMARY](SUMMARY.md)。

## 5. 多方案结合（Phase 0 · `scripts/incubate/dh_combine.py`）

不止"叠刹车"，另试 4 类组合（DH-1 用**无前视**日频 NAV，S-3 用引擎 NAV + `positions_by_day` 实际暴露）：

- **S1 固定配比**：`w·DH1 + (1−w)·S3`，w∈{0.3,0.5,0.7}
- **S2 风险平价**：按 60 日滚动波动反比配权
- **S3 闲置资金入 DH-1**：S-3 未投的现金改赚 DH-1 日收益（`r3 + idle_prev·r_dh`）
- **S4 仅深跌时停 DH-1**：S-3 暴露<50% 时闲置资金才入 DH-1

| 窗口 | S-3 单独 | S1 w0.3 | S1 w0.5 | S2 风险平价 | S3 闲置→DH1 | S4 停 DH1 | corr |
|------|---------|---------|---------|------------|-------------|-----------|------|
| OOS2 | **+46.6% / sr1.26** | +34.4 / 1.25 | +26.2 / 1.21 | +19.2 / 1.16 | +43.1 / 1.16 | +41.7 / 1.14 | +0.50 |
| train | +34.6 / **2.27** | +30.0 / **2.55** | +26.8 / **2.71** | +22.3 / 2.53 | +38.5 / 2.22 | +39.0 / 2.30 | +0.32 |
| valid | **+38.7 / 2.42** | +23.8 / 2.07 | +14.4 / 1.58 | +6.5 / 0.83 | +24.4 / 1.47 | +24.8 / 1.50 | +0.20 |
| long | **+94.5 / 0.64** | +52.5 / 0.53 | +27.7 / 0.38 | +5.2 / 0.14 | +46.8 / 0.41 | +51.2 / 0.43 | +0.33 |

**结论**：**S-3 单独在 OOS2/valid/long 三个窗口的 Sharpe 都最高**；只有 train 的配比组合略高
（2.27→2.55/2.71）但 valid 崩到 2.07/1.58——**不满足三窗一致**。闲置资金入 DH-1（S3/S4）
在所有窗口 Sharpe 都低于 S-3 单独（OOS2 1.26→1.16、valid 2.42→1.47、long 0.64→0.41），
因为 DH-1 在有效市场暴露为负会**恶化回撤**（OOS2 DD −15.4→−16.9、valid −9.4→−19.2）。

**叠加根因**：DH-1 本身已被证伪（前视偏差，见 [a1-voltarget-beta](a1-voltarget-beta-2026-09-11.md) §1），
且 S-3 是高 Sharpe alpha（1.3–2.4），与一个 Sharpe≈0 的 beta 混合**只会稀释**——
没有免费午餐。**多方案结合也 REJECT。**

**结论（DH-2 版）**：

4. **没有任何方案在四窗同时胜出**；本质是"S-3 高 Sharpe alpha + beta 稀释"，选择只在
   **要 Sharpe（选 S-3 单独）** vs **要某窗降波动（选配比，但强窗掉收益）**之间，不存在免费改进。

## 7. DH 作**方向指引**：指数趋势 → 收紧止损（2026-09-11 · 信号层结合）

用户设想：DH（指数趋势）当**涨跌方向指引**，"有时让止损更严格"。引擎加默认关闭的
`trend_guide_code / trend_guide_ma / trend_guide_stop_pct / trend_guide_trail_pct`
（`backtest_engine.py`；指数跌破 MA 时**只收紧** exit 线，`max(stop_i, tight)`；as-of 收盘判定）。

| 指引 | OOS2 收益/夏普 | train | valid |
|------|---------------|-------|-------|
| 关（基线） | +46.5 / 1.26 | +34.4 / 2.25 | +38.7 / 2.40 |
| 000905 MA200 → trail−5/stop−3 | +46.5 / 1.26 | +34.4 / 2.25 | +38.7 / 2.40（**几乎不触发**） |
| 000300 MA200 → trail−5 | +46.5 / 1.26 | +34.4 / 2.25 | +38.7 / 2.40（同上） |
| 000905 MA60 → trail−5 | **+38.4 / 1.09** | +34.4 / 2.25 | +38.7 / 2.40 |
| 000905 MA20 → trail−5 | **+31.6 / 0.96** | +31.9 / 2.10 | +39.9 / 2.58 |
| 000905 MA60 → trail−4/stop−3 | **+34.8 / 1.02** | +34.4 / 2.25 | +39.3 / 2.47 |

**结论：REJECT。**
1. **慢均线（MA200）几乎不触发**——指数跌破 MA200 的那些天，S-3 的 regime 闸/熔断**早已让它空仓/防守**，方向指引冗余。
2. **快均线（MA60/MA20）确实触发，但在 OOS2 明显劣化**（46.5→38.4/31.6）——收紧止损**砍掉了会反弹的右尾**，
   正是仓库反复出现的 **#2 死法（防守收紧 → 截断右尾）**。
3. valid 有一点点改善（+0.6pt）、train 无变化 → **三窗不一致**，不构成采纳。
4. 引擎钩子**默认关闭保留**（零行为变化，355 引擎测试通过），仅作能力备用；不建议进 Live。
