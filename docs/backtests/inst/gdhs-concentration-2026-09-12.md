# H-GDHS-A：股东户数 / 筹码集中（2026-09-12 · REJECT 含微弱苗头）

> **一句话**：24.5 万个股东户数披露事件做前瞻诊断——**户数下降（筹码集中）确实相对户数上升好一点**（N20 超额差 **+0.18%**，中位数差 +0.40%），方向符合机制；**但绝对超额为负**（N20 各桶 mean/median 均 ≤+0.8/−0.5）、**不单调**（弱降 > 强降）、**60 日反转为负**（diff −0.19）→ K1/K3 FAIL → **REJECT**。即"深层次正向"在这条上**只有耳语级、不够格**。
> **关键词**：股东户数 筹码集中 深层次 前瞻超额 弱正向 REJECT

**预注册**：[`designs/gdhs-concentration-prereg-2026-09-12.md`](../../designs/gdhs-concentration-prereg-2026-09-12.md)
**脚本**：`scripts/sync_gdhs.py`（253,503 行）· `scripts/diag_gdhs.py`
**口径**：`chg = holder_num/prev−1`；ann_date 后首个交易日 T+1 开盘买、持有 N 日；超额 vs 中证500。桶 = 强降 ≤−5% / 弱降 −5~0% / 升 >0。

**读法**：户数下降相对更好（mean/median 差 +0.2~0.4%/20d，方向对），**但**：
- 所有桶 N≥20 的 **median 全为负** → 典型个股跑输中证500（事件池偏小盘）；
- **不单调**（弱降 > 强降）；
- **60 日反转**（diff −0.19）。
均值全靠右尾。

## 2. 分窗（excess_20，强降/升/差）— ⚠️ 均值不可靠

| 窗口 | 强降 | 升 | 差 |

train/valid 的 −25/−7 是**离群/数据伪影**（ST/退市/复权跳空，均值被拖爆），不可采信；中位数口径无此现象。**K1（绝对正、≥2 窗）FAIL**（valid 无强降样本）。

## 3. 判定

| 线 | 结果 | |
|----|------|---|
| K1 强降 long>0 & ≥2 窗 | long +0.36 但 WF 仅 1 窗 | ❌ |

| K3 三桶单调 强>弱>升 | 弱降 > 强降 | ❌ |

**→ REJECT / 关线。**

## 4. 读法（对"深层次正向"的意义）

- **方向对了，力度不够**：筹码集中确实**相对**正向（~+0.3%/20d），是三条深源里**唯一出现机制方向**的——但**绝对为负 + 不单调 + 60 日反转**，做不成策略。
- 只差在**幅度**：要变成可交易，需要更强的条件（如"强降 + 户均持股市值上升 + 无送转"）——但那是**扫参/组合**，本预注册冻结不做，且大概率撞 `#2 共线/过拟合`。
- 三条深源现状：龙虎榜机构（REJECT，链尾）· 股东户数（REJECT，耳语级正向）· 大宗交易（未跑）。
- **可能真"深"的只剩大宗交易/机构专用席位**，但预判同族。

## 5. 边界
- 未剔股本变动（送转）与 ST；train/valid 均值受离群污染（已用中位数交叉核）。
- 事件池偏小盘 → 相对中证500 系统性负超额，绝对收益口径需另设基准。
