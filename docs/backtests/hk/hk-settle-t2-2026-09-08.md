# HK T+2 交收现实化（2026-09-08 · 实验 · Live 策略不动）

> **一句话**：用户提出港股卖出资金 T+2 才可用，要求回测按真实场景重跑。引擎新增实验开关 `settle_lock_sessions`（默认 0，CN 冻结），HK 三窗 `--param settle_lock_sessions=2`：**OOS2 +31.3→+7.7（−23.6pt，未通过）/ train +1.9→+0.3（−1.6）/ valid +60.7→+66.4（+5.7）**。结论：交收是换手税——吃掉弱市年高换手的 21 笔回收，牛市慢磨段无伤（笔数相同 44→44，回撤 27.8→17.0）。策略不换，期望重置 + paper 缺口挂账。

## 0. 口径（用户拍板）

- 锁定范围：**卖出资金冻结**（闲置资金不受影响），整户/单票锁定皆否。
- 天数：**T+2 可用**（卖周一 → 周三可用，周二冻结；若券商实际更晚，改参数重跑一行命令）。
- 范围：**只动 HK**，A 股保持现状（单变量）。

## 1. 实现

- `BacktestConfig.settle_lock_sessions: int = 0`（<0 非法；默认 0 = 冻结行为，bit-identical 已验：valid 窗 flag0 与默认逐数一致 60.676/44 笔）。
- `simulate()`：`settled_cash` 账本（初值 1.0）+ `pending_settle`（usable_idx = exit_idx+N，当日开盘前释放）；entry/pyramid 走 settled 检查（`settle_lock` / `settle_lock_pyramid` 计数进 `gated_blocks`）；exit 只记 `nav_cash`（NAV 含在途资金，曲线口径不变）。
- 覆盖 entry / exit / pyramid；swap 在本引擎不走现金（HK swaps 本来就关）。
- 单测 3 个（T+2 咬合：B 进场日 2→4；非法值；默认 0 守卫），`test_backtest_engine.py` 115 全绿。

## 3. 机制

- 交收冻结专杀**换手依赖型收益**：OOS2 基线 99 笔高回收，冻结后少 21 笔（−23.6pt）；回撤跟着降（钱被迫闲置）但收益塌得更多。
- valid 是慢磨型赢家（44 笔一笔不少，只是进场顺延），冻结反而滤掉加仓噪音：回撤 27.8→17.0，收益 +5.7。
- train 本就弱（+1.9→+0.3）：HK 线真实期望比展示更薄。

## 4. 实盘指导（策略不动，期望与执行动）

1. **期望重置**：HK 线对外展示用基线， heart 里用 realistic——弱市年 +7.7 不是 +31.3，train 约等于 0。HK 不作高置信叙事（原有结论加强版）。
2. **弱市降换手**：冻结 + 高换手 = 双杀。HK 弱市年别追短信号、少做 pyramid 加仓（pyr 拦截 OOS2 达 73 次），与"弱市少动"同向，无需新规则。
3. **paper 缺口（挂账 OPT-148，不今天改）**：`paper_s3` HK intake 没有 settled 账本，会开出真券商买不起的仓（paper 偏乐观）。真执行以券商可用资金为准；C4 对照 HK 时记住这层乐观偏差。
4. **不改事项**：HK 参数（trail-12/RS0.6/hold60）、择强逻辑、CN 线（settle=0 冻结，逐数验证过）。

## 5. 方法论沉淀

- 换手摩擦律（→ first-principles §一.13）：无现金账本的回测按即时再投资计，真实交收下高换手策略打折；伤换手年、放过慢磨年（回撤同降）。
- 若券商确认可用日晚于 T+2：`--param settle_lock_sessions=3` 重跑三窗即可，无需改码。

## 6. 附加：滑点 +0.2（2026-09-08 同日加测）

- 背景：费用模型里 HK round-trip 本来就是 A 股 2 倍（60bps vs 30bps：佣金 5+5、印花 10+10、滑点 15+15bps）；用户要求引擎 `slippage_pct` 0.05→0.25（+0.2pt）再测。注意这是**成交价滑点**（与费用模型里的滑点 bps 是两套账，叠加吃）。
- `--param settle_lock_sessions=2 --param slippage_pct=0.25`：OOS2 +4.6（−26.7pt）/ train +0.2（−1.7）/ valid +65.2（+4.5）。相对 settle-only 再掉 −3.1/−0.1/−1.2——**主杀伤仍是交收（−23.6），滑点是添头**；valid 44 笔一笔不少（胜率 40.9→34.1，成本把边缘笔翻负）。
- 结论不变：未通过（OOS2 −26.7pt）。

## 7. 重调 R1：pyramid 关（2026-09-08 · REJECT）

- 动因：加仓腿 = 完整 round-trip + 占交收，OOS2 已被拦 73 次；单 binary 旋钮，机制最干净。
- 杀线（跑前冻结）：相对现实版（§6）三窗不劣化 >5pt，且 valid 慢磨笔数不塌。
- `--param settle_lock_sessions=2 --param slippage_pct=0.25 --param pyramid_max_adds=0`：
  OOS2 +8.8/61（vs 现实 +4.6/76，+4.2pt 但少 15 笔）/ train −1.4/33（−1.6）/ valid **+43.5/37（−21.7pt，少 7 笔）**。
- **REJECT**：valid 杀线直接命中。加仓腿与主腿同进退，关掉改变整条资金路径（7 笔主腿进出亦变化），不是单纯"省成本"；OOS2 的 +4.2 是"少做少亏"（胜率反降），不是 edge。
- 相对冻结基线更是 −22.5/−17.2pt，双重拒收。R2/R3 见 §10（已关闭，不跑）。
