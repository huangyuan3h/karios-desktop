# MACD × 趋势 关系研究（2026-08-24）

> 问题：`MACD 12-26-9`（`DIF=EMA12-EMA26` / `DEA=EMA9(DIF)` / `Hist=DIF-DEA`）在上升/下降趋势中是否有 edge？方法同 `§22.7` 与 `bollinger-trend-study`：`ahead 10d` 分层，`n≥500` 采信。

## 口径

- **MACD**：`12-26-9` 标准；信号 `金叉 (DIF上穿DEA)` / `死叉` / `DIF>0 bull` / `Hist>0`。
- **趋势**：`trend_up = MA20>MA60`（`down = MA20<MA60`），样本 `2023-01-01~2026-08-21`。
- **标的**：
  - **多资产 ETF** `518880/513350/513100/511260` 单资产 `10d` 回放
  - **CN A股** `liquid1500`（`2024-07 avg vol Top1500`）聚合 `1.14M` 票-日 `base +0.76% win47.5%`（`up 0.54% / down 0.94%`）

## 与既有结论的复核

- `P5 金叉 / P6 三线多头` 已 `❌ 拒收`（`C3/C5/C10 + 长窗灾难`），`P4 斜率` 全劣化，本次 `MACD` 是同一家族的第三次独立验证：**动量加速度类在 `S-3` 的 `RS` 短期转强 + 主线 `beta` 已占满后无正交 edge**（`backtests/SUMMARY.md` 48次失败同向）。
- `bollinger-trend-study` 已证 `趋势×%b` 为噪音（`up+骑上轨 +0.73%≈base`），`MACD` 趋势×信号亦为噪音（`±0.5%` 内），**形态/动量加速度层在 `CN` 上天花板已现**。

## 结论（记录）

1. **MACD 无意义**：`金叉 +0.47%`、`Hist>0 +0.35%` 为 `CN` 最强，但 `win≈49% median≈0`、`excess<0.5%`，**不达 `>5pt` 票决与 `win>70%` 杠杆线**，且 `趋势×MACD` 无加成（`up+金叉` 反弱于 `down+金叉`）。
2. **不进系统**：不纳入 `S-3` 参数表（`§19` 封闭）、不改 `multi_asset_sleeve`（`mom60+MA200` 仍最优）、不做 `MACD金叉` 新策略。
3. **唯一观察**：`油 down+Hist<0 +1.8% win72% n111` 与 `CN down+金叉 +1.30% win50%` 为标的特定超跌反弹，可作提示层，但 `n<150` 小样本且 `median` 偏低，不加仓。
