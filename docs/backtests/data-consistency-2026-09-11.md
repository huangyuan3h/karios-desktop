# 数据一致性重建：CN daily 复权统一 + 长历史回填（2026-09-11）

> **一句话**：生产 `daily.close` 曾是「标准前复权 + 陈旧基准 + 原始未复权」的混合体，
> 跨期收益会在除权日跳变（000001 在 2021-01-04 真实 −3.83% 被算成 **+3.46%**，方向反）。
> 本轮统一为 **2007–2026 单一前复权基准**，全市场一致性 99.8%→100%。
> **关键词**：数据质量 qfq 复权基准 回填 长历史 P0-12 前提

## 1. 问题（怎么发现的）

做长持回测时，日线回填 2007–2020 与库内 2021+ 拼接不上。反推每行隐含复权基准
（`implied_base = raw × adj / db_close`）：

- 000001：2021 行基准 ≈129、2024 行 ≈147.5、当前应 139——**基准在时间轴上乱跳**；
- 全市场同日比对：中位 ratio=1.0，但仅 **60.5%** 在 ±0.5% 内；
- 尾部 ratio 高达 8（**北交所 920xxx**）：库里 `close` 直接等于原始价，复权没应用。

**排除 qfq/hfq 之争**：`daily.close` 最新值=原始价，锚在最新日期，是前复权口径；
问题是**执行层**（陈旧基准未随分红重算 + 部分行根本没复权 + 多次导入拼接）。

## 2. 修复（三步）

| 步骤 | 内容 | 量 |
|------|------|-----|
| 回填 2007–2020 | tushare raw+adj，qfq=raw×adj/latest，upsert | 837 万行 |
| 重建 2021–2026 | 同基准重算，替换旧混合值 | 706 万行 |
| 修 59 只离群 | 退市/停牌旧行 + 北交所，逐票全历史重刷 | ~15 万行 |

**统一口径**：`qfq_price(t) = raw_price(t) × adj_factor(t) / adj_factor(latest)`；
`pct_chg/vol/amount` 不变，`open/high/low/close/pre_close/change` 同比例缩放。

## 3. 验证

- **边界连续**：000001 2020-12-31 `15.4501` → 2021-01-04 `14.8589`（**−3.83%**，修正前 +3.46%）；
- **拆股连续**：BYD 2025-07-29（3:1）`110.596→111.004`（+0.37%，无断裂）；
- **全市场**：5 个抽样日期离群数 **40/34/18/8/8 → 0**；2024-07-15 100% 在 ±0.5%。
