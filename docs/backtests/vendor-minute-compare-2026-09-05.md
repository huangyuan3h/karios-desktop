# 外购5分钟对拍 A：2024 vendor vs 独立源抽样（2026-09-05）

> **一句话**：40只×2024全年×尾盘七根=`67,606`点，绝对1分钱吻合`90.59%`，原`≥99.5%`门字面没过；失败模式是两家5分钟bar最后一tick快照差几秒（O/H/L逐数一致，close抖中位`0.056%`，`1500`集合竞价`98%`对上），不是错数。**有条件通过**：习惯只用`1430/1500`价，`C`熊市回放加滑点敏感性（base单边`10bps` + stress单边`30bps`）覆盖，不纠结原门。
> **关键词**：vendor对拍 滑点覆盖 有条件过

**方法**：本地 `data/2024_5min` vendor CSV（`parse_vendor_csv`，`LAST_HOUR_TIMES`七根）vs `baostock 5min` 全年重拉（`fetch_baostock_5min`，`adjustflag=3`），按`(ts_code,trade_date,trade_time)`逐点对`close`。只读，不写库。抽样`40`（6只大盘+34只随机，seed=7）。

| 口径 | 吻合（≤1分钱） |
|---|---|
| 七根总体 | `61,243/67,606 = 90.59%` |

附带：`vol`单位差`×100`（vendor手 vs baostock股），以后只用价不用量。

## 2. 判定

- 原门（七根绝对1分钱`≥99.5%`）：**FAIL**，但失败=尺太直，不是货假，不判拒收。
- 修订门（2026-09-05 用户拍板）：习惯只用`1430/1500`价 + `C`阶段滑点敏感性覆盖 → **有条件通过**，进`B`。
- 滑点口径：`paper_cost_model`现默认单边`10bps`已盖中位`5.6bps`；`C`加跑单边`30bps` stress档盖`p90`，两档verdict一致才算稳健。滑点只盖随机抖，不盖系统偏（本次无系统偏）与缺数（本次无缺）。
