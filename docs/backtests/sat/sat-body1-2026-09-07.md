# 卫星持有 1/2 天 vs 3 天（2026-09-07）

> **一句话**：习惯口径（14:30 买/收盘卖、无 C1）只改 `body`，`body=2` 相对 `body=3` OOS2 **−17.8** / train **−2.4**（夏普全差、回撤全差）→ **REJECT/total**；`body=1` 与 `body=2` 逐数一致——引擎每日先扫退出后做买入，同日卖不可表达，`body=1` 退化为次日收盘卖。valid 未碰（复用预算），Live 不动。
> **关键词**：机会双子星 body=1 body=2 持有期 截右尾 同日退出退化

**方法**：`services/data-sync-service/scripts/compare_sat_habit_clock.py` 同 harness（window-local 空簿、clip4、strict `skip_t1`、当天缺口 + `FILL_SAME_1430` 14:30 买、收盘卖、核心冻结择强 trail8、`opp_50`），`VARIANTS` 覆写为 `body∈{3,2,1}`，`WINDOWS` 覆写为 OOS2+train（valid 不碰），无 `--save-report`（只读筛查，未落盘 JSON，数取运行终端表）。
**口径差声明**：本筛查无 C1、退出=收盘（非 Live 习惯 `C1 3% + 第 3 日 14:30 卖`）。C1 历史增量（OOS2 约 +14 / train 约 +8，两侧同向）不足以翻转 OOS2 −17.8；train −2.4 缺口仍在。要翻案需在 C1 口径重跑，本次关闭方向，不补跑。

## 2. 为什么 body=1 == body=2（引擎语义，非巧合）

`state_bucket_track.py` 日循环每日**先扫全部持仓退出、后做当日买入**：当天买入的票当天不可能卖出。`held = ci − ei + 1`，`body=1` 的票最早次日收盘才能 `body_exit`——与 `body=2` 同路径（fills/NAV 逐数一致即证据）。用户设想的"14:30 买→当天收盘卖"日内单在此引擎不可表达；且连隔夜版都塌，无需为日内单开新引擎分支。

## 3. 读法（与路径表互证）

- `sat-hold-path-day2-2026-09-03.md`：整日 open→close 的 d1 均值仅 +0.02~+0.21%（不含 0.3% 往返成本，扣完必负），三窗 `d1<d2<d3`，右尾在 d2/d3。砍到 1–2 天 = **截右尾（死因 #1）** + 周转×2 成本×2。
- 旧网格 `body∈{2,3,5}` 选出 body=3（`state-bucket-algo-2026-08-31.md` §R12 网格行）；`body=4` 占槽税 `aligned −16pt`（`sat-habit-clock-2026-09-03.md`）。本刀补上 1/2，持有期邻域搜尽，维持 body=3。
