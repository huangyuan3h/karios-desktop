# 卫星成交日历：冻结 T 开盘 vs 当日收盘 vs 14:30（2026-09-03）

> **一句话**：你的习惯 = **当天缺口 + 约 14:30 买 + 第 3 日收盘卖**。用真 14:30 价三窗后：相对冻结 9:30 **REJECT**；相对核心 OOS2 仍赚、**train −3.3 / valid −10.9**，valid 卫星腿 **−1.4%**。收盘代理比 14:30 好看，是因为缺口票 14:30→15:00 往往回吐。Live / 冻结引擎都不变。下一刀是 14:30 **入场过滤**（C1），不是改成早盘买。
> **关键词**：机会双子星 S-gap `fill_mode` next_open same_close same_1430

**脚本**：`services/data-sync-service/scripts/compare_sat_fill_same_close.py`

## 3. 读法

- **14:30 真价比收盘代理差。** 同一套名单，买在 14:30 比买在 15:00 差一截 → 缺口票最后半小时往往回吐，14:30 更容易买在当日偏高处。
- **习惯日历收不到冻结那条 9:30 边。** valid 上冻结卫星 +18.1pt，14:30 习惯 −10.9pt。
- **OOS2 单窗仍好看**（1430 twin 仍 +47 vs 核心），不能当方案。
- **下一刀 C1 已跑**：[sat-entry-c1](sat-entry-c1-2026-09-03.md)。3% 过滤修好夏普/回撤，valid 总收益仍 −3.3，不进 Live。
