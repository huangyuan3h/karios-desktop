## 1. 假设与口径

- **假设（用户）**：固定 3% 对低波票太松/太紧、对高波票相反 → 分层后应出现「calm 被误伤（Δ>0）、wild 买错（Δ<0）」的稳定结构。
- **宇宙**：重建冻结严格桶 = S-gap `open/pre_close−1 > 3%` → `amp_1430` 升序前 1/3 → R-wide 14:30 闸（`_breadth_at_1430`，OPT-224 覆盖率回退）→ 剔 T-1 涨停锁。
- **C1 输入**：`run = 14:30 raw print / raw open − 1`（qfq 日线按 `raw_1500/qfq_close` 重建 raw，与引擎同基期）。
- **远期**：`14:30 T → 14:30 T+2` 净 `COSTS_ROUNDTRIP`（body=3，入场日 = 持有第 1 天）。
- **分层**：每窗内按 `vol = 前 20 个交易日 (high−low)/close 均值` 分 calm/mid/wild 三档（严格因果，不含决策日）。
- **对账**：重建的 C1 跳过数与引擎 blotter 逐窗一致（557/558 · 63/63 · 106/107 · 820/821，差 1）。
- **性质**：诊断，只测量；不扫阈值、不改 Live、不落表。

## 2. 结果

### 2a. 跨窗 Δ(跳过 − 保留) 净收益（>0 = C1 砍掉的票平均比留下的更能赚 = 候选「误伤」）

| 窗口 | calm（低波） | mid | wild（高波） |
|---|---:|---:|---:|
| OOS2 | +1.61 (n319) | +3.27 (n155) | +1.58 (n83) |
| train | +1.00 (n22) | +0.24 (n16) | **−1.21** (n25) |
| valid | **−0.38** (n22) | +1.78 (n29) | +0.41 (n55) |
| long | +0.73 (n404) | +1.76 (n202) | +1.27 (n214) |

- calm Δ：+ / + / **−** / +（valid 翻负）
- wild Δ：+ / **−** / + / +（train 翻负）
- 唯一三窗全正的 mid 层，train 仅 16 笔、幅度 +0.24~+3.27 乱跳 → 噪音。

### 2b. run–收益曲线（四窗同形 · 与波动率无关）

各波动率层内，`0–1%` run 档都最好（约 +1.4~+3.4%），`2–3%/3–4%` 最弱（常为负），`>4%` 小样本、符号乱。C1 的 3% 线正好切在弱区起点，但同时也砍掉 `4%+` 偶尔正收益的尾。

| run 档 | 四窗共同形状 |
|---|---|
| 0–1% | 最好 |
| 1–2% | 转平 |
| 2–3% | 走弱（calm/mid 为负） |
| 3–4% | 最弱区 |
| 4–5% / 5%+ | 小样本、非单调、符号跨窗乱 |

### 2c. 顺带反例

若硬看，OOS2/long 里 **calm 的保留池反而比 wild 差**（kept fwd −1.92/−0.96 vs wild −0.56/+0.25），与「稳定票被误伤」直觉正好相反；train 又反号。

## 3. 判定

**REJECT（假设证伪）。** 分层没有显示稳定的波动率结构：Δ 符号跨窗翻面，属 first-principles §一.9（波动率非因子：OOS2 高波最赚、holdout 高波全亏）+ §三 #4（单窗过拟合）的典型形状。C1 的问题不在波动率维度，而在「run–收益本身非单调」这个与波动率无关的形状上；该形状也不足以推翻已冻结的 C1=3%（`sat-c1-grid` 平顶 + §六 参数平台律：现任者 + 不折腾）。

**不新增波动率维度；C1 维持 3%；Live 零改动。**
