## 4. 判定

- **不证伪，不调参**：−5.1 落在 p5 之内（−5.53），是约十四分之一的坏月份，不在分布外。40% 的月份 twin 本来就跑输核心——这就是 +2.7 valid 缓冲 + 高方差卫星的真实形态。
- **真正的风险是方差，不是均值**：单票 12.5% NAV、4 槽，坏月份 −5pt 就是常态分布的一部分（~7% 概率）。跟随层面要按“一年里会遇到几次 −5pt 月”来预期，不是一直赢。
- **卫星对冲腿定位的注脚**：本窗卫星加大了回撤（twin dd 8.7 > core 4.1），与“卫星降回撤”的长期叙事相反——短窗里噪音主导，对冲属性只在长窗统计意义下成立，不要按月考核卫星。
- holdout 窗随数据增长每月可重跑（只读），满 60 sessions 再看一次；在此之前不作为任何调参依据。
