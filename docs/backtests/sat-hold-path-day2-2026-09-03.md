# 卫星持有路径：第 1 / 2 / 3 日收盘 vs 成本（2026-09-03）

> **一句话**：冻结 clip4、T 开盘买、第 3 日收盘卖。全体均值 **d1 < d2 < d3 往上走**；但第 2 天收盘仍亏的票，第 3 天 **多数回不到绿**（13–25%），大约一半只是减亏。这是路径观察，**不改 Live**。−5% 早停仍以 [sat-exit-trail](sat-exit-trail-2026-09-03.md) 三窗 REJECT 为准。
> **关键词**：机会双子星 S-gap body=3 第2天 收盘路径 回本
> **脚本**：`services/data-sync-service/scripts/sat_hold_path.py`  
> **原始表**：`data/backtest_reports/sat_hold_path_day2_2026-09-03.json`

口径：window-local 空簿、卫星冻结 clip4（4×25% · strict `skip_t1` · body=3）。只统计 **完整拿满 3 天** 的 `body_exit`。标记 = `当日收盘 / T 开盘 − 1`，**不含** 0.3% 往返成本（中间日没有成本事件）。

---

## 0. 为什么测

一阶段 B：[sat-entry-filter-phase1](../designs/sat-entry-filter-phase1-2026-09-03.md)。问题是「第 2 天亏了，第 3 天回不回」——用来理解 3 日脉冲，**不是**新的卖出规则。Live 成交仍是约 14:30；本表是回测 T 开盘路径。

---

## 1. 全体：平均还在往第 3 天走

| 窗口 | 完整 3 日笔数 | 均 d1 / d2 / d3 | 收盘≥0 占比 d1 / d2 / d3 |
|------|----------------|-----------------|--------------------------|
| OOS2 | 270 | **+0.21 / +1.03 / +1.97%** | 69.6 / 57.8 / 56.3% |
| train | 124 | **+0.20 / +1.00 / +1.53%** | 61.3 / 62.9 / 58.9% |
| valid | 52 | **+0.02 / +0.70 / +1.28%** | 61.5 / 55.8 / 55.8% |

三窗均值都是第 1 天小正、第 2 天再加、第 3 天再加。胜率第 3 天并不比第 1 天高（OOS2 甚至从 70% 掉到 56%）——赚的是 **少数票把均值拉上去**，不是「越拿越容易绿」。

---

## 2. 第 2 天收盘仍亏 → 第 3 天怎样

| 窗口 | d2 仍亏 | 占成交 | 第 3 天翻红 | 第 3 天比 d2 好（减亏或翻红） | 这组的均 d3（翻红 / 仍亏） |
|------|---------|--------|-------------|------------------------------|---------------------------|
| OOS2 | 114 | 42.2% | **25.4%** | 56.1% | −2.19%（+2.49 / −3.79） |
| train | 46 | 37.1% | **17.4%** | 50.0% | −3.46%（+1.29 / −4.46） |
| valid | 23 | 44.2% | **13.0%** | 69.6% | −2.58%（+2.12 / −3.29） |

读法：

- **「第 2 天亏了第 3 天会翻红」不是主流**（valid 只有约 1/8）。
- **「再拿到第 3 天，一半以上会比第 2 天收盘好」** 成立（减亏），但这组整体第 3 天均值仍是负的。
- 全体均值还能升，靠的是 **第 2 天已经绿的票继续跑**，不是靠亏票大翻盘。

所以：不能从这张表推出「第 2 天收盘亏就卖能提高卫星收益」。那会锁死减亏段，也动 4 槽周转；要改退出必须另开三窗，且 −5% 已经 REJECT。

---

## 3. 和第 2 天前已触及 −5% 的关系（对照，不是新实验）

「d1 或 d2 收盘相对成本 ≤ −5%」：

| 窗口 | 笔数 | 占成交 | 其中第 3 天翻红 | 这组均 d3 |
|------|------|--------|-----------------|-----------|
| OOS2 | 19 | 7.0% | 15.8% | −5.33% |
| train | 11 | 8.9% | 0% | −6.10% |
| valid | 3 | 5.8% | 0% | −5.73% |

这些票拿到第 3 天，平均仍在 −5% 附近，**很少翻红**。这和「−5% 后大面积拉回」的直觉不完全一样。

**不因此重开 −5%。** [sat-exit-trail](sat-exit-trail-2026-09-03.md) 的 `body+protect5` 是 **引擎里真的提前平仓**（valid twin **−14.9pt**）：会换槽、会改后面所有成交，不是「同一批票再看一眼 d3」。本表只描述冻结路径上同一批成交的收盘标记。protect 还可能在第 3 天收盘抢在 body 前触发，笔数也会比这里的 6–9% 多（那次 OOS2 约 41/298）。

---

## 4. 结论（给一阶段 B）

| 问题 | 答案 |
|------|------|
| 3 日脉冲的均值在哪一天兑现？ | 三窗都是 **d3 最高**，d2 已经比 d1 好 |
| 第 2 天亏了会不会在第 3 天翻红？ | **多数不会**（13–25%） |
| 第 2 天亏了再拿一天有没有用？ | 大约一半 **减亏**；这组均值仍负 |
| 要不要第 2 天亏就卖 / 重开 −5%？ | **不要**；退出仍 body=3。要测新规则走三窗 |

Live 这 4 只仓的「第 2 天」和本表不可比：实盘是 14:30 买，回测是次日开盘。
