## 0. 为什么改：旧口径的四个漏洞

| # | 漏洞 | 实例 |
|---|------|------|
| V1 | **踩线 PASS 无制度**：`worst Δ ≥ −5` 是 0/1 门，−4.9 与 −0.1 同算"过"，无余量概念 | 星港 1/3 valid Δ −4.9 踩线 PASS，数据一漂（−7.6）即挂——运气，不是鲁棒 |
| V2 | **小窗与大窗同权**：valid（n=55）一票否决权 = OOS2（n=237），且 valid 已被复用 ≥4 次（选择压力） | 双子星/H-SAT-W 两次死在 valid 单窗 |
| V3 | **长窗/holdout 不进裁决**：long 只"补充"、holdout 只"确认"，主裁决只看三窗；古代 regime（2021–23 熊市）的风险信息进不了门 | 母港 long MDD −11.6 vs 港湾 −22.8 的腰斩证据在旧门里只是"观察" |
| V4 | **只看收益、无兑换价目**："用少量收益换回撤/Sharpe"靠拍脑袋，无价格、无上限 | M50（−85pt 换腰斩）与 C1（修 Sharpe 但 tot −3.3）用同一套语言讨论 |

| train | 2025-08-01 ~ 2026-02-01 | dev 调参窗 |

## 2. G0 预注册门（不变，仍是前提）

单假设、零网格、拒收线跑前冻结、一句话机制、预判死因类（first-principles §三 #1–#7）、L 门逐条 tick。
G0 不过 → 不开跑。

## 3. G1 收益主门（收益最重要：先过收益，再谈别的）

- **G1a 加权合计**：`mean(OOS2Δ, trainΔ, validΔ) ≥ 0`（等权均值：可审计、无需新数据；
  精度差异由 G1b/G3b/holdout 吸收，不另加权）。
  - `G1a ≥ 0` → 收益干净（继续往下走）。
  - `−3 ≤ G1a < 0` → **赤字通道**：只能走 G2 兑换（§4），上限条件PASS。
  - `G1a < −3` → **REJECT**（收益是爹：C1 式"风险修好、收益仍负超 3pt"到此为止，v2 不救）。
- **G1b 单窗地板（hard，任何兑换都不能补）**：OOS2/train/valid 任一窗 `Δ < −5` → REJECT；
  `long Δ < −5` → 标准通道 REJECT（转保险通道 §6）。
  - 地板数值维持 −5（"而不是 5%"指的是**不再只有 5%**，不是放宽 5%）。
- **G1c 长窗确认**：`long Δ ≥ 0` 为干净；`[−5, 0)` → 条件PASS（古代 regime 容忍带，仅 informational 不致死）。
- **G1d 余量门（V1 的制度化）**：任一 binding 窗余量 `< 2pt`（即 `Δ < 地板 + 2`）→ **上限条件PASS**。
  踩线（−4.9）与干净（−0.1）从此是两种裁决，不再是运气。
- **G1e 休眠保险子类**：`|G1a| ≤ 0.5` 且行为覆盖 ≈0（零拦截/零换手改变）且 `long Δ > +10`
  → **PASS（休眠）**：平时零行为、只在古代 regime 生效的"睡着的保险"（国家队闸先例）。

## 4. G2 风险兑换门（少量：有价、有上限、有代价）

仅当 G1b/G1c 地板全过（地板是命，兑换买不了命）：

| 条款 | 数值（v1 默认，可调） |
|---|---|
| 赤字上限 | G1a ∈ `[−3, 0)` 才可兑换；超 −3 不谈 |
| 价格 | 每 1pt 收益赤字 ⇔ `long ΔMDD ≥ +2pt` **或** `long Δsr ≥ +0.08`（任一腿支付即可） |
| 未购买腿 | 容忍带内不劣化：`ΔMDD ≥ −0.5pt` 且 `Δsr ≥ −0.02`（测量噪音带，非放水） |
| 兑换上限 | 兑换通道的裁决**上限 = 条件PASS**（花了收益，就必须经 holdout/paper 确认，不给干净 PASS） |

刻意不对称：小额兑换从优（1:2），M50 级大额买保险从严（§6 保险通道另议，
M50 隐含价 ≈ 7.7pt 收益 / 1pt MDD）——防止"千刀万剐"式 tactic 漂移，也防止大交易 sneaking 过自动门。

## 5. G3 一致性 / 稳健门

- **G3a 符号一致**：≥2/3 dev 窗 `Δ ≥ −0.5`（−0.5 为中性带；单窗过拟合只有"valid 好看+选参窗崩"一个形状，first-principles §三元结论 #3）。
- **G3b 铰链规则（V2 的制度化）**：去掉任一 `n<100` 窗后裁决翻转 → 上限条件PASS。
  小样本窗可以参与 passing，不可以**单独决定**干净 PASS。
- **G3c 样本地板**：`n<30` 窗 → 描述不判定；`n<100` 标 `underpowered`（维持旧纪律）。
- **G3d 成本敏感性**：2 倍成本重跑，G1a 仍 `≥ −1` 且 G1b 地板不破（B 系 20bp/15bps 检查的统一版）。
- **G3e valid 复用计数（V2 的制度化）**：valid 每被用作**选择窗**一次 +1；
  `复用 ≥ 3` 后新候选**上限条件PASS**（选择压力下的过拟合税）。
  - **起算**：v2 生效时 valid 复用 = **4**（README 已记"n=55 已复用 4 次"）→
    所有新候选上限条件PASS，直到 holdout n≥50 或窗口重切（重切 = 新预注册 + 用户拍板）。

## 6. 双通道：标准 vs 保险

- **标准通道**（S-3 参数、单机制、overlay 小权重）：G0→G1→G2→G3→L（§8），全过出裁决。
- **保险通道**（M50 式：花大钱买风险结构）：`long Δ < −5` 或赤字超 3pt 的候选**不走自动门**，
  必须：预注册明示"买保险" + 收益代价/风险对价双披露 + **用户拍板资本结构** + paper 3/20。
  M50（long −85pt 换 MDD 腰斩 + Sharpe 全升）是本通道的已走完先例，其冻结 K1–K5 + 用户决策继续有效。

## 7. 裁决档与转正（移动球门禁令）

| 裁决 | 含义 | 去向 |
|---|---|---|
| **PASS** | 硬门全过 + 处处余量 ≥2pt | 产品候选（进 Live 仍需 paper 3/20 + 用户拍板） |
| **PASS（休眠）** | G1e | 固化为例行保险，不进收益叙事 |
| **条件PASS** | 余量/兑换/铰链/复用/long[−5,0) 任一触发 | **上限**：holdout（n≥50，`Δ ≥ −2` 且无破地板）或 paper 确认后转正；转正前**不进产品/落地讨论、不进 Live** |
| **REJECT** | 任一硬门挂 | 方向关闭（重开需新预注册 + 写明为何值得重开） |
| **VOID** | L 门（§8）任一挂 | 无效实验：数字作废，不是 REJECT（REJECT 是诚实数值，VOID 是口径事故） |

> **禁令**：本标准只管 2026-09-16 之后的新预注册。已冻结文档的 K1–K5 判据与其 PASS/REJECT
> 是当时的诚实裁决，不追溯重判（b3-cap"不改判据"先例）。

## 8. L 门：前视杜绝（blocking，挂一条 = VOID）

每条 = 内容 + 执行 + 测试锁。预注册必须逐条 tick，实验文档必须逐条贴证据行。

- **L1 时点宇宙**：窗口内用的任何 symbol/名单必须在**窗口起点可构造**
 （`as_of listed_date` / listed_history；禁 `trade_date >= end` 式窗后选择）。
  新回放脚本必须显式带 market 过滤 + 印分桶金额分布表（first-principles §二.7）。
  锁：`TestHkContainmentOPT147` 模式 + 新脚本 unit 断言（OPT-213 推广）。
- **L2 成交因果**：每个 fill 价格的时间戳 ≥ 决策时间戳（`next_open` 建仓当日不可出场；
  14:30 print vs 收盘；T+1 规则；qfq/raw 见 L4）。
  **新成交/退出语义必须自带合成幽灵交易探针**（`test_engine_entry_timing.py` 模式：信号日买次日价、
  当日价反向大波动 → 断言零成交/零 PnL）。
- **L3 数据不倒灌**：决策时数据（live 14:30 prints、scores）**永不**被事后回填覆盖。
  回填默认 `on_conflict=nothing`（只补缺）；读侧做 source 分级（live > vendor 回填）。
  锁：`test_bar_5min.py` 三断言模式（OPT-212 已立）。
- **L4 基期单一**：qfq 系列永不对 raw 水平（涨停价/成交价/委单）直接比较；
  混合研究必须先 `raw = qfq × adj_latest / adj` 重建 + **先贴匹配数 sanity**（逐日匹配数 vs
  已知口径如涨停家数，远小于先停跑查基期、后看 PnL，first-principles §二.8）。
- **L5 口径冻结**：report 必须记录**数据版本**（关键表行数 / vendor 分布 / bar_5min 覆盖 /
  git tag + baseline sha）；漂移归因走 **stash 反事实协议**（旧代码在新数据上重跑：
  同漂 = 数据问题，不同漂 = 代码问题——OPT-212 星港 valid 漂移即此协议定案）。
- **L6 日历市场**：双市场日历检查（HK-only 日期不得加速 CN 腿，OPT-183）；
  凡抄 `_load_rows` pattern 必带 market 门。
- **L7 可复现**：一命令复现 + report JSON 落盘 + valid 复用计数 +1 记录。
