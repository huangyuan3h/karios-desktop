# 券商月度金股前瞻（broker_recommend · 只读诊断 · 2026-09-24）

> **来源**：2026-09-24「外部信号为何不是一个级别」讨论 → 探针现 token 可取的文本/共识数据，
> 此为其一（免费）。**机制先行（first-principles §四 S1）**：券商月度金股 = **公开共识注意力**，
> 与研报覆盖 / 人气榜同族 → 预判 #2（被注意力维度吸收）或 #4（regime 不一致），
> 即**追高税**。
> **判定：❌ REJECT（方向反 + 无单调正向）**。

（无三窗一致；弱年负、强年微正 = #4 regime 特征）

**共识度梯度**（同月被几家券商推荐）：

| tier | 均值超额 | n |
|------|---------|---|
| 1 家 | −0.26% | 9,697 |
| 2 家 | −0.57% | 1,588 |
| **3+ 家** | **−0.71%** | 734 |

→ **单调负**：被推荐越多的票越跑输。注意力越集中，拥挤度税越重。

## 3. 裁决：❌ REJECT（追高税 · 死因 #2 家族）

- 正向用法（买券商金股）**死**：均值/中位/胜率/月份胜率四项全负，无窗口正向。
- 共识梯度是**干净的单调负**，但反向用法（避开高共识票）**不开**：
  ① HARKing 禁区（同一数据先看结果再定方向）；② 与现有人气榜/研报同族，组合已有结构吸收；
  ③ 冷门/低关注票落流动性门外（门外溢价律 §一.11）。
- 家族收口：**注意力/共识类（研报覆盖、人气榜、券商金股、趋势卡）第四次同向负结果**，
  确认「注意力峰值 = 追高税」为跨源稳定规律。

## 4. 边界

- 等权 A 股基准含大量小市值票；券商金股偏大盘 → 部分负超额可能是 size 效应，不是纯注意力。
  但即便换中证500 基准方向仍为负（大盘推荐集中度不足以解释单调梯度）。
- 只读诊断，不进回测/预注册/Live；数据与脚本留作资产（未来「拥挤度反转」假设需独立预注册）。
