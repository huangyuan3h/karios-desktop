## 3. 11 条 CANDIDATE 其实是**一个因子**

逐条展开公式，全部是**价量相关性/协方差的反向**：

| 因子 | 形式 | 取反方向 |
|------|------|----------|
| A13 | `−rank(cov(rank(close), rank(volume), 5))` | 价量协方差越低越买 |
| A16 | `−rank(cov(rank(high), rank(volume), 5))` | 同上（用 high） |
| A44 | `−corr(high, rank(volume), 5)` | 同上（不 rank、用 high） |
| A15 | `−Σ₃ rank(corr(rank(high), rank(volume), 3))` | 同上（3 日、平滑 3） |
| A26 | `−ts_max(corr(ts_rank(vol,5), ts_rank(high,5), 5), 3)` | 同上（取 3 日最大反转） |
| A50 | `−ts_max(rank(corr(rank(vol), rank(vwap), 5)), 5)` | 同上（用 vwap） |
| A55 | `−corr(rank((close−minₗ)/(maxₕ−minₗ)), rank(volume), 6)` | 同上（位置×量） |
| A3 | `−corr(rank(open), rank(volume), 10)` | 同上（开盘×量） |
| A6 | `−corr(open, volume, 10)` | 同上（不 rank） |
| A2 | `−corr(rank(delta(log vol,2)), rank((c−o)/o), 6)` | 量增×日内涨，反向 |
| A27 | `sign（corr(rank(vol), rank(vwap), 6) 的分位）` | 同族弱化版 |

**一句话机制**：价量同向（放量上涨）在 A 股 5 日尺度上倾向反转 → 买"价量背离/缩量"的票。
这与仓库的 `vol20` 负 IC、`P2 放量突破全拒`、`强股勺型耗尽` 同源，属 `first-principles §五` 的**价量/波动维度**。
11 条高度共线（同一维度的不同窗口/字段变体），因此 **L0 的有效独立因子数 ≈ 1**，不是 11。

## 4. REJECT 的结构

- 90/101 拒收。典型死法：
  - **单窗过拟合 / 方向翻转**：多条在 OOS2（弱市年）IC 很漂亮、valid 转负或归零（A4、A19、A69、A76、A94、A66…）。
    这是 `§三.4` 的固定形状，不是 regime 机会。
  - **零方差/二值**：比较类因子（A61/A62/A64/A65/A68/A74/A75/A79/A81/A84/A86/A95/A99）大量输出 0/1，
    有效截面少、IC 接近 0。
  - **纯粹动量/反转**：A101 日内实体（IC +0.003）、A33（IC ~0）、A4 `−ts_rank(rank(low),9)` 等，无稳定增量。
- 换手是全局问题：候选家族日均换手 0.4–0.9，成本 30bp/往返 → 日成本 ~0.12–0.26%，5 日 ~0.6–1.3%，
  系统性高于毛价差。

## 5. 对"识别因子何时有效"的回答（本轮证据）

用户的核心问题是"大多数时候没用、有用时识别并交易"。本轮给出两个可复用的判据：

1. **三窗 ICIR 同号** 能筛掉绝大多数噪音：90 条里很多在单窗 |ICIR|≥0.5，但跨窗翻转（`§三.4`）。
   真正三窗同号且 |ICIR|≥0.5 的只有 **A13/A16/A44/A26/A15/A50/A3/A6** 这一个家族。
2. **统计活着 ≠ 可交易**：这 8 条即使三窗稳，也全部死在成本门（净价差 < 0）。
   **"因子有效"必须从第一步就带换手/成本**，否则会把 11 条幻影当成发现。

→ 本轮的答案倾向于：**对 Alpha101 做 regime 择时（L2）没有意义**——先解决"有没有独立于成本的信号"，
再谈"何时开"。唯一可能值得的后续是 **A13/A16 家族的正交化（L1）**：看它是否独立于 S-3 的 RS/主线/桶，
但毛价差 ~0.4%/5d、换手 0.66–0.69 的结构下，**大概率仍是不可交易**。

### S1 · 正交化结果（A16，h=5）

逐日横截面 OLS 取残差（含截距），三窗重算：

| 阶段 | 控制变量 | ICIR OOS2/train/valid | 残差 IC OOS2/train/valid | 净价差 OOS2/train/valid |
|------|----------|----------------------|--------------------------|--------------------------|
| raw | — | +0.65/+0.96/+0.79 | +0.052/+0.057/+0.046 | −0.0070/−0.0061/−0.0032 |
| S1a | size + 流动性 | **+1.03/+1.15/+0.88** | +0.056/+0.053/+0.042 | −0.0047/−0.0065/−0.0051 |
| S1b | + 反转/动量/波动 | +0.66/+0.91/+0.70 | +0.031/+0.036/+0.031 | −0.0085/−0.0081/−0.0071 |
| S1c | + 行业固定效应 | **+0.79/+0.98/+0.65** | +0.029/+0.033/+0.021 | −0.0093/−0.0088/−0.0092 |

（A13 复算：S1c = +0.71/+1.07/+0.65，与 A16 同形，结论一致。）

### 解读

1. **不是 size/流动性代理**（推翻头号死因）：S1a 去掉 size+流动性后 ICIR **不降反升**（0.65→1.03 等）。
   说明原始因子里混着小/低流动性噪音，剥离后信号更干净。
2. **不被动量/反转/波动吸收**：S1b 后仍 0.66–0.91，稳过 0.5。
3. **不被行业吸收**：S1c 后 0.65–0.98，三窗同号、全部 ≥0.5。
4. **但成本门依旧不过**：每一阶段净价差都为负——正交化让统计更纯，**不解决换手**。
   这是"统计存活 ≠ 可交易"的教科书案例。

### 判定（预注册 kill 线）

- S1a/S1b：任一窗 `|ICIR| < 0.3` → 未触发。
- S1c：三窗 `|ICIR| ≥ 0.5` 且同号 → **`SURVIVOR`**（有资格进 S2，不等于可交易）。
- **更新定位**：Alpha101 家族的 **A16/A13 是独立于已知维度的真实统计信号**（S1 SURVIVOR）；
  作为**可交易 alpha 仍是 REJECT**（净价差 < 0）。
- **下一步（需单独预注册）**：S2 只测三件事——非重叠/拉长持有降换手、long-only tilt、
  或作为核心选股内部 tie-breaker（不增换手）；任一出三窗净价差转正才谈组合层。
  禁止直接把它当独立多空腿或 regime 开关。
