# G1：现金流含金量 + 市值中性（P0-11 · 预注册 · REJECT 2026-09-11）

> **来源**：P0-11 带控制重验第一项（F2 的市值中性版，独立预注册 H-G1）。
> **一句话机制**：F2 原始信号弱可能被规模效应淹没（2024Q2 小盘暴动）——组内中性化后见真章。
> **死因预判**（跑前）：中性化后仍弱（#3），或规模组间翻面（成分效应）。

## 1. 方法（跑前冻结）

* 每季按流通市值（`stock_dailybasic.circ_mv`，信号日快照）分 5 组，组内算
  RankIC / Q5−Q1，等权 pooled；只看 pooled 数，不挑组（挑组 = 网格）。
* PASS 线：pooled meanIC > 0；pooled Q-spread 为正 ≥60% 季；pooled |corr(mom)| < 0.5。
* 脚本：`scripts/diag_fin_g1.py`（`fin_panel.load_mv_map/mv_asof` 复用）。

## 2. 诊断电池（20 季，2020Q4–2026Q1；2024Q1 因组内 n 不足剔除）

* pooledIC **+0.026**（原始 +0.016 → 中性化确有改善，但仍是噪音级）。
* pooled Q-spread 为正 **50%**（10/20 ✗）。
* max pooled |corr| = 0.20 ✓；ccr–size 相关仅 0.06–0.19（轻微大盘偏）。
* 组间无一致翻面，但也无一致正向——各季 pooled spread 在 ±5 内摇摆。

## 3. 裁决：REJECT

中性化把 IC 从 0.016 抬到 0.026，方向对但量级不够，Q 线纹丝不动。
**规模不是 F2 弱的主因**——关闭该分支，不试 total_mv / 分组数等变体（网格禁区）。
