# F1：ROE-TTM > 行业中位数（P0-11 · 预注册 · REJECT 2026-09-10）

> **来源**：P0-11 财务质量计划 F1（P15 质量因子首项）。单假设、零网格、拒收线跑前冻结。
> **一句话机制**：高质量公司（高 ROE）基本面更稳，持有 60 天应跑赢同行——防守 gate 候选。
> **死因预判**（跑前）：#2 被 RS/主线吸收，或 #3 方向证伪（A 股高 ROE = 拥挤高估值）。

## 1. 数据与口径

* 三表 `cn_balance_sheet / cn_income_stmt / cn_cashflow_stmt`（2018Q1–2026Q2，5461 只，migration 0044）。
* ROE-TTM = 归母净利 TTM（单季拆分后 4 季滚动）/ 近 4 季平均净资产；行业中位数逐期截面（`stock_basic.industry`）。
* PiT：`ann_date` 公布后首个交易日进场；剔除金融股（`comp_type != '1'`）；`report_type='1'`。
* 管线：`service/fin_panel.py:roe_ttm_panel`；诊断：`scripts/diag_fin_f1.py`。
* **数据边界**：A 股 `daily` 行情自 2021 年起全覆盖 → 诊断窗实为 2020Q4–2026Q1（22 季），
  2018–2020 队列因无价格剔除（`n<100` 门，非 bug，已逐段验证）。三窗回放不受影响（OOS2 起 2024-08）。

## 2. 预注册 PASS 线（跑前冻结）

1. mean RankIC(roe_ttm, fwd60) > 0；2. Q5−Q1 > 0 的季度 ≥60%；
3. 每季 |corr(roe rank, mom60 rank)| < 0.5（RS 独立性）。一门不过即关，不开网格，不翻符号。

## 4. 裁决：REJECT（方向证伪 · 死因 #3）

三条线只过一条（独立性），两条方向全反：**高 ROE 组合 60 天系统性跑输**。
不是覆盖问题（每季 n>1500），不是单窗问题（负了 16/22 季）。

* 机制解释（事后，不据此开新仓）：A 股高 ROE = 高估值 + 机构拥挤 + 均值回归；
  弱市/小盘季（2024Q2）低质反杀极端。这与 first-principles §一.6 成分效应律同构。
* **反号版本不开**：把"买低 ROE"当 H2 需要独立预注册 + 市值/估值正交控制，
  本档不自动翻多（防 HARKing）。
