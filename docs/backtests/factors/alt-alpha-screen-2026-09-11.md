> **结论**：三类未测数据源**均无增量 alpha**；唯一有统计信号的是**股东户数变化**，但它**只是小市值的代理**
> ——控制市值后信号消失。**REJECT**。

## 3. 增量性检查（决定性）

对信号做横截面 rank 残差（控制市值 log(amt) / 上月收益 / 6 月动量）：

| 变体 | 原始 IC / t | 控制市值后 IC / t | 同时控制三者 IC / t |

| `chg1` | +0.0087 / 2.21 | **+0.0025 / 0.71** | +0.0026 / 0.79 |
| `chg2` | +0.0142 / 3.05 | **+0.0022 / 0.66** | +0.0026 / 0.78 |

**控制市值后信号几乎归零**（t 从 3.05 → 0.66）。`chg2` 对 `ret_prev`/`mom6` 稳健（不依赖反转/动量），
但**完全被市值吸收**——它只是"小市值/户数churn"的马甲，而小市值在 A 股是已知且难交易/已拥挤的因子。

## 4. 裁决：REJECT

- **陆股通持股变化、大单资金流 = 噪音**（t<1.5）。
- **股东户数变化 = 小市值代理**，非独立 alpha（控市值后 IC≈0）。
- 不建策略、不进 Live、不结合 S-3。新数据源里**没有找到可交易的增量 alpha**。
- 方法沉淀：**任何"新因子"必须先做市值/反转/动量正交化**，否则会把已知的 size 溢价当成新发现。
