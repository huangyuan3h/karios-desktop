## 2. 结论

1. **只有一个 S-gap 级引擎**，且它的 alpha 精确等于「**隔夜跳空事件 × 14:30 买最没被追高的那只**」。
   拆开任一半都不成立：跳空本身收盘买≈0（层 2 E1）；层内换任何排序全输（层 1）。
2. **日线级事件族没有第二个**：跳空/放量突破/回踩/跌停反弹全部弱或 regime 依赖；涨停族唯一一致但
   不可跟（`board-quality`：缺口归封板者）。
3. **「只找到一个」是结构性的**，不是搜索不足——这是 first-principles §五「结构吸收律」的直接推论：
   公开、可复制的形态维度已被组合结构吃掉；剩下的 edge 只在**信息冲击 + 执行微结构**的窄缝里。

## 3. 要什么才能改变结论（诚实边界）

- **数据层级**：当前只到日线 + 5min。下一层 = **逐笔/分笔成交、盘口挂单**（不在库）——理论上是唯一
  还没被证伪的「微结构」来源。接入成本高、先验命中率低（本层 12 臂 0 命中）。
- **事件来源**：新的**信息冲击源**（例如可交易的日内新闻/公告时点、可执行的宏观时点）——现有宏观
  已被 §一.14 判「全在隔夜 gap、不可交易」。
- **重开纪律**：任一方向须新预注册 + 新数据通路 + 先过「代理振幅 A/B 自检」（禁止桶均值代理，ALT-1 §3.1）。
