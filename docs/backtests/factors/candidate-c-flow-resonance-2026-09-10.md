## 0. 方法学修正（重要）

TIP-017 §3 原写"先 IC 后闸（TIP-013 协议）"，但 **TIP-013 的 Rank IC 是截面选股口径**——
本候选的数据是**市场级日度时序**（无横截面），跑不了 Rank IC。正确工具：

1. **条件前瞻收益**（时序择时诊断）：按信号状态分组的 forward 1/5/20 日收益 + 单调性；
2. **共线诊断**：与组合已有结构（R-wide breadth / 主线闸 Top3 / neutral_block / 熔断 / regime）
   的相关——命中"被吸收"即杀（§五 维 3 S-3 域"全吸收"）；
3. **gate walk-forward**：幸存者才进，复刻 TIP-016/017 协议。

> 一句话：**这是择时门实验，不是选股因子实验。** TIP-013 的教训（"有效因子清单为空、
> S-3 超额来自 regime/timing 而非 selection"）恰恰说明：若这批数据有用，只可能在门这一层。

## 1. 假设与机制（S1）

**主假设 H（预注册 · 有机制）**：
> **杠杆收缩状态**（全市场两融余额 20 日净变化进入近一年低分位）**叠加核心腿趋势破位**
> → 核心腿前瞻负向；可作为 **fail-open 的休眠保险闸**（平时零成本）。

- **机制一句话**：两融去杠杆是**过程不是终点**——§7.1 已实证"两融减最狠 25% → 未来 60 日
  指数 **-8.04%**"（四条资金信号里唯一同向且幅度大者）。杠杆出清期市场缺少承接，
  核心腿（趋势跟随）在破位后继续被鞭打。
- **反例意识**：§7.1 同日条件差（+0.28%/日）被当日行情污染，不可用；只有**前瞻**检验有效。
- **为什么是休眠闸**：与 B 国家队闸同族（F1 类：长记忆、账本外、可长窗回填验证）。
  若三窗惰性，承认它是"休眠保险"而非"当前救星"。

**次假设 H2（描述性 · 无先验方向，不据此下 verdict）**：
> 多维度**共振/背离**是否有前瞻信息：三路同向 vs 背离，forward 收益是否分层。

> 诚实预期先写死：基于 §7/§7.1，单因子前瞻 ρ 仅 0.1~0.14、资金流是价格**内生响应变量**
> （同期 0.41 / 反向 -0.18），**大概率 Phase 0 就杀掉大半**；H 的期望值是"候选级/惰性"，
> 而非"找到闸"。

## 4. Phase 0 — 诊断协议（零回测；kill 线跑前冻结）

对 §3 每个信号，在三窗各印 **5 列**（不印 PnL、不回放）：

1. **覆盖**：极端态天数 / 总天数（信号定义为事前固定的分位/符号规则，不 onsite 调阈值）；
2. **前瞻**：forward 1 / 5 / 20 日的分组均值 + 单调性（三窗分别）；
3. **共线**：与现有结构（R-wide breadth 0.5 / 主线闸 Top3 / neutral_block / 熔断 / regime）的
   日均相关；
4. **三窗方向一致性**：条件收益差的符号是否三窗同向；
5. **一句话机制**（S1）。

**KILL 线（跑前冻结，任一触发即杀）**：
- 覆盖 < 1%（§一.5）→ **杀**（#7 覆盖不足）；
- 与现有结构 |相关| > 0.7（§五 维 3 全吸收）→ **杀**（#2 共线）；
- 三窗条件收益差**方向翻转**（§四 S2 F4）→ **杀**（#3 方向证伪）；
- 说不出机制 → **不开**（S1）。

> 产出：一张"候选 × 三窗"诊断表；幸存者进 Phase 1。

## 5. Phase 1 — 共振 / 背离（单一定义，绝不扫组合）

只测**事先写死**的两个状态（不枚举组合、不调阈值）：

- **共振**：`SIGN(natD20) == SIGN(marginD20) == SIGN(northD20)` → 三路同向；
  比较"全正 / 全负 / 混合"三组的 forward 5/20 日收益（描述性，无 verdict）。
- **背离**：只看 **两融 vs 国家队** 这一对（§7.1 已定性：两融顺周期、国家队逆周期）：
  - **背离看空** = `marginD20 > 0 AND natD20 < 0`（杠杆进场 + 护盘撤退）；
  - **背离看多** = `marginD20 < 0 AND natD20 > 0`（杠杆撤退 + 国家队进场）。

**判定**：两组背离的三窗 forward 收益若方向一致且覆盖 ≥1%，作为 H 的机制佐证；
否则并入 Phase 0 结论。

## 6. Phase 2 — 预注册闸（只对 Phase 0/1 幸存者）

### 9.2 唯一三窗一致者：国家队份额 20dΔ 低分位 —— 趋势控制后**只在指数>MA200**

Phase 1C 趋势分层（低分位 ≤0.2）：

| 窗口 | 低分位全体 | 低分位 & 指数>MA200 | 低分位 & 指数<MA200 | 基线 fwd20 |
|---|---|---|---|---|
| OOS2 | n=65 fwd20 **−1.05** | n=65 **−1.05** | **n=0** | +2.21 |

**读法**：低分位（国家队大幅净赎回）三窗 fwd20 均**跑输无条件基线**（−0.4~−3.3pp），方向一致；
但 **100% 发生在指数>MA200（上涨中撤退）**——它是"强势中派发"信号，**与 B 闸（指数<MA200）是
不同 regime**，不是同一扇门。高斯分层显示高尾（国家队大幅加仓）三窗并不稳定跑赢（train +1.31
< 基线 +1.73），故不是"加仓→涨"的正向信号。

### 9.3 总结论：**REJECT / 无候选进入 Phase 2**

1. **预注册主假设 H（两融去杠杆低分位 → 前瞻负向）被 Phase 0 证伪**（三窗方向翻转）——
   且与 §7.1 的 fwd60 结论冲突（horizon/口径敏感），进一步说明该维度不稳。
2. **共振（多维同向）覆盖率≈0**——不是弱，是**几乎不发生**，用户"共振"直觉在可观测定义下不存在。
3. **唯一三窗一致的是"国家队上涨中撤退"**：机制说得通（强势派发）、方向一致，但
   ①幅度小（−0.1~−1.0%/20d，最大也仅 ≈−3.3pp vs 基线）；②样本 n=65/14/45；③多重比较产物
   （筛了 10 个信号）；④仅上涨 regime。按 §四 S5（二值开关需单边极端证据）**不够进 Live**。
4. **处置**：国家队 20dΔ 低分位 + 背离看多，**降级为显示/监测信号**（`FundFlowPanel` 已有三路图，
   无需新造）；**不进任何闸**。复活条件写死：前瞻 paper 累积 ≥20 个"上涨中撤退"样本且仍负向，
   或 holdout（2026-08+）独立复现——否则不重开。

> **产出价值**：本轮把"多维度情绪共振"从直觉变成**可证伪的负结果**（共振≈0、两融不成立），
> 并定位到唯一有生命体征的角落（国家队上涨中派发）——按纪律留档，不再扫阈值/组合。
