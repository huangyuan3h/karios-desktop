## 3. 唯一干预：参数无关波动率层 —— **无效**

`scale_t = clip(expanding_median(trailing24m vol)/vol_{t-1}, 0, 1)`（不加杠杆、现金 0%）：
- Sharpe **0.33 → 0.33**、maxDD **−58.2% → −58.2%**、超额 **+2.2% → +2.5%**。
- **机制判读**：这个 sleeve 的回撤是**持续的市场 beta 下跌**（长期熊市段），不是"波动率聚集 → 靠降杠杆躲开"的那种。
  波动率层只削了 ~1pt vol，对回撤无用。→ **预注册判据 #2 不通过（⚠️）**。
- 这是本轮最有信息量的否定：**sleeve 的风险问题不是"什么时候波动大"，而是"它一直满仓 A 股"。**

## 4. 裁决：`PARK`

预注册：判据 #1 通过、#3 通过（Sharpe 0.33 > 流动池 0.26），但 #2 不过。

- **真实边成立**：流动池 + 行业中性后，低投资/低应计确有 **+2.2%/年**、跨 17 年、OOS 更强的超额；
  容量与成本都不构成障碍。**这一条记入因子库（smart-beta 级真实信号）。**
- **但不可独立部署**：绝对 Sharpe 0.33、回撤 −58% ≈ 满仓小盘 A 股；相对基线的 +2.2%/年 不足以把它变成"引擎"。
  波动率层（唯一干预）无效 → 没有可部署的风险管理层。
- **不组合、不进 paper、不调参**（P0-12 纪律）。与 S-3 组合已 §8 REJECT。

**残余唯一路径（记录，不本轮做）**：做空/对冲市场 beta 把它变成市场中性 —— 但 A 股期指基差 + 券源 + 执行语义
（`hedge-twin` 已因成交语义证伪）成本极高，家庭账户不现实；不建议开。

## 5. 诚实边界

- 行业映射仍为**当前快照**（非 PIT）；§7 已用独立源 + 安慰剂 + 分期三重验证，但无法排除两源共享的归类漂移。
- maxDD −58% 是包含 2008/2015/2018 的满仓 beta 回撤，与 §6 的 −49%（年度 May-to-May 口径）差异来自频次/窗口。
- 绝对 CAGR 不作发布依据；本档判据是**相对自有基线的超额**与**可部署性**。
- 未做完备的因子正交化（行业中性已做；size 中性已证不提升，§7）。
