# 5 分钟日内微结构探针（P0-12 · 2026-09-11）

> **结论**：`bar_5min` **不是连续 5 分钟**；可用的尾盘/隔夜信号统计上很强（反转），
> 但**非单调、仅尾部、毛收益 < 交易成本** → **REJECT（不可交易）**。
> **脚本**：`scripts/incubate/{intraday_probe,intraday_reversal}.py`（只读）

## 1. 数据实况（重要）

`bar_5min` 是**稀疏切片**，不是完整 5min：

| 时间 | 覆盖 |
|------|------|
| 14:30 / 14:35 … / 15:00（尾盘 30min） | 2021-01 起 |
| 10:00 / 13:30 / 14:00 | **2024-01 起** |

即：**没有 09:30–10:00、10:05–11:30、13:05–13:30 的 bar**。完整日内微结构做不了；
只能测尾盘 30min、隔夜跳空、首小时（2024+）。

## 2. IC 探针（2021+，信号在 t 收盘可知 → 预测 t+1）

| 信号 | → 次日收盘 | → 次日**开盘跳空** |
|------|-----------|-------------------|
| `overnight`=open/pre_close−1 | IC +0.022 / t10.0 | IC **+0.061** / t29.1 |
| `intraday`=close/open−1 | IC −0.030 / t−7.6 | IC −0.054 / t−18.0 |
| `last30`=bar1500/bar1430−1 | IC −0.057 / t−24.2 | IC **−0.112** / t**−53.8** |
| `firsthour`（2024+） | IC +0.010 / t1.9 | IC +0.015 / t4.6 |

`last30` → 次日开盘 **强烈反转**（尾盘拉高的次日低开）。

## 3. 可交易性检验（target=次日开盘跳空，成本 30bp 往返）

| 信号 | 宇宙 | Q1 / Q5 | Q1−Q5/日 | L/S 净值（毛/净） |
|------|------|---------|----------|-------------------|
| `last30` | 全市场 | −0.029 / **−0.243** | +0.214% | x18.99 / **x0.30** |
| `last30` | 流动≥中位 | −0.168 / −0.393 | +0.226% | x22.19 / **x0.35** |
| `last30` | 大流动(≥80%) | −0.399 / −0.594 | +0.196% | x14.59 / x0.23 |
| `last30` | 用 14:55 代替 15:00 | −0.085 / −0.183 | +0.098% | x3.84 / x0.06 |
| `overnight` | 全市场 | −0.229 / +0.012 | −0.241%（Q5−Q1 +0.241） | x0.04 / x0.00 |

**三处致命**：
1. **成本吃掉全部**：毛 0.21%/天 vs 30bp 往返 → 净值 x0.30（五年亏 70%）。换 14:55（避开收盘竞价）毛降到 0.10%，
   说明近半来自**收盘竞价/尾盘买卖价差**（微结构假象）。
2. **非单调、仅 Q5 尾部**：只有"尾盘大涨"那档次日明显低开；做多 Q1（尾盘跌）在全市场均值 −0.029%/天（**亏**）。
3. **需要做空 Q5** 才能赚，A 股券源难；且各档隔夜均值为负（样本期隔夜负漂移）。

## 4. 裁决：REJECT

- 日内反转信号**统计真实但经济上不可交易**（成本 > 毛收益；尾部效应+做空约束）。
- `firsthour`（2024+）IC≈0.01，无料。
- **不建议为完整 5min 回填**（baostock 全量 ~6.8 亿行），除非有明确的日内目标形态。
- 方法沉淀：**日频以上的微结构信号必须按"毛收益 vs 往返成本"先算清楚**，IC 再高也可能是竞价价差。
