# 核心 S-3 入场执行微观诊断（2026-09-10 · 只读 · 无 PnL）

> **一句话**：冻结核心的 `next_open` 成交是**干净且可代表实盘**的（≈ 信号日收盘，≈ 实盘 14:30 代理，差在 ±0.7% 内）；**限价入场有 ~0.1–0.9% 的价格改善，但有 25–50% 漏单且漏掉的正是"开盘后一路涨"的强势票（逆向选择）→ REJECT，不单开回测**。
> 方向：执行/微观（用户 2026-09-10 选定）。脚本 `scripts/diag_core_execution.py`（只读，stdout）。

## 0. 背景与数据陷阱（重要）

- **唯一未测过的执行缺口 = 核心 S-3 入场成交**：`entry_mode="next_open"` 是 2026-08-28 的 **realism 修正**（audit E4），从未做过 CN 的 close-vs-next_open A/B；卫星时钟（T-open / body=3 / C1 3% / 第 3 日 14:30 卖）**已测尽**，不再碰。
- **数据陷阱（本轮踩到并修正）**：`daily` 是**前复权（qfq）**、`bar_5min` 是**不复权（raw）**，跨源价位不可比（首跑出现"14:30 比开盘便宜 10%"的伪影）。全部改用**同日内比值**（复权因子抵消）。
- `bar_5min` 只有**尾盘**（1430/1435/…/1500，另 2024+ 有 1000/1330/1400）——**没有早盘**，故"次日早盘挂单"不可测；尾盘/日线可测。

## 1. 方法

冻结 CN 核心，long 窗 2021-08~2026-08，取全部入场（`next_open` 成交），对每笔比较替代成交价：
- 成交日收盘 / 成交日 14:30（5min，比值法）；
- **信号日**收盘 / 信号日 14:30（实盘 14:00–15:00 代理）；
- 成交日**低触限价**（§二.1 成交语义：`low ≤ limit` 才成交）：=信号日收盘 / =开盘−0.5% / =开盘−1%。

## 3. 结论

1. **`next_open` 基线确认干净**：与信号日收盘的中位差 **0.00%**（三窗一致）、与实盘 14:30 代理差在 ±0.7% 内 → **audit E4 的 realism 修正成立**，回测成交价可代表实盘，**不存在此前担心的 ~10bps/笔口径缺口**。
2. **换成更晚的成交（收盘/14:30）无系统优势**：三窗方向不一致（OOS2/train/valid 略差、long 略好）→ 维持 `next_open`。
3. **限价入场：REJECT**。条件成交时的价格改善（+0.1~0.9%）被两件事抵消：**① 25–50% 漏单**；**② 逆向选择**——漏掉的是那些"开盘后一路涨"的票（三窗 open→close 漂移为正），恰是强势动量票。
4. **不单开回测**（漏单/选择偏差无干净隔离手段；§二.1 日线低触也无法还原盘中路径）。执行/微观方向到此为**负结果**：现有执行已接近最优可实现。

## 4. 边界与下一步

- **日线低触的局限**：无法判断盘中价序（低点是否在拉升后）。要严格测"早盘挂单/限价"需早盘分钟数据——`bar_5min` 没有，**不可测**。
- **遗留 realism 项（非 alpha，正确性）**：audit E5 — `slippage_pct=0.05` 与 cost 模型 0.10 双计约 40bps（偏保守），且小票仍低估 20–50bps。可作独立正确性修复评估。
- 已测尽不再碰：卫星入场/出场时钟（`sat-fill-same-close` / `sat-habit-clock` / `sat-exit-hhmm`）。
