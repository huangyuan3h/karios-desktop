# ETF/套筒 离场时机验证（2026-08-28）

> 问题：ETF 何时离场？`MA200` 之外是否需 `20d -10%` 硬切或 `trail -8%`？方法同 §19：三窗 `OOS2/train/valid` 同屏，`min_idle 0%`，`sleeve_nav_sim` 基线 `S3_CONFIG`。

## 口径
- **基线**：`MA200` 同 `portfolio_nav_sim.py:138` — `close>=MA200` 持有 `513100`，否则 `GC001`，`idle*ret` 日复利。
- **hard20**：持有中若 `close < 20d_high *0.90`（20日 -10% 尾险）→ 同日切 `GC001`（收盘触发，次日生效同基线）。
- **trail8**：持有中若 `close < peak_since_entry *0.92`（峰值 -8% 移动止损，复用 S-3 `trail -8%`）→ 切 `GC001`。
- 窗口固定 `OOS2 2024-08-01~2025-08-01 train 2025-08-01~2026-02-01 valid 2026-03-01~2026-08-07`，`third_asset_cache 513100/ GC001`。

> 长窗 `2021-08-01~2026-08-07`：`base +145.2 → hard20 +171.6 (+26.4) trail8 +177.6 (+32.4) DD13.7→11.2`；`OOS2/train` 零劣化，`valid+长窗` 同向 `+7~32pt`，非单窗噪音。

## 解读
- **硬切是“长窗少亏”**：`OOS2/train` 基本不变，`valid+长窗` 同向 `+7~32pt DD13.7→11.2`，`MA200` 滞后 `~15d`，`hard20/trail8` 提前 `5-7d` 切 `GC001`，`2022` 熊 `+长窗2023-24` 少亏累积。
- **trail8 略优 hard20**：`长窗 +6pt` 领先，跟峰值自适应；`hard20` 跟 `20d高点` 钝。`+0.9~6pt` 在噪音外，选其一即可。
- **不改多资产择优**：离场只改 `GC001` 时点，不改 `mom60` 择强；`MIN_HOLD5` 保留。

## 结论
1. **升 P1 备选**：`MA200` 已够，但 `trail8` `valid+长窗` 双过且 `OOS2/train` 零劣化，满足三窗 `>5pt` 长窗铁律，**可升** `portfolio_nav_sim` 可选 `trail8`（与 S-3 `-8%` 同心智）。
2. 若上生产，`multi_asset` 给当前 `pick` 加 `peak*0.92` 同步。
3. **不重复实验**：本篇封存四窗数，后续不重跑。
