## 1. 实验背景（用户直觉 → 回测验证）

用户真实执行节奏 = 14:00-15:00 随机时刻按信号买入。`last_hour_low` 入场假设不可执行
（02099 案例：8/12 收盘 202.8 入场 → 8/13 -6.4% 止损 → 8/14 业绩利好 +14.6%）。
因此不优化入场价，而是优化**买入方向**：不同市场环境下买什么类型的票。

**核心假设**：电风扇行情 → 买短期调整大的强势股（低吸）；主升行情 → 买龙头（追强）。

环境标签每日生成（`service/env_label.py`，纯 DB 本地数据）：
- uptrend 主升：涨跌比 ≥ 2 + 涨停溢价 ≥ 0 + riskMode ∈ {hot, euphoric, normal}
- fan 电风扇：涨跌比 ∈ [0.5, 1.5] 或 主线 top3 每日切换率 ≥ 2/3
- weak 弱势：riskMode ∈ {extreme_caution, no_new_positions} 或 涨跌比 < 0.5
- neutral 真中性：sentiment + mainline 数据都在但非上述（**16/16 笔全亏 → 禁开仓**）
- unknown 无情绪数据（OOS2/train 前期）→ 不拦截、不缩放

## 2. 成功路径（已固化 ✅）

### 2.1 neutral_block（弱/中性日禁开仓）

| 窗口 | 收益变化 | 备注 |
|------|---------|------|
| valid | **+10.7pt**（89.1→99.8） | DD 12.1→2.7 · 胜率 60.8→78.2 |
| OOS2/train | 0（无情绪数据 = UNKNOWN，不拦截） | 零影响 |

- 触发条件：涨跌比 < 0.5（隐含弱势）或真 neutral 日 → 禁新开仓
- **数据事实**：valid 窗 16/16 笔全亏 avg -6.1%
- 同步：S3_CONFIG 三处 + execution_gate（BREADTH_IMPLICIT_WEAK）+ paper_s3

### 2.2 entry_style auto（主升追强 / 电风扇低吸）

| 窗口 | 收益变化 | 备注 |
|------|---------|------|
| valid | **+4.7pt**（99.8→104.4） | 电风扇日 avg +12.8→+17.4 · 胜率 81.8% |
| OOS2/train | 0 | 无环境标签 |

- auto 映射：uptrend→momentum（RS≥0.7 且 5日回撤 ≥ -3%）· fan→dip（5日回撤 ≤ -3%）· weak→blocked
- 参数扫描：RS 0.6/0.65/0.7 + dip 2%/3%/5% → **RS0.7 + dip3% 最优**
- **与行业无关**：auto 只过滤个股 RS+回撤；行业限制来自独立的主线闸门层（mainline Top3 动态）

## 3. 失败路径（已拒收/不适用 ❌ — 别重走）

### 3.1 E1：neutral_block 大环境条件化（2026-08-14 实验 · 已删除）

- **假设**：neutral_block 只在某些大环境（如 weak 年）生效？
- **结果**：新基线（E2 panic=2）上持平、无任何效果——**E2 已吸收其价值**
- **处理**：代码已删除；保留字段有误开风险（发现时 E1 残留 `hk_style_map` 外泄到 live 配置）

### 3.2 HK 线环境感知（2026-08-14 · 结论：不适用）

- HK 只有 HSI/HSTECH 红绿灯（2 个信号），无 CN 式 sentiment
- 归因：HK 动量股极少 5 日回调（dip 分支形同虚设）；regime 与收益无稳定关系
  （valid Strong 日 -0.72% 亏 vs OOS2 Strong 日 +0.53% 赚）
- 任何风格过滤都破坏 OOS2（-170~-181pt）→ **HK 维持 entry_style=score**
- **根因**：环境感知需要足够的环境数据（CN 4+ 信号 vs HK 2 个）→ 对应 D8 港股情绪数据需求

### 3.3 电风扇细分（D1 · 主线在 vs 无主线，2026-08-14 · 数据不足）

- valid 全部 18 笔 fan 日都属于"无强主线"（top3 平均分 <70）
- "有主线但轮动快"子集零样本，无法对比 → 待更长历史
