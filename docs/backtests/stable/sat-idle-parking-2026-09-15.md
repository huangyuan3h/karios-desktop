# 星舰空闲现金停放（H-SAT-IDLE）· 2026-09-15 · REJECT

> **何时看**：想知道「星舰（卫星 standalone）的空仓/空槽现金能不能停到港湾核心或 ETF 套筒来加收益」时。
> **何时不看**：Live 操作（Live = 港湾）；星舰前置（paper 3/20 + 用户授权）判定。
> **一句话**：预注册单假设 A1（因果 T−1 停放 → 港湾核心）**K1 过（三窗 +26.4/+10.2/+1.6）、K2 挂（long −93.3，MDD −8.4→−27.6）→ REJECT**。死因 = **#2 regime 冲突**：卫星的空仓日 = 弱广度日，港湾核心在这些日子平均 **≈ −4%/yr（核心整体 +25.7%/yr）**——把卫星的"对冲现金"换成核心敞口，long 反而变差。价目表（不裁决）：防御 ETF 套筒（A2）long **+152.6** 但 OOS2 −1.6 / valid −4.1 双窗稀释 + MDD −30.5，且 15bps 转移成本下只剩 **+51.1**；REPO（A3）被转移摩擦吃掉（**−31.3**）。**Live 不动；「卫星锚 + 空闲现金停放」方向关闭。**
> **关键词**：星舰 · 空闲现金 · 因果停放 · regime 冲突 · 收益拟合 · REJECT

## 1. 口径（一句话）

卫星腿 = habit 冻结（`amp_1430` + C1 3% + `same_1430` + `gate_1430` + 30bps RT，100% 名义、4×25% 槽）；停放权重 = **T−1 收盘因果** `w_t = clamp(1 − 0.25×satPositions[t−1], 0, 1)`；`port_ret_t = sat_ret_t + w_t×x_ret_t − 5bps×|w_t−w_{t−1}|`（15bps 敏感性）。X 三臂：**A1 = 港湾核心**（`parking_replay` 单源，含成本）· **A2 = ETF 停车场单腿**（mom60+MA200 argmax + 因果 trail8）· **A3 = REPO 0.7%/yr**（对照）；`A1_legacy` = 同日 label 版（描述行，不裁决）。

## 3. 裁决（冻结 K1–K2）

| 臂 | K1（三窗 Δtot ≥ 0） | K2（long Δtot ≥ +100） | 结果 |
|---|---|---|---|
| **A1（主假设）** | ✅ +26.4/+10.2/+1.6 | ❌ **−93.3** | **REJECT** |

**锚点披露**：本档是「卫星锚 + 空闲现金 → 港湾」的**新资本结构**，≠ 港湾加卫星（H-SAT-W 仍 REJECT）。交叉验证：本档 A1（≈ H-SAT-W w=1 端点）vs 港湾核心 long **+168.8**（曲线 w≤0.5 外推 2×+90.4 ≈ +180.8，量级一致）、valid **−34.0**（线性 −42.4 外推略更差）——**H-SAT-W 的死区结论在 w=1 端点依然成立**。

## 4. 发现（为什么死 + 什么活着）

1. **核心在卫星空仓日亏钱（#2 regime 冲突，实锤）**：A1 − A3（同成本、只换停放资产：核心 vs REPO）= **−62.0pt**，扣 REPO 毛收益 +1.1pt → **核心在这些美元日净贡献 ≈ −4%/yr（停放本金口径）**，而核心自身 long +25.7%/yr。年度 Δ：2021 −15.1 / 2022 −9.9 / 2023 −1.2 / 2024 +0.2 / **2025 +34.2** / 2026 −22.2——核心只在 2025（单边牛）加分。机制：卫星 `gate_1430` 空仓 = 弱广度日，S-3 股票腿在这些日子尚有敞口 → 逆势。
2. **相关低 ≠ 能停**：两腿 idle 切片相关 ≈ 0（0.00/−0.17），但问题是**均值**不是相关——低相关只降低波动，不改变"弱日负收益"的拖累。
3. **防御套筒没有这个冲突，但另有代价**：A2 − A3 = **+183.9pt**（≈ +6.1%/yr 组合、停放本金口径 ≈ +10%/yr，与其 standalone +14.1%/yr 同档）→ 套筒在卫星空仓日的收益 ≈ 其整体（金/油/纳/债 + MA200 闸，天然防守）。**但**：OOS2 −1.6 / valid −4.1 双窗稀释、MDD −8.4→**−30.5**（卫星的现金对冲属性被换掉）、15bps 转移成本下 long 只剩 +51.1（成本吃掉 2/3）。
4. **REPO 被转移摩擦反噬**：日均 |Δw| 12.6% × 5bps ≈ 1.6%/yr 成本 vs REPO 0.4%/yr（long −31.3）。卫星槽位变动 ~1.6 次/日，任何"低收益停放"都扛不住进出摩擦。
5. **同日 label 不是救星**：A1_legacy（同日 `satPositions`）long −161.9，比因果版更差——滞后不是本档的死因。

**机制诊断（套筒日均收益按卫星占用状态切分；`parking_replay` 全因果：pick/trail 只用 prev 收盘）**

|---|---|---|---|---|---|---|---|---|
| OOS2 | 44.6% | 96（39.7%） | +0.070% | −0.222% | +0.098% | +4.9 | **−6.5** | −1.6 |

| long | 57.3% | 642（52.8%） | **+0.066%** | +0.038% | +0.066% | **+209.4** | **−56.8** | **+152.6** |

读数：
1. **长窗机制成立**：套筒在卫星空仓日 **+0.066%/日 ≈ +17%/yr 算术**（略高于其自身 long CAGR 14.1%）——"钱不是白停的"得到验证。
2. **但强 regime 依赖**：train +0.271%/日（大赚）· OOS2 +0.070%/日（小赚）· **valid −0.024%/日（不赚）**——valid 正是套筒不给钱的窗口 → 该窗净 −4.1；这也是 OOS2 净 −1.6 的一半原因（毛 +4.9 < 摩擦 6.5）。
3. **摩擦真实存在**：long 5bps 吃掉 **56.8pt**（毛 +209.4 → 净 +152.6）；15bps 只剩 **+51.1**。卫星槽位日均变动 12.6–17.2%（OOS2 最高）→ 停放本金频繁进出。
4. **回撤代价 = 拆刹车**：套筒自身 −28.7（valid/long）→ 组合 MDD −8.4 → **−30.5**；valid 更从 −6.5 → −28.3。

**边界补充**：停放收益按"T−1 收盘占用 + 全日套筒收益"计（近似）；卫星 14:30 成交日实际只持有停放资产 ~5/6 天 → 本档对停放收益略偏乐观（量级 <1/6 × 换手日收益）；转移摩擦按 5bps/边（含 15bps 敏感性），未建模冲击。

## 5. 边界（诚实项）

- 停放权重用 `1 − 0.25×satPositions`（house `sat_idle_frac` 同口径）近似 NAV 现金份额；14:30 成交日内进出的精确资金流未建模（首/末 30 分钟口径误差）。
- 转移成本取 5bps/边（对齐停车场 0.05%/边）+ 15bps 敏感性；未建模滑点/冲击。
- A2 的套筒 standalone long **+89.1/0.68** 与 B13 档的"套筒单独 +63.4/0.54"有口径差（本档用 `parking_replay` 单源 + 卫星日历 + 含 5bps/边；B13 未含 2026-09-14 clean 修正），差异方向对结论不利者已保守说明。
- holdout n=26（数据至 2026-09-11），只描述。

## 6. 结论 / 下一步

- **「星舰 + 空闲现金停放」REJECT**：主假设 K2 挂，价目表两臂（套筒/REPO）分别有双窗稀释 + MDD×3.6、摩擦反噬问题。**卫星的空仓现金是它的对冲垫，不是待利用的闲置资本**——「只追求收益」在 A1 上都不成立（long 更差）。
- 想提升整体收益的**已验证路径**仍是**换基座**而非换现金去处：星港 = 母港×卫星 **H-B3-SAT PASS（chosen=1/3）**（三窗 +15.5/+11.0/+11.6、long +125.4；valid 稀释 −42.4×w → −14.6×w）；星舰 standalone 仍是 long 收益之王（+463.6）。
- **Live 不动**（= 港湾）；星舰前置条件不变（**paper 3/20 + 用户风险授权**，执行审计已过 90bps +310%）。
- 若未来要重开：唯一还没测的是「卫星**自身**加槽/加名义」（杠杆），属卫星配方调参 → 需另起预注册 + 全周期门槛（现行纪律：卫星不可调参重扫）。
