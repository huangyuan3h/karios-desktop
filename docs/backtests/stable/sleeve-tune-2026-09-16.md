## 5. 方法论 catches（本次实验附带产出）

1. **窗口基线课**：NAV 必须开盘持平（eval 惯例）。探针版漏掉 day-0，吃掉了首日 +10% spike，
   把 valid 从 +6.8 算成 −2.9；`_stats` 交叉核对抓获。已修（`_nav_from_recs` 开盘补 1.0）。
2. **价格基线课**：实验必须用冻结口径的 fund-adj CSV 收盘（daily-qfq 另有 BOND10-2026
   2.2% 的分红口径漂移，会翻转 argmax  picks）。已对齐：canonical long 与冻结
   +89.1 逐数一致（OOS2 +11.0/train +23.6/valid +6.8 全对上）。
3. **诊断门课**：B 门过了（4pt 微弱优势）但臂死了（−37.7）——入选增益 ≠ 跳过增益，
   跳过支付的是机会成本（错过随后拉升），诊断时必须把"不做"的代价也算进去。
4. **机制-实现一致性课（2026-09-17 审计）**：原 H2 机在 band 阻断时 `want=None` →
   清仓去 REPO——把"挑战者不够好"和"没有候选"混为一谈，实际是"迟滞一天 + 多付一次
   卖出 + 空仓一天"，不是预注册的"继续持有旧腿"。**两份实现（eval 副本 + 服务）互相
   NAV parity 并不证明正确——两边可以是同一个 bug**。冻结数字（valid +7.9、MDD −26.1、
   long +1062.6）全部来自错误机制。修正：H 臂单源到服务机 + 行为级单测
   （`test_blocked_rotation_keeps_incumbent_leg`：阻断日 pick 不变、sides=0、
   当日收益为旧腿收益）。
