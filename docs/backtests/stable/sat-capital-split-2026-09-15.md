## 1. 口径（一句话）

## 3. 读数（预注册声明的三种汇总）

1. **收益前沿：全部其他腿 = c=1.0（纯星舰）**。每条曲线 long total 随 c 单调——**没有任何"少给卫星钱"能提高总收益**（卫星是收益王，混合必然让收益）。
2. **风险调整前沿（long Sharpe）**：**B3 c=0.50 → 3.78**（long +193.5/MDD −3.6）· REPO c=0.20 → 3.73（+47.5/−1.5）· 母港 c=0.80 → 3.58（+374.1/−6.2）· 港湾 c=0.80 → 3.33（+413.9/−6.9）。纯星舰 3.50。
3. **换手价格 ≈ 线性**（Δ 基本按 c 插值，无结构性拐点）：年度分解（c=0.50，Δ vs 星舰）——港湾 `2021 −40.4 / 2022 −18.1 / 2023 −7.0 / 2024 −5.0 / 2025 +9.6 / 2026 +20.3`；母港 `−37.8/−21.3/−5.7/−9.0/−0.8/+9.6`。**混配的收益来自"用 2021–24 换 2025–26"**（近期 regime 更互补），不是免费午餐。

**特别行（两窗不劣的候选）**：
- **星舰 80% + 港湾 20%**：train **+43.6**（vs 40.3）、valid **+22.0**（vs 14.7）、MDD −6.9（vs −8.4）、long +413.9（−49.7），OOS2 +175.7（−37.0）。
- **星舰 80% + 母港 20%**：valid +17.0、train +39.7、MDD −6.2、SR **3.58**（>3.50）、long +374.1。
- **星舰 50% + B3 50%**：long SR **3.78**、MDD −3.6，但三窗 total 全面低于纯星舰（OOS2 +97.0/valid +8.2）。

## 4. 发现

1. **收益层面没有杠杆**：卫星长窗 CAGR 43.1% 独一档，任何配比的 long total 都在 3.4%（REPO c=0）× 46.4%（星舰）之间按 c 插值（读数 3）。
2. **"少给卫星钱"买到的是三样东西**，按效率排序：
   - **回撤**：B3/REPO（现金型）最狠——B3 c=0.5 把 long MDD 从 −8.4 压到 **−3.6**；港湾/母港温和（−6~−7）；套筒反而更差（自身 MDD −28.7）。
   - **valid 短板**：港湾 20% → valid **+22.0（+7.3）**、母港 20% → +17.0（+2.3）；这是 H-SAT-W/H-B3-SAT「valid 稀释」的**反向用法**——用港湾补卫星的弱窗。
   - **Sharpe**：B3 50% → 3.78、母港 80% → 3.58、REPO 20% → 3.73。
3. **套筒（纯停车场）是最差的一条腿**：收益低于港湾/母港、MDD 更差（−28.7），与 H-SAT-IDLE 的 A2 结论一致——**它只适合当"卫星空槽的临时现金去处"（H-SAT-IDLE A2），不适合当资本配比腿**。
4. **静态配比 > 空闲停放**：对比 H-SAT-IDLE——A1（只停空仓现金→港湾）long **−93.3**；本档静态 20% 港湾 long 只 −49.7 且 train/valid 双升。原因：空闲停放把港湾敞口精准压在"卫星空仓=弱广度"的日子（撞 regime）；静态配比则**全年 20% 拿港湾**，不择时更稳。

## 5. 结论 / 建议（价目表，非产品决定）

- **只追求收益 → 100% 星舰不变**（+463.6 / MDD −8.4 / SR 3.50）；配比只会让收益（读数 1）。
- **要补 valid 短板 / 压回撤，且不想丢太多收益 → 星舰 80% + 港湾 20%**（三窗两升、MDD −6.9、long +413.9）。
- **要长期 Sharpe → 星舰 50% + B3 50%（3.78）或 星舰 80% + 母港 20%（3.58, long +374）**。
- 全部为价目表；任何落地（含 paper 试跑）需**另起预注册 + 用户拍板**；**Live 仍 = 港湾**；星舰前置（paper 3/20 + 风险授权）不变。
