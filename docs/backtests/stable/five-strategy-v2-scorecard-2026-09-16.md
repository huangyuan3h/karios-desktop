## 4. 关键发现

1. **valid 是唯一的坟场**：全部卫星腿在 valid 失血（vs 港湾 −25~−50pt），机制一致——valid 是趋势窗，
   卫星有仓仅 27%，脉冲腿无米下锅；星舰更叠了停车套筒在 valid 内的 **−28.7 自体回撤**
   （套筒 long MDD −28.7 的兑现位置就在 valid 窗内，valid 绝对 0.0%）。
   这不是五个独立坏消息，是**同一个 regime 依赖的五个侧面**（诊断档结论复用）。
2. **long 端卫星腿全胜，但价格不同**：星舰 long +717（MDD 代价 −7.1pt）· 双子星 +114（MDD +2.0pt 改善）·
   星港 1/3 long **+0.3（vs 港湾持平）**——星港相对港湾的全部增量在 OOS2（+32.4），long 端只是"用 valid −32.3 换 OOS2 +32.4"。
   **基座决定结论**：星港 vs M50 是条件PASS/REJECT 之争，vs 港湾是干脆的 REJECT——H-B3-SAT"换基座有效"的反面。
3. **风险腿只有母港全优**：long MDD 排序 星港 −11.2 ≈ 母港 −11.8 < 双子 −20.8 < 港湾 −22.8 < 星舰 −29.9；
   long Sharpe 排序 星舰 2.12 > 星港 1.90 > 双子 1.53 > 母港 1.19 > 港湾 1.02。
   母港是唯一"四窗 MDD+Sharpe 双优"，代价 long −89（保险通道定价）；星港是"便宜版母港"
   （MDD −11.2 ≈ 母港，收益持平港湾，valid −32.3 是短板）。
4. **holdout（5 周，一致下跌，纯描述）**：五策略全红；叠加档 total 亏得略少（卫星有仓 100% 部分对冲）
   但** intra-window MDD 全比基座深**（星舰 −13.6 vs 核心 −4.2）。n≈25，不作判定，只记一笔：下跌带里卫星腿"亏得少、抖得凶"。
5. **成本覆盖**：母港 cost20 ≈ 零影响（G3d 强过）；星舰 15bps long +873.8（Δ +399，3 倍成本仍成立）；
   星港/双子星 2x-cost 重跑**待补**（fills 已含 30bps RT 卫星成本，2x 敏感性未跑，OPT-213 工具化时补）。

## 6. 留给比较轮的问题
1. valid-regime（趋势窗卫星挨饿）是永久结构还是周期位置？若是永久的，任何卫星 overlay 的上限就是"用 valid 失血换他窗收益"，定价后决定配比。
2. 星港 vs 港湾 long 持平（+0.3）：星港的存在价值 = OOS2 弱市年 +32.4 + MDD 腰斩，价格 = valid −32.3。这笔兑换是否值得，取决于问题 1。
3. 母港保险通道：long −89 换 MDD −22.8→−11.8 + 四窗 Sharpe 全升——产品层是否接受，前置（paper 3/20 + 资本结构）不变。
4. 星舰：long +717 / Sharpe 2.12，但 valid −50.3 + long MDD −29.9——只适合"卫星 standalone + 用户风险授权"轨道（前置不变），不进 Live 讨论。

## 7. 评分（rubric v1 · 2026-09-16 · 权重 收益40/风险30/稳健20/执行10）

> 权重承接 v2"收益最重要但不是唯一"；数值档为 v1 默认，可调。分数只在本轮五策略之间可比，
> 不跨档比较历史实验。

- **R 收益 /10**：long 档（≥800→10；≥300→8.5；≥200→8；≥150→7；≥100→6；≥50→4.5； else 3）
  + dev 均值修正（≥60 → +0.5；≤35 → −0.5；封顶 10）。
- **D 风险 /10** = MDD 分（long MDD ≥−12→5；≥−15→4；≥−20→3；≥−25→2；else 1）
  + Sharpe 分（long SR ≥2.0→5；≥1.5→4；≥1.0→3；else 2）。
- **S 稳健 /10** = 最差窗 `min(5, 1+min(dev)/10)` + 离散 `max(0, 3−1.5×range/mean)` + holdout `max(0, 2−(|ho|−1.5))`。
- **E 执行 /10** = 成本 4（已证不敏感 4；fills 含成本但 2x 待补 2.5；星舰 15bps 成立但有容量约束 3）
  + 复杂度 3（2 腿清晰 2.5–3；3 腿 2；Live 在跑 +0.5→3）+ 实盘就绪 3（Live 3；在轨 1.5；前置未达 1）。

  双子星 MDD（−20.8）与港湾（−22.8）同档是 rubric 粗糙，实际略优。
- **第二梯队（68–69，偏科生）**：星舰（收益满分 10 + Sharpe 5，但稳健 2.3 崩盘：离散 0 + 最差窗 1）·
  母港（MDD 满分 + 稳健 7，收益 5.5 全场最低：保险的定价）。
- **权重敏感性**（50/25/15/10）：港湾 76 = 星港 76 > 双子星 75 > 星舰 74 > 母港 66——
  收益权重一上去双子/星舰就追上来，母港垫底。**排名是权重的函数**，本表只代表"收益重要但风险一票不便宜"的价值观。

### 五策略一句话特点

- **港湾**：全天候底座——唯一 valid 最强（+50.3）+ 执行满分；代价是风险指标全场最弱（long MDD −22.8/SR 1.02）。适合：Live 默认。
- **母港**：保险——四窗 MDD/SR 双优 + 成本零敏感 + 压测过；代价 long −89。适合：低波产品候选（保险通道）。
- **星港**：均衡增强——OOS2 进攻 + long 持平港湾 + MDD 减半 + SR 1.90；代价 valid −32 + 三腿复杂度。适合：研究默认档（条件待转正）。
- **双子星**：弱市爆发型——OOS2 +145.9 全场最暴力 + long +322；代价离散度最大、valid −25.5。适合：并行对照（已定）。
- **星舰**：收益怪兽——long +924.9/SR 2.12/OOS2 +241；代价 valid 归零 + MDD −29.9 + 容量 ≤5M。适合：独立高风险轨道（paper+授权前置）。
