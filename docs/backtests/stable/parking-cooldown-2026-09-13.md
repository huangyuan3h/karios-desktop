## 1. 做了什么

在 B11 P1 口径上只加一个变量：被因果 trail8 踢出某只 ETF 后，该 **key**（纳指别名同暴露）在 k 个交易日内不可再买；冷却期资金停**次优合格候选**，无候选 → REPO。k=0 = 现任者。网格 `{0,1,2,3,5}` 预声明（S4 平台扫描），风险目标 = valid MDD 改善 ≥3pt 或 Sharpe +0.10。

## 4. 关键观察

1. **主死因 = #1 截右尾（预判命中）**：冷却挡住的正是急跌后的 V 反抽——long k1 −22.9pt 最典型；valid 总收益 −6.8~−13.4pt。R 反抽是 ETF 停车场的收益来源之一，冷却把它一起关了。
2. **风险目标没达到**：valid MDD 最好只改善 +2.4pt（门槛 3pt），k5 反而变差 2.7pt；Sharpe **四档全降**（−0.18~−0.41）。"用冷却降低噪市回撤"的机制在数据上不成立——回撤峰值那段（2026-06/07）冷却只削掉极小部分。
3. **换手反而增加**：停次优 + 回补 = valid 交易 21→26/27；冷却制造了新的 churn，与"少动"直觉相反。
4. **k5 的 long +5.0 是单窗假象**：OOS2/train/valid 全负，不构成 S4 平台 → 按 #4 过拟合拒收。
5. 次死因 **#4 regime**（预判命中）：冷却在噪声市的收益税大于风险收益，长窗纯税。

## 5. 结论 / 处置

- **方向关闭**；港湾维持 P1（k=0），`pick-strong-track.md` §3 的"再入场冷却"候选清空。
- 不重开同族（全局冷却/上限/自适应冷却），除非能先解释本 REJECT 的机制（V 反抽不可让渡）为何不适用；那是另一个预注册。
- 港湾空仓期回撤（valid −21.8）仍由 **B13 基线×风险预算 50/50** 处理——属产品层资本结构选择，未落地。
