# 「星舰」（Starship = 习惯 S-gap 卫星腿 standalone）· 2026-09-14

> **命名（2026-09-14）**：**「星舰」（Starship）**——本档 standalone 口径（100% 名义卫星曝露）的命名，tag `starship`；与「星港」（母港×卫星三腿）同族，星舰是激进档、星港是受预算约束档。
> **何时看**：想理解「习惯双子星」的卫星腿到底能赚多少、或要重开卫星参数时。
> **何时不看**：想要 Live 规则——Live 是「港湾」，本档是**研究/激进候选档，不进 Live**（前置见 §6）。
> **一句话**：卫星 = 隔夜跳空 >3% 的 A 股里，挑「14:30 前振幅最小」的 1/3，14:30 买、第 3 日 14:30 卖，4×25%、30bps；基期统一 + 日历修正（OPT-183）后 standalone 三窗 **+212.7 / +40.3 / +14.7**、long **+463.6%（MDD −8.4）**；但 **valid 单窗只有 +14.7%** → 拖累双子星过不了 K1/K2。

## 3. 用途与判定

- **用途**：作为「习惯双子星」的增强腿（有卫星仓日与港湾核心 50/50；无仓日 100% 核心）。不是独立产品、无 Live 接线。
- **双子星贡献**：加卫星后 long +201.5%→**+291.9%**、Sharpe 1.00→**1.45**、回撤 −22.8%→−20.8%（OOS2/train/long 全面改善）。
- **短板**：valid 窗卫星只有 +14.7%（同一窗核心 +50.3%），双子星被稀释（Δ−21.2 / Δsr−0.65）→ 冻结 K1/K2 不过，**双子星维持 REJECT**。**根因已诊断 = regime 依赖**：有仓 30 天里核心同日跑赢 3.2×（见 [`sat/sat-valid-shortfall-diagnosis-2026-09-14.md`](../sat/sat-valid-shortfall-diagnosis-2026-09-14.md)）。
- **风险/纪律**：卫星早期年份（2021–23）是事后样本（C1/amp_1430 规则在 2024+ 窗验证）；重开参数须新预注册 + 全周期门槛 + valid 短板诊断（已完成）；已 REJECT 变体不得直接进 Live。

## 4. 数据真实性（2026-09-14 校验）

- long 窗把每笔 raw 成交价按**当日因子**（raw 15:00 ÷ qfq close）换算回前复权后：**1036/1036 入场、1017/1017 出场全部落在该股当日日线 [low, high] 内**（另 19 笔出场日无行情数据，多为退市/停牌）；单笔盈亏 −18.7%~+26.3%（20% 涨跌幅板），无异常值。
- 退市股（生存偏差）在 gap 事件中占 **0.36%**（本库退市记录不全，属已知残余）。
- 残余：3 日持仓不计股息（保守）；14:30 用采样 5 分钟 bar 代理 Live 实时快照（名字级非逐只相同）。

## 6. 「星舰」命名与激进档记录（2026-09-14）

**命名**：星舰（Starship）= 本档 standalone 口径。同族：港湾（Live 底仓）→ 母港（保守混合）→ 星港（三腿，w=1/3 受预算）→ **星舰（激进，100% 卫星曝露）**。

**用户立场（风险授权声明，非数据证明）**：「终局财富导向——若第一年高收益、次年回撤见底仍领先慢速稳定策略，则没有理由不选更赚钱的策略，回撤容忍可放宽。」

**关键澄清（为什么 §3 的 REJECT/预算与"回撤"无关）**：

- 本家族的**回撤不是约束**：星港高曝露档 long MDD 反而更低（w=0.5 → −11.2 vs 港湾 −22.8；星舰 −8.4）。被 K1（valid Δ ≥ −5pt）限制的是**valid 窗的相对落后**，不是回撤路径。
- 数学上用户立场成立：只要不上杠杆、不在低点用钱、能拿住，"第二年回撤见底但仍领先"是纯赢；平滑不是目标，它只是抗**估计误差**的保险。

**推进前提（缺一不可，未满足前只作命名档记录）**：

1. **执行审计**（"回测可信"只过了一半）——**✅ 2026-09-14 完成（H-SAT-EXEC）**：成本 30/45/60/90bps 重放（90bps 仍有 **+310%/SR 2.45**）、贴板成交 0、近涨停 4/1040、ADV median 0.76 亿、容量 ≤¥5M 舒适。残余：采样 bar 代理（`amp_1430` 对 51.5% 的 fill 只反映采样窗）、>¥5M 冲击未建模。见 [`../sat/sat-execution-audit-2026-09-14.md`](../sat/sat-execution-audit-2026-09-14.md)。
2. **多重检验注记**：配方自数十个 `compare_sat_*` 实验迭代选出；三窗只能证伪不能证真，激进档需更高证据标准。
3. **regime 集中已露馅**：年度 2026 仅 +5.8、valid +14.7 vs OOS2 +212.7——"第二年见底仍领先"是事后路径；未知的是下一段 regime。
4. **纪律**：`paper 3/20`；OPT-178（Live 卫星路径）+ OPT-184（Live 日历）修完；用户**书面风险授权**。
