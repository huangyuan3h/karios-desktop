## 3. 读数（价目，不裁决）

1. **拐点在 a≈0.25**：a∈[0, 0.25] 时 MDD 几乎不动（−6.8→−6.9），收益却从 +654 升到 +728——
   **a25 支配纯 B3**（收益 +74pt、回撤相同、Calmar 7.98 > 7.66、valid 还略好 +3.3 vs +3.0）。
2. **过 a=0.25 就陡**：a50 MDD −15.0、a75 −22.7、a100 −29.9。套筒的深回撤从 25% 权重起开始主导。
3. **要最低回撤**：`b3_repo_5050`（+556.2 / MDD **−5.9** / SR 3.62 / Calmar **8.09**）——但收益最低。
4. **valid 仍是所有停车的短板**：standalone +6.5 最高；任何停车都稀释（a25 −3.2、b3_repo −1.7）。
   这是"卫星弱窗+停车无收益"的 regime 依赖，非本档能解。
5. **前沿给用户的三个端点**：最低回撤 `b3_repo_5050`（−5.9）· 收益/回撤最优 `a25`（+728/−6.9）·
   最高收益 `纯套筒`（+913/−29.9）。

## 4. 边界（诚实项）

- 静态配比、日频恒定权重、无再平衡成本（价目惯例）；未建模冲击。
- holdout 描述：a 越小越好（纯 B3 −2.2 vs 纯套筒 −4.7）。
- **a25 是新候选点**（25% 套筒 + 75% B3），落地需另起预注册 + 用户拍板；**不进 Live**。

## 5. 结论 / 下一步

- **推荐候选点：a25（25% 套筒 + 75% B3）** long **+728% / CAGR 55.0% / MDD −6.9% / SR 3.49**——
  比纯 B3 多 74pt 收益、回撤不变；比纯套筒少 22pt 回撤、少 185pt 收益。
- 若用户要"收益优先、回撤可忍"：a50（+798/−15.0）或纯套筒（+913/−29.9）。
- **不进 Live**；星舰前置不变（paper 3/20 + 风险授权）。
