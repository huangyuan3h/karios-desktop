## 4. 读法 / 边界
- **机制**：S-3 常年 40–60% 闲置；闲置吃 ETF（金/油/纳指/国债择强）替代 0 收益 → 不改股票仓、天然保 alpha。
- **因果性**：原闲置套筒模拟（`portfolio_nav_sim`）用**当日收盘**判进出场（同类前视）；本稿改为 **t-1** 后仍三窗全正 → **历史结论经因果检验存活**。
- **边界**：ETF 历史仅 2023+（油 2023-11），故只测 2024+ 三窗；repo 记 0（保守，实际有 GC001）；成本仅 0.5bp 级未细算。
- **V1 出局的教训**：单资产（只有纳指）在 valid（美股弱/纳指回撤）拖累 → 多资产轮动更稳。

## 5. 结论 / 处置
- **ETF 层 = 闲置现金停车场（V2 多资产 / V4 +trail8）**，三窗正增量，因果可用。
- **不改股票仓**；S-3 仍是核心。
- **落产品前**：需产品层预注册（真再平衡日历/成本/实盘口径、REPO 收益计入、与 satellite 的关系）。
- **不扫**候选/lookback/MA/trail。
