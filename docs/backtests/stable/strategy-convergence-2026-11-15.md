# 策略收敛建议：8 个卡片 → 3 个引擎 → 3 个角色（2026-11-15 · 只读）

> 对象：策略总览里的 8 个条目（星舰 / 稳健星舰 H2-a25 / 星舰 B / 舰队 / 星港 / 母港 M30 / 港湾 / 双子星）。
> 目的：数清数量、打分、只留进攻/防御/综合三档，其余观察；并给出 50–60% 港湾 + 40–50% B3 的整合方案。
> 口径：各策略 windows 取 `strategy_catalog.py` 冻结值（2026-09-24/10-03）；评分沿用
> `five-strategy-v2-scorecard` 的 rubric v1（收益 40 / 风险 30 / 稳健 20 / 执行 10）。
> 新增 Core50/Core30 用 `compare_nav.npz`（2021-08-02~2026-09-30）日 NAV 重算，只读。

## 1. 数量：8 个条目，3 个引擎，6 个独立策略

| 条目 | 本质 | 独立性 |
|---|---|---|
| 港湾 | S-3 股票 + 闲置现金停 ETF（Live 底座） | 引擎 A |
| 母港 M30 | 70% 港湾 + 30% B3 | A+C 的组合 |
| 星港 0.2 | 50/50 港湾/B3 + 20% 卫星 | A+B+C 的组合 |
| 双子星 | 50% 港湾 + 50% 卫星 | A+B 的组合 |
| 星舰 v2 | 卫星 + 100% H2 停车 | B + H2 |
| 稳健星舰 H2-a25 | 卫星 + cashShare×(25% H2 + 75% B3) | B + H2 + C |
| 星舰 B | 卫星 + cashShare×100% 3 腿停车 | B + C′ |
| 舰队 | 50% 港湾 + 25% M30 + 25% B3 + 星舰复活闸 | 包装（不是独立引擎） |

**结论：8 个卡片、3 个独立引擎（港湾核心 / 卫星 / B3）、6 个独立策略。**
港湾是 Live 执行腿，舰队是包装；把它们当“独立策略”会重复计数。

## 3. 只留三个：目标档（推荐）

| 角色 | 策略 | 权重 | 理由 |
|---|---|---|---|
| **进攻** | 稳健星舰 H2-a25 | 10–15% | 当前可用的最高收益/可接受回撤组合：long +738.5、MDD −8.4、SR 3.50；canonical，仅 K3 失败。星舰 v2 的 MDD −30.5/valid −0.6 不适合；星舰 B 复活闸未开，作为备选。 |
| **综合** | **Core50**（新） | 45–50% | 50% 港湾 + 50% B3；CAGR 15.4、MDD −12.8、SR 1.05；比 M30 少 2.9pt CAGR，换来 −4.0pt MDD、+0.09 SR、holdout −5.8 vs −7.3。 |
| **防御** | **Core30**（新） | 35–40% | 30% 港湾 + 70% B3；CAGR 12.3、MDD −8.8、SR 1.21；真正的低波压舱石。 |

**观察/退出**：星舰 v2（研究）、星舰 B（进攻备选，复活闸）、双子星（valid −24.5）、舰队（包装/随机中位）、星港（与 Core50 重叠）、母港 M30（Core50 的参考前身）、港湾（Live 执行底座，不是第四档）。

**过渡档（不想今天上新权重）**：进攻 H2-a25 / 综合 星港 0.2 / 防御 M30；其余观察。
这三档都用现有卡片，今天就能收敛；Core50/Core30 作为下一步替换。

## 4. 整合方案：50–60% 港湾 + 40–50% B3

同一港湾/B3 配方在不同权重的风险阶梯（月频、5bp/边）：

| 方案 | 港湾/B3 | CAGR | MDD | SR | long | OOS2 | valid | holdout |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| Core30（防御） | 30/70 | 12.3 | −8.8 | **1.21** | +87.9 | +29.3 | +6.4 | −4.3 |
| Core40 | 40/60 | 13.9 | −10.8 | 1.12 | +103.2 | +34.0 | +8.0 | −5.1 |
| **Core50（综合）** | **50/50** | **15.4** | **−12.8** | **1.05** | **+119.1** | **+38.8** | **+9.5** | **−5.8** |
| Core55 | 55/45 | 16.1 | −13.8 | 1.02 | +127.2 | +41.2 | +10.2 | −6.1 |
| Core60 | 60/40 | 16.9 | −14.8 | 1.00 | +135.5 | +43.6 | +11.0 | −6.5 |
| 母港 M30（参考） | 70/30 | 18.3 | −16.8 | 0.96 | +152.6 | +48.5 | +12.4 | −7.3 |

- **Core50 = 50% 港湾 + 50% B3**，每月首个交易日复位，5bp/边；不需要 regime 规则。
- **Core30 = 30% 港湾 + 70% B3**，同上。
- 若想再挤一点收益：Core55（16.1/−13.8/1.02）；若想再稳：Core30。
- 55/45 加 10pt regime tilt（300<MA200→45/55，否则 60/40）可到 16.8/−14.3/**1.05**、
  holdout −5.4；但这是在同 5 年上拟合的，先当候选，不直接上。

**“更好”指更稳，不是更高收益**：Core50 在 long/valid/OOS2 都低于 M30（设计如此），
换来 MDD/SR/holdout 更好。若目标是最高收益，仍是 60/40 或 M30。

## 5. 边界与前置

- Core50/Core30 是**新候选**，未过硬标准（硬标准是 long/valid/holdout 收益全超 M30，
  它们按设计不会过）；要按“风险预算/稳健性”另开预注册，不能写成 PASS。
- 先 paper 20 笔 / 3 个月，再谈替换 M30/星港；Live 执行仍是港湾。
- 三档不是三个独立 alpha：Core50/Core30/M30 与港湾相关 0.998，只有 H2-a25（与港湾 0.16）
  是真分散。配置时不要把三档等权，也不要把 M30 和 Core50 同时满配。
- 卫星容量约 500 万以内；H2-a25 的 10–15% 进攻仓在 120 万规模无容量问题。

## 6. 一句话

**8 个卡片 → 3 个引擎 → 3 个角色。**
进攻 H2-a25（10–15%）、综合 Core50（45–50%）、防御 Core30（35–40%）；
星舰 v2/星舰 B/双子星/舰队/星港/M30 观察，港湾只做 Live 执行底座。
