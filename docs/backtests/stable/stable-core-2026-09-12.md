# H-STABLE：多资产稳健核心 · 结构实验（2026-09-12 · 找到可用结构）

> **一句话**：在 5 个低相关资产（沪深300/中证500/黄金/纳指/十年国债）上做**波动率倒数（风险预算）月度再平衡**（2021–2026，扣 5bp/边）→ **Sharpe 1.47 / CAGR +7.3% / MDD −7.3%**，碾压沪深300 买持（0.09/−42.2%）、60/40（0.27/−20.2%）、等权（0.91/−13.0%）。**这是一个可独立持有的稳健结构**（本页不结合双子星，用户要求先做独立结论）。
> **关键词**：稳健核心 多资产 波动率倒数 风险预算 趋势过滤 可用结构

## 3. 判定（门槛：long Sharpe≥1.0 & CAGR≥5% & MDD≥−20% & 优于 B0）

**→ 可用结构 = {B3, B4, B5}**（B4 与 B3 同值——组合实现波动仅 4.9%，8% 目标**从未触发**；B5 略降收益不加分）。

## 4. 读法 / 边界

- **机制**：低相关资产 + 波动率倒数加权 = **等风险贡献的近似**（金/债低波拿大权重、股高波拿小权重）→ 组合波动被压到 ~5%，回撤随之收敛。这是经典的 **ARP/风险平价**，本实验在**本宇宙+本区间**验证有效。
- **regime 依赖（#4）**：2021–2026 恰是"股弱、金/债/纳指强"——分散红利被放大；2022 股债短暂同向也未破 −7.3%。**换到"股强债弱"年，B3 会跑输等权/300**（B3 长期收益低于 B2 的 9.83%）。
- **样本仅 5.6 年**（panel 2021 起），含一轮熊+恢复；非长历史。
- **成本已计**（月度再平衡、5bp/边），但未计 ETF 溢价/跟踪误差。
- **B4 波动率目标冗余**：目标 8% 高于实现 4.9% → 恒等于 B3；要它生效需更低目标（但那会砍收益、且属参数选择，未做）。
- **B5 趋势过滤**在本区间**不加分**（走弱时资产本就权重小），仅多一层保险。

## 5. 结论 / 处置
- **独立可用结构成立：B3 = 5 资产波动率倒数月度再平衡**（Sharpe 1.47 / CAGR 7.3% / MDD −7.3%）。
- 定位：**低波稳健核心**（可单独持有，也可作未来组合腿）；**本页不动双子星**。
- **后续（用户倾向，暂缓）**：与双子星做组合层风险预算（另起预注册、三窗）；本页只交独立结论。
