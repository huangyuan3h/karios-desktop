## 4. 发现（为什么值得重开）

1. **B3 停车是"近乎免费的收益"**：对卫星 standalone 只增加 **1.7pt 回撤**（−5.1→−6.8），
   却加 **+186pt long 收益**、SR 3.45→3.67。对比套筒是 +444.9pt 收益但 −24.8pt 回撤。
   → **B3 捕获了套筒收益增量的 ~42%，只付了 ~7% 的回撤增量。**
2. **现行套筒的回撤是"集中"造成的，不是"停车"造成的**：换成分散组合，long MDD
   **−29.9% → −6.8%**（浅 4.4×）、Sharpe 2.11→3.67。sat-idle §4c 的"回撤归因 100% 停车腿"
   被本档坐实为**可修**。
3. **valid 也改善**：套筒 valid −6.8（把卫星 +6.5 打负）；B3 只 −3.5——**同一弱窗里 B3 明显更好**。
   K1 挂是因为 standalone 本身只有 +6.5%，任何停放都有微小稀释，不是 B3 的机制问题。
4. **前沿（long）**：standalone +468/−5.1/3.45 → **A4_true +654/−6.8/3.67**（Pareto 改进：
   收益更高、回撤几乎不变、Sharpe 更高）→ A5 +556/−5.9 → A6 +681/−15.9 → A2 +913/−29.9。
   **A4_true 是前沿的拐点**：拿走大部分收益、几乎不碰回撤。
5. **部分停车 A5（50% B3 + 50% REPO）**：+556/−5.9/3.62——比 A4 更保守、收益更低，可作中间档。

## 5. 边界（诚实项）

- **冻结 K1 是按"收益口径"标的**（承自 H-SAT-IDLE）；本档前提是"要回撤"，K1（任何窗不劣化）
  对 B3 偏严——**这是预注册设计问题，不是结果问题**。不得事后改判据；重开需新预注册。
- A2_true long +913.2 与冻结档 +884.9 有差（成本口径改万3/滑点 + 数据至 2026-09-18），**方向一致**。
- B3 前 60 日为等权（冻结约定）；月内不再平衡；未建模冲击。
- 卫星腿未调参；holdout 未跑（只描述口径）。
- **PASS/条件PASS 均不进 Live**：落地需用户拍板资本结构 + 新预注册（含 Live 口径）+ paper 前瞻。

## 6. 结论 / 下一步

- **冻结裁决 REJECT**（K1 valid −3.5）；但**实测 = 强风险候选**：**A4_true（卫星 + 闲置现金停 B3）**
  long **+654% / MDD −6.8% / SR 3.67**，是"要收益也要回撤"的现行最优解。
- 建议**另起预注册**，把判据改成**回撤口径**（例：K1 = 三窗 Δ ≥ −5pt 且 long Δmdd ≥ +20pt 且
  long SR ≥ standalone），再正式裁一次；或直接把 A4_true 作**产品候选**（星舰的"稳健版"）待拍板。
- 若要更多收益、少一点回撤：A6（50% 套筒停车）long +681/−15.9/2.88 是中间档（需同预注册）。
