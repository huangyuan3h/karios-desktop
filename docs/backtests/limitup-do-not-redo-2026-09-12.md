## 2. 机制：为什么打板结构性难

- **逆向选择**：封得住的板你排队买不到（一字/涨停开盘），能买到的往往是马上开板的——**信号最强的样本正好不可交易**。
- 这不是数据问题、也不是参数问题：换止损/换连板高度/换 10-20cm 都在同一根因上（[first-principles §二.1 成交语义 + §二.7 宇宙门](first-principles-2026-09-05.md)）。
- 与卫星 S-gap 的关系：S-gap 是"缺口 + 尾盘确认"，本来就把"买不进"的一字板过滤掉（`skip_t1_limit`）；打板正是去接 S-gap 主动回避的那部分。

## 3. 未测的唯一缝 + 开刀门槛

- **日内封板排队 / 开板回封**（真打板）：需要**封单量、逐笔/level-2、龙虎榜**——本地只有日线 + 稀疏 `bar_5min`，测不了。
- 开刀门槛（预注册）：拿到 level-2/封单数据 + 能对"排队成交概率"建模（否则还是假设买得到）；**在那之前不在现有数据上重开打板**。
- 便宜替代（已做）：T1 v0 用日线近似次日追板 → 已判方向关闭。

## 4. 操作纪律

- **不要**再用日线/`bar_5min` 重跑任何"买涨停/追板"假设（形态 1–3 已死，第 4 条已否决）。
- 若日后拿到 level-2，按 P0-12 纪律：独立预注册 + 独立基线 + 多窗，先在**排队成交语义**下出单笔净期望，再看回放。
- 与打板相关的**涨停建模**（阻买/顺延）本身保留在 S-3/卫星引擎里（[strategy-params](../modules/strategy-params.md) OPT-105），那是**风控**，不是打板策略。
