# 卫星成交日历：冻结 T 开盘 vs 当日收盘（Live 习惯代理，2026-09-03）

> **一句话**：用**今天的缺口 + 今天收盘价**对齐你「约 14:30 买、第 3 日收盘卖」的习惯，三窗相对冻结 T 开盘 **valid −17.7pt → REJECT 当实盘成交改写**。OOS2 好看不能当方案。Live / 冻结引擎都不变。14:30 价等 `bar_5min` 齐了再补一刀，不预期它能翻盘。
> **关键词**：机会双子星 S-gap `fill_mode` next_open same_close 14:30 成交日历

**脚本**：`services/data-sync-service/scripts/compare_sat_fill_same_close.py`  
**原始表**：`data/backtest_reports/sat_fill_same_close_2026-09-03.json`  
**口径**：window-local 空簿、卫星冻结 clip4（4×25% strict `skip_t1`）只改成交日历、核心冻结择强 trail8、`opp_50`。主判据 twin NAV vs 冻结 `next_open` twin。

**实盘**：**不改**。Watchlist 仍约 14:30 出名单；回测真值仍是 T-1 信号 + T 开盘。不要把收盘价或 14:30 写进冻结引擎当开盘。

引擎改动（默认不变）：`replay_sgap_from_context(fill_mode=...)`。`next_open` 默认；`same_close` 只给本脚本。Live / UI 不传。

## 0. 为什么测

冻结回测和你的习惯差了几乎一天：

| | 冻结回测 | 你的 Live |
|--|----------|-----------|
| 信号 | **昨天**是 S-gap（昨开 / 再昨收） | **今天**盘面当最后一根（今开 / 昨收） |
| 成交 | **次日开盘** | 约 **当天 14:30** |
| 持有 | 入场日 = 第 1 天，第 3 日收盘卖 | 同样从买入日起算 |

缺口日 = D0。冻结买 D1 开、卖 D3 收；习惯买 D0 下午、卖 D2 收。重叠只有 D1 和 D2，日历不是「同一个 3 日脉冲换了个价」。

ops 设计 E 线已经禁止把 14:30 写进回测当开盘。本实验是**另一条日历**，回答：习惯还能不能收到冻结卫星那条边。

收盘价是 14:30 的代理：买在 15:00，第 1 天标记≈0，少吃 D0 最后半小时。`bar_5min` 一年还没齐，先不混 14:30 成交。

| id | 信号 | 成交 | skip_t1 |
|----|------|------|---------|
| `next_open` | T-1 S-gap | T 开盘（冻结） | T-1 收盘涨停 |

已知偏差（相对真 14:30）：

- 排名用全天振幅，比 14:30 时多看了尾盘

- 第 1 天没有 14:30→收盘

## 3. 读法

- **日历比价更重要。** 冻结吃的是 D1 开→D3 收（缺口次日开盘买入、再拿两整天）。习惯吃的是 D0 收→D2 收（缺口当天下午买、少一天续脉冲、多一个缺口隔夜）。valid 卫星 +14.5 → +8.8，twin 少 17.7pt：开闸日叠在核心上的日子也换了，不只是成交价差一点。
- **OOS2 +26.8 是弱市年、单窗好看。** 和 trail 实验一样：OOS2 漂亮、valid 崩，不能改 Live。
- **past_year 卫星更好、twin 更差**（sat +63 vs +52，twin −8.7pt）。缺口日往往也是核心猛的日子，50/50 叠上去会切掉核心涨幅。
- **不要把收盘/14:30 写进冻结 T 开盘。** 对不齐的是日历，不是滑点。
- **14:30 补刀不预期翻盘。** 要从本代理翻到不超过冻结 5pt，valid 至少得收回 ~12pt。半小时成交价撑不起这个日历差。等 `bar_5min` 齐了再跑 `same_1430` 观察，默认仍不进 Live。
