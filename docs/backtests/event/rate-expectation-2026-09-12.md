# H-RATE-B：美国利率「预期差」→ 次日资产（2026-09-12 · 关系真、不可交易 REJECT）

> **一句话**：用**隔夜 ΔUS 2Y 收益率**当预期差代理，黄金次日确实**显著负相关**（all −0.18、valid −0.29、**FOMC 日 −0.51**），分档单调（宽松 +0.39% → 鹰派 −0.23%，差 0.62%）——**你的直觉是对的**。但成交语义门一开就破了：**整个效应在隔夜跳空里（gap corr −0.19），盘中 open→close 只有 −0.03**；A 股开盘前市场已把预期差 price in，**开盘买入抓不到**。**统计 K1/K2 过、成交语义 FAIL → REJECT（不可交易）。**
> **关键词**：利率 预期差 美债2年 黄金 隔夜跳空 成交语义 不可交易

**预注册**：[`designs/rate-expectation-prereg-2026-09-12.md`](../../designs/rate-expectation-prereg-2026-09-12.md)

## 2. 成交语义门（决定性）

| 资产 | corr(ΔUS2Y, **隔夜跳空** open/prev_close) | corr(ΔUS2Y, **盘中** open→close) |
|------|------------------------------------------|-----------------------------------|
| 黄金 | **−0.190** | **−0.034** |
| 纳指100 | −0.006 | −0.018 |
| 恒生科技 | −0.061 | +0.034 |

**效应全在隔夜跳空**：ΔUS2Y 是 A 股开盘前已知信息，黄金 ETF 开盘已跳空反映；等你开盘能买时，只剩无信号的盘中段（−0.03）。**close-to-close 的 −0.18 是幻觉成交**（`§二.1 成交语义`，与 hedge-twin 教训同款）。

## 3. 判定

| 线 | 结果 | |
|----|------|---|
| K1 久期资产 corr<0 & \|corr\|≥.05 & ≥2 窗 | 黄金 −0.18，3/3 | ✅ |
| K2 五档单调 top−bottom >0.3%/日 | 黄金 +0.62、纳指 +0.31 | ✅ |
| **成交语义（盘中可交易）** | 黄金 open→close corr **−0.03** | ❌ |

**→ REJECT（统计关系真、但不可交易）。** 不扫窗/阈值。

## 4. 读法（回答"预期差好不好测"）

- **预期差确实影响市场**（黄金↔实际利率是最经典的宏观关系，FOMC 日 −0.51 更印证）——**直觉对**。
- 但"**你能观测到的预期差，市场开盘就补给你了**"：可交易的部分被套利抹平。这正是"买预期卖事实"的另一面——**不是没有影响，是影响发生得太快、发生在你下不了单的那一刻**。
- 想抓只能**在美股 session 前就持有**（用不可得的未来信息择时）或**盘中微观**（隔夜跳空后的延续，数据不支持）。
- 归档进 first-principles 味：**"宏观预期差 → A 股"多是 gap 事件，日线级不可交易**（与指数/事件线同族死法）。
