# 假期效应（节前买点差 / 节后涨？）（2026-09-24 · REJECT 猜想）

> **一句话**：用户猜想「节前一段时间不是好的买点，买了就亏；节后会涨」。四大指数 2005–2026 事件研究**基本证伪**：**节前（尤其最后 1–5 日）整体是涨的**（十一节前最后一日 +1%+ 显著），**节后只有春节可靠上涨（红包行情）**，十一/五一节后是平到负，**十一近年节后明显下跌**——恰好与猜想相反。
> **关键词**：节假日 春节 五一 十一 节前效应 事件研究 REJECT 日历效应
> **性质**：描述性事件研究，**非可上 Live 的机制**（样本小、iid t 值偏高、单日噪声大）。任何交易化需另起预注册 + 验证门控 v2 三窗。

**脚本**：`services/data-sync-service/scripts/diag_holiday_effect.py`
**数据**：`index_daily`（000001.SH 2005+ / 000300.SH 2005+ / 000905.SH 2007+ / 399006.SZ 2010+）+ `trade_calendar`（SSE）。

---

## 1. 口径

- **假期** = 两个相邻开市日之间 ≥3 个连续休市自然日（即至少含 1 个工作日休市；普通周末只有 2 天）。按假期末休市日归类为 **春节 / 五一 / 十一**，其余（元旦/清明/端午/中秋）归"其他"（本档只报三大节）。
- `d0` = 节前最后开市日；`d1` = 节后首个开市日。
- 分段（各资产 close-to-close）：
  - `pre_N` = close(d0)/close(d0−N)−1（节前 N 日买、持到节前最后一日）
  - `lastday` = 节前最后一日单日收益
  - `gap` = close(d1)/close(d0)−1（持有过假期）
  - `post_N` = close(d1+N)/close(d1)−1（节后首日买、持 N 日）
- **超额 abn** = 事件窗口均值 − 同资产同周期无条件同久期均值；t 值按 iid（会偏高，只作参考）。

## 2. 结论表（full 周期）

| 假期 | 节前 | 节后 | 对猜想 |
|------|------|------|--------|
| **春节** | 正（pre_2~5 显著） | **明显正**（红包） | 两头都涨 → **反驳** |
| **十一** | **明显正**（节前抢筹） | 平/负，近年明显负 | **恰好相反** |
| **五一** | 近端小正、两周前小负 | 偏负（弱显著） | 节后不涨 → 部分反驳 |

## 3. 关键数字（abn，full）

**春节（前后皆正）**
- 沪深300：pre_2 +1.22%(t2.38)、pre_5 +2.03%(t2.66)；post_3 +1.06%
- 中证500：pre_2 +1.74%(t2.87)、pre_5 +2.50%(t2.88)；post_2 +1.95%(t3.74)、post_5 +3.58%(t3.80)、命中 85%
- 创业板：pre_5 +2.60%(t2.74)；post_2 +1.78%(t2.26)、post_3 +2.26%(t2.15)

**十一（节前涨、节后跌）**
- 节前：上证 pre_1 +1.10%(t2.30)、lastday +1.10%；沪深300 pre_1 +1.24%(t2.46)、pre_2 +2.06%(t2.47)；创业板 pre_2 +3.29%
- 节后 2020–2026 post_10：上证 −2.26%(t−1.72)、沪深300 −2.70%(t−1.69)、中证500 −4.32%(t−3.75)、创业板 −5.46%(t−2.30)，命中 0–20%

**五一（最弱）**
- pre_1 约 +0.4~0.8%，但 pre_10 全负（中证500 −1.68%, t−1.45）
- 节后 post_2/3 全负（沪深300 −0.83%/−0.91%, t≈−1.5）

## 4. 判定

- **"节前买了会亏" → 不成立**：节前（尤其最后 1–5 日）整体上涨，十一节前最后一日显著 +1%+。唯一例外=五一"两周前"弱负、不显著。
- **"节后会涨" → 只在春节成立**（很强）；十一、五一节后平到负，十一近年明显下跌。

## 5. 边界

- 每假期 full 仅 13–22 次，小样本；t 值按 iid 会高估显著性，未做 block bootstrap / 多重比较校正。
- 单日窗口（lastday/gap）噪声大；跨资产/跨周期方向一致是本档唯一可信之处。
- 只测指数，未测 S-3 小市值动量池；节假日择时若叠加在港湾/星舰上需单独验证增量。
