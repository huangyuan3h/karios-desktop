# H-FLOW-2：头部席位时间结构——隔夜型 vs 接力型（2026-09-15 · REJECT）

> **⚠️ 修正记录（2026-09-15 同日）**：一字判定的 qfq×raw 基期混用已修正（`hotmoney_lib` raw 重建）；本文指标（卖出可见率/d3）不依赖基期，数字基本不变（剔一字后可见率 17.7%/15.2%）。
>
> **一句话**：想分清头部席位里谁是"隔夜卖给跟风盘"、谁是"多日接力"，但**公共龙虎榜只披露前 5 席位**：头部事件里 T+1 还能看到同一席位出现在卖方/买方的比例只有 ~17.5%（机构 15.0%），**预注册的两个分型门槛（卖出再现 ≥50%、加仓 ≥30%）没有任何席位能达到** → 分型不可测，K2/K3 FAIL。**这是披露口径的天花板，不是策略结论**：我们能从公开数据看到他们的"进"，看不到他们的"出"。
> **关键词**：席位再现 卖出可见度 披露截断 龙虎榜前5 数据墙

## 1. 口径

- 事件 = 头部席位 S 在 T 日对股票 X 净买 > 0；跟踪 `(T+1, X, S)` 是否再现于披露席位：
  `sold = net(T+1) < 0`、`added = net(T+1) > 0`。
- 席位分型（跑前冻结）：`overnight`（卖出再现率 ≥50%）· `relay`（加仓 ≥30% 且卖出 <50%）· 其余 = `mixed`。
- 前瞻 `d3 = close(T+3)/open(T+1)−1`；对照机构专用席位；剔除 T+1 一字重算（K3）。
- 判定：K1 head 卖出再现率 > inst（≥2/3 窗）；K2 `relay` 的 d3 > `overnight`（≥2/3 窗）；K3 剔一字后 K1/K2 不翻号。

## 2. 结果

- 事件 73,284（head 52,758 / inst 20,526）。
- **分型：20/20 头部席位全为 `mixed`**（无任何席位达到 0.5/0.3 门槛）；overnight/relay 组为空。
- 卖出再现率（T+1 可见）：**head 17.5% vs inst 15.0%**；分窗 OOS2 19.0/17.5 · train 17.3/14.7 · valid 12.3/12.0 → **K1 pass（弱）**。剔一字后 17.7/15.2。
- `d3`（head）：OOS2 −0.32 / train +0.13 / valid −0.31 / long −0.38（inst：+0.20/+0.27/−0.40/−0.04）→ **K2/K3 FAIL**。

## 3. 判定与读数

- **总判：REJECT**（K2 结构性失败——不是数据里有信号没抓住，而是**披露口径连分型都无法建立**）。
- **披露截断**：龙虎榜席位是"前 5 买卖"口径，席位第二天只要不在前 5 就消失。17.5% 的可见率意味着 ~80% 的退出行为**在公共数据里不可观测**。头部 vs 机构的 17.5/15.0 差异（K1）不足以支撑任何规则，只能说明头部席位第二天更活跃。
- **对"他们怎么赚钱"的含义**：结合 H-FLOW-1（进入脚印在可交易口径下 ≈0），公开数据能看到的只是"他们买了"；**他们怎么卖、卖在哪个价位，公共数据看不到**——这正是 level-2 / 逐笔 / 完整席位流 的领域，和打板卡在同一面数据墙上（[limitup-do-not-redo](../limitup-do-not-redo-2026-09-12.md) §3）。
- **复活条件（写死）**：拿到完整席位流水（非前 5 截断）或逐笔成交，按预注册重测"隔夜 vs 接力"；在那之前不再在本数据上重开分型。
