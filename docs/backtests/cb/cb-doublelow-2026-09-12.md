# H-CB3：CB 双低（价格+低溢价）— 预注册验证（2026-09-12 · REJECT）

> **一句话**：用 akshare PIT 转股溢价率（零前视）正式验双低：**长窗 +59.2% vs 等权 +18.8%（Δ +18.3pt）、2022 熊市抗跌（Δ +12.2）**——机制像真的；但 **WF 仅 1/3（train −10.6/valid −5.3）、40bp 成本下 Δ 翻负 −12.7、next-open 只剩 +7.6 → 按预注册线 REJECT**。这是 CB 线里「最不死」的一条（成本敏感 + 近年失效），但仍不到采纳线。**CB 日线横截面至此全关（低价/低波/mom/rev/双低）。**
> **关键词**：可转债 CB 双低 低溢价 PIT 预注册 REJECT

**预注册**：[`designs/cb-doublelow-prereg-2026-09-12.md`](../../designs/cb-doublelow-prereg-2026-09-12.md)

**口径**：周频、按 `双低 = price + conv_prem_pct` 取最低 20%、等权、20bp、close-to-close；基准=同流动性门等权全宇宙。

## 4. 判定（预注册 K 线）

| 线 | 结果 | |
|----|------|---|

**→ H-CB3 REJECT。** 不补网格、不调双低系数。

## 5. 读法

- 机制诚实：2021/2022 表现最好（债底保护在熊市兑现），但 2025/2026 失效——**近年转债信用/供给结构变化 + 拥挤**。
- 是 **beta 型 regime 收益**（低价+低溢价 ≈ 高弹性债底多头的市场 beta），不是稳定独立 alpha；成本一加就露馅。
- 与低价/低波高度共线（CB 横截面只有约一个有效维度），印证 first-principles §五「结构吸收」。
