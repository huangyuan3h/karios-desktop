## 2. 每个候选的实验设计（参数 / 口径 / 判定）

### P1 海龟唐奇安突破
- **机制**：入场 gate 额外要求 `close > N日最高`（N ∈ {20, 55}）；出场附加 `close < N/2日最低`（10/20）
- **作为**：候选增强过滤器（在现有 score≥65 候选上再要求突破）——**不替换 RS**
- **口径**：扫描 N=20/55 × 突破回看 10/20；三窗 + long
- **预期**：突破与 RS 弱相关，可能捕获"RS 已高但还没创 N 日高"的延续段

### P2 放量突破 — ❌ 已拒收（2026-08-15 · 见 §5）
- **机制**：入场 gate 要求 `vol > MA20_vol × K`（K ∈ {1.5, 2.0}）且 `close > N日最高`（N=20）
- **作为**：量价共振过滤器
- **风险**：成交量维度在 A 股噪声大（一字板/对倒）；需剔除非交易日异常
- **口径**：K=1.5/2.0 × N=20；三窗

### P3 200 日均线过滤 — ❌ 已拒收（2026-08-15 · 见 §5）
- **机制**：个股 `close > MA200` 才允许买入（多头排列过滤）；变体：市场指数 > MA200 才开仓
- **作为**：准入 gate（替代/补充现有 regime gate）
- **口径**：个股级 / 指数级 两变体；三窗
- **预期**：与 regime gate 可能重叠（趋势状态），但 MA200 更长周期——可能更稳或更滞后

### P4 均线斜率过滤 — ❌ 已拒收（2026-08-15 · 见 §5）
- **机制**：MA20 斜率 > X%/20日（X ∈ {1%, 2%, 3%}）才买
- **作为**：加速度过滤器（趋势加速段才进，震荡段不进）
- **与 A2 区别**：A2 是"均线多头状态"，P4 是"均线变化率"——不同维度，值得测
- **口径**：X=1/2/3%；三窗

### P5 双均线金叉 — ❌ 已拒收（2026-08-15 · 见 §5）
- **机制**：MA5 上穿 MA20 当周/当日才买（事件驱动）
- **作为**：候选增强（金叉后 N 日内才允许买入）
- **预期**：大概率重复 A2（均线类无增量），快速证伪关闭

### P6 三线多头排列 — ❌ 已拒收（2026-08-15 · 见 §5）
- **机制**：MA5>MA10>MA20 才买
- **作为**：状态 gate
- **预期**：= A2 子集，预期拒收

### P7 短线超卖反转（仅 weak/neutral 环境）
- **机制**：环境=weak/neutral 时，RSI<30 且 1-2 日收阳 = 反向买入
- **作为**：反向实验（正常环境不启用，避免与 S-3 趋势哲学冲突）
- **口径**：仅 weak/neutral 子窗；三窗对比"启用 vs 不启用"

### P8 长阴次日反转（仅 weak/neutral 环境）
- **机制**：单日 -5% 后次日收阳 = 抄底
- **作为**：反向实验（同 P7 约束）

## 3. 过拟合防御（铁律之上的额外约束）

1. **三窗铁律**（todo §19）：三窗 0 劣化 + 单窗收益提升；单一窗好看 = 拒收
2. **ADDITIVE 不替换**：新信号只能作为**额外 gate / 候选增强**，不能替换 score/RS/env
3. **信息独立性**：新信号与现有 RS 的逐窗相关性 < 0.5，否则视为重复 RS（共线 = 过拟合）
4. **样本量门槛**：valid 窗 ≥ 30 笔触发才算有效信号；< 30 笔的结论降级为"方向参考"
5. **参数扫描上限**：每个信号最多扫 3-4 个参数组合，不网格搜索（网格 = 过拟合温床）
6. **单一机制**：一次只验证一个信号；组合叠加只在单个验证通过后才做
7. **失败即记**：拒收的信号记入 `experiments-d-pool.md` 或本表"已验证"区，标注根因

## 5. 已验证结果（成功/拒收回填区）

### P1 海龟唐奇安突破 — ❌ 拒收（2026-08-15）

- **实验**：`scripts/signal_p1_turtle.py`（引擎 `breakout_days` gate，close > N日最高）
- **三窗 + 长窗**（N=10/20/30/55 vs base）：

| 窗口 | base | N10 | N20 | N30 | N55 |
|------|------|-----|-----|-----|-----|
| OOS2 pnl | 117.2 | 146.6 | **148.2** | 129.6 | 113.2 |
| OOS2 DD | 11.7 | 6.0 | 5.7 | 6.1 | 6.6 |
| train pnl | 122.6 | **85.1** | **85.1** | 83.7 | 63.7 |
| valid pnl | 142.2 | 142.9 | 134.2 | 120.9 | 96.6 |
| 长窗 pnl | 333.9 | 269.4 | 268.7 | 212.1 | 183.6 |
| 长窗 DD | 45.1 | **89.6** | **90.8** | 116.5 | 112.4 |

- **判定**：**违反三窗铁律**——OOS2 单窗暴增（+31pt, DD 5.7, Calmar 25.9）但 train
  -37.5 / valid -8 / 长窗灾难（DD 45→90+，收益 -65pt）→ **典型单窗过拟合**，拒收
- **根因**：突破 gate 在 2024-25 结构牛（OOS2）捕获延续，但在震荡/转折段（train/long）
  追高即套——与 A2「绝对量因子无增量」同向结论
- **处置**：引擎 `breakout_days` 保留默认 0（关）；信号记入失败列表，不再重试
- 原始数据：`data/backtest_reports/signal_p1_turtle.json`
