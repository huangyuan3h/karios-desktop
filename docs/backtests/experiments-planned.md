> **11 项拒收的完整教训（避免重走）**：
>
> 1. **绝对量技术形态 6 项（P1-P6）全部无增量**——价格突破/放量/均线状态/加速度/金叉事件/三线排列，
>    与 A2（2026-08-09）结论一致：**A 股绝对量因子无增量，RS 相对强弱是唯一稳健因子**。
> 2. **反转类 2 项（P7/P8）与 S-3 候选集互斥**——RS 前 50% 强势票不存在超卖/长阴形态。
> 3. **波动率调整动量（P12）= 砍 beta 而非降噪**——与动量哲学冲突，train/长窗灾难。
> 4. **ST 剔除（P16）= 准入链已隐性过滤**——拦截 3145 次仅少 1 笔成交，且 ST 摘帽是真 alpha。
> 5. **行业中性（P11）= 主线闸门已占行业维度**——行业动量与资金流 Top3 重合（拦截零差异）；
>    行业内选强砍掉行业 beta 盈利（valid -30pt / 14 笔 +492pt）——**S-3 alpha = 主线行业 beta + 全市场 RS**。
> 6. **中期动量（P9）= 与"短期转强"买入逻辑冲突**——相关性虽低（0.04-0.10），但 M250 把
>    valid 候选池清空（0 笔）——S-3 买「RS 突然转强」的票，中期动量 top30% 是「已持续涨半年」的票，
>    两者交集在 valid 不存在；**低相关性 ≠ 互补**（还可能互斥）。
> 7. **共同模式**：单窗（OOS2）暴增 + 其他窗灾难 = 过拟合（P1/P2/P10）；无拦截 = 无信息（P3/P9-M120）；
>    共线 = 重复 RS（P4）；互斥 = 无样本（P7/P8/P9-M250）；与现有闸门重复 = 零增量（P11-M）。

## 2. 每个候选的实验设计（参数 / 口径 / 判定）

### P1 海龟唐奇安突破 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：入场 gate 额外要求 `close > N日最高`（N ∈ {20, 55}）；出场附加 `close < N/2日最低`（10/20）
- **作为**：候选增强过滤器（在现有 score≥65 候选上再要求突破）——**不替换 RS**
- **口径**：扫描 N=20/55 × 突破回看 10/20；三窗 + long
- **预期**：突破与 RS 弱相关，可能捕获"RS 已高但还没创 N 日高"的延续段

### P2 放量突破 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：入场 gate 要求 `vol > MA20_vol × K`（K ∈ {1.5, 2.0}）且 `close > N日最高`（N=20）
- **作为**：量价共振过滤器
- **风险**：成交量维度在 A 股噪声大（一字板/对倒）；需剔除非交易日异常
- **口径**：K=1.5/2.0 × N=20；三窗

### P3 200 日均线过滤 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：个股 `close > MA200` 才允许买入（多头排列过滤）；变体：市场指数 > MA200 才开仓
- **作为**：准入 gate（替代/补充现有 regime gate）
- **口径**：个股级 / 指数级 两变体；三窗
- **预期**：与 regime gate 可能重叠（趋势状态），但 MA200 更长周期——可能更稳或更滞后

### P4 均线斜率过滤 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：MA20 斜率 > X%/20日（X ∈ {1%, 2%, 3%}）才买
- **作为**：加速度过滤器（趋势加速段才进，震荡段不进）
- **与 A2 区别**：A2 是"均线多头状态"，P4 是"均线变化率"——不同维度，值得测
- **口径**：X=1/2/3%；三窗

### P5 双均线金叉 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：MA5 上穿 MA20 当周/当日才买（事件驱动）
- **作为**：候选增强（金叉后 N 日内才允许买入）
- **预期**：大概率重复 A2（均线类无增量），快速证伪关闭

### P6 三线多头排列 — ❌ 已拒收（2026-08-15 · 见 §5）

- **机制**：MA5>MA10>MA20 才买
- **作为**：状态 gate
- **预期**：= A2 子集，预期拒收

### P7 短线超卖反转 — ❌ 已拒收（2026-08-15 · 见 §5）

## 3. 过拟合防御（铁律之上的额外约束）

1. **三窗铁律**（todo §19）：三窗 0 劣化 + 单窗收益提升；单一窗好看 = 拒收
2. **ADDITIVE 不替换**：新信号只能作为**额外 gate / 候选增强**，不能替换 score/RS/env
3. **信息独立性**：新信号与现有 RS 的逐窗相关性 < 0.5，否则视为重复 RS（共线 = 过拟合）
4. **样本量门槛**：valid 窗 ≥ 30 笔触发才算有效信号；< 30 笔的结论降级为"方向参考"
5. **参数扫描上限**：每个信号最多扫 3-4 个参数组合，不网格搜索（网格 = 过拟合温床）
6. **单一机制**：一次只验证一个信号；组合叠加只在单个验证通过后才做
7. **失败即记**：拒收的信号记入 `experiments-d-pool.md` 或本表"已验证"区，标注根因

## 3b. 验证方法（三步走 · 2026-08-15 研究建议）

**不要一上来把所有 filter 全部叠加。** 分三步：

- **Step 1 单因子有效性**：五分组是否单调 · 多头组是否跑赢 · IC/ICIR 是否稳定 · 三窗是否一致 ·
  各 regime（strong/neutral/weak）下是否稳定；hard filter 要额外看：过滤后股票池是否过小 ·
  换手是否大幅上升 · 收益是否来自极端小样本
- **Step 2 对 base 的增量贡献**：`base = score≥65 + regime gate + 现有进出场`，比较
  base / base+新filter / base+新rank weight / base+新出场风控。**重点不是只看收益**，而是：
  年化 · 最大回撤 · Calmar · 夏普 · 胜率 · 盈亏比 · 换手率 · 交易成本后收益 · 与 base 的相关性。
  只提收益但回撤更差 → 未必值得
- **Step 3 复合 score 而非全 hard gate**：hard gate 太多 → 候选池过窄 + 过拟合。更推荐：

```text
score_v2 =
0.60 * original_score
+ 0.15 * momentum_rank
+ 0.10 * high_52w_rank
+ 0.10 * quality_rank
+ 0.05 * low_vol_rank
- event_penalty
```

或「original_score 选候选 → 新因子二次排序 → 负面因子剔除」。各分量权重需在单个因子验证
通过后由三窗再定，**不要一次全加**。

## 3c. A股回测特别注意事项（不处理则回测虚高）

1. **涨跌停成交**：涨停不可买 / 跌停不可卖 / 一字板无法成交——突破、打板、事件驱动策略必须处理
2. **停牌 / 复牌**：停牌期间不能交易，复牌可能大幅跳空
3. **ST / 退市 / 生存者偏差**：股票池用**历史时点池**，而非当前成分
4. **财报未来函数**：基本面数据必须用**公告日**（业绩预告/快报/正式财报），不用报告期
5. **交易成本**：佣金 + 印花税 + 滑点 + 冲击成本；保守测单边 0.15% / 0.25% / 0.35%；
   高换手策略重点压力测试
6. **容量限制**：小市值 / 微盘 / 涨停板 / 事件驱动 / 龙虎榜需加——日均成交额过滤 · 可买入市值下限 ·
   持仓占个股成交比例限制
