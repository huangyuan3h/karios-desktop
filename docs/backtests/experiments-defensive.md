## 方法论遗产（为什么这轮有价值）

1. **防守合格线**：收益下降 ≤10% 且最大回撤下降 ≥15%，或卡玛提升 ≥10%
2. **组合叠加只在单项验证后做**（先单后叠，防交互掩盖）
3. **alpha/事件信号永不进回测参数**（数据起点 2026-06）——只走 C4 对照
4. 每项 `run_walk_forward.py --param k=v` 三窗 + long 同屏
5. **最大教训**：直觉上"更严/更早/更小"都更安全，但数学上它们都截断右尾或压期望
   ——S-3 的利润来自让赢家奔跑 + 准入质量，不在防守参数
