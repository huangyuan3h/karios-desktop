## 1. 为什么结束（数据全景）

自 2026-08-09 起的全部回测实验（success + failure 全记录）：

| 轮次 | 数量 | 结果 |
|------|------|------|
| 防守向攻击 A/B/C/D | 23 项 | 20 拒收 / 3 中性 / 0 采纳 |
| 信号池 P1-P26 | 15 项 | **15 全部拒收** |
| 早期实验（A2/A4/止盈/分数/持有期等） | ~10 项 | 全部拒收 |
| **成功的仅 3 类** | — | 环境感知（neutral_block / entry_style auto / D2 / D3 / E2）· 仓位杠杆旋钮 · 数据修复（情绪回填） |

**48+ 次失败的共同模式**：
1. 绝对量技术形态（突破/放量/均线/斜率/金叉/三线）→ 无增量（与 A2 同向）
2. 防守收紧（更严/更早/更小）→ 截断右尾或砍 beta
3. 与 RS 共线 → 重复过滤（P4）
4. 与候选集互斥 → 无样本（P7/P8/P9-M250）
5. 与现有闸门重合 → 零增量（P3/P11-M）
6. 事件信息已被价格吸收 → 双重追高（P9/P14）
7. 单窗好看 + 其他窗灾难 = 过拟合（P1/P2/P10）

## 2. 最终定案：A 股 S-3 的 alpha 来源（已占满）

> **S-3 的 alpha = ① RS 短期转强（相对强弱） + ② 主线行业 beta（动态 Top3 白名单） + ③ 环境感知（neutral_block / entry_style auto / D2 持有期 / D3 仓位） + ④ 纪律空仓（弱市/冷却/熔断）**

| 机制 | 参数 | 验证 |
|------|------|------|
| score ≥ 65 + RS 前 50% | 准入 | 双窗 + 三窗 |
| 主线闸门（5日资金流 Top3 行业） | gates=full | 三窗 |
| 环境感知 5 件套 | neutral_block / auto / D2 / E2 / D3 | 三窗 + 长窗 + 蒙特卡洛 |
| 纪律空仓 | panic 冷却 2d / 熔断 -25 / 弱日禁开 | 长窗 + 蒙特卡洛 |

**基线（2026-08-28 NAV · 现行）**：CN OOS2 **+47.3%** / train **+34.1%** / valid **+38.7%** n⚠️。
旧 D3 算术（OOS2 **+117.2%** …）与 HK 旧 270% **已封存**——见 `audit-verdict-2026-08-29.md`。

## 3. HK 线定案：beta 偏多，无强规律，空间到顶

- HK 与 A 股**完全独立**回测（vol-top500 universe + HSI/HSTECH regime 闸门）
- HK 环境信号不足（仅 2 个指数红绿灯，无涨跌家数/溢价/主线轮动）→ **环境感知不适用**（TIP-014 HK 实验）
- HK 动量股极少 5 日回调 → dip 风格形同虚设；regime 与收益无稳定关系
- HK 参数最终 = A 股框架 + trail-12 + RS 前 40%（三窗全正：OOS2 +86.9 / train +45.9 / valid +52.3）
- **结论**：HK 的收益主要来自 beta（港股整体动量），个股层面规律弱于 A 股；回测已到顶，
  不做进一步信号探索（除非获得港股情绪/宽度类新数据源，见 D8）

## 5. 纪律声明（回测时代的遗产）

1. **回测数字不作发布依据；paper 实绩为准**（todo §19）
