# S-3 股票腿 14:30 成交时钟实验（H-CLOCK-1430 · 2026-09-18）· **REJECT**

> **一句话**：把 S-3 股票腿的成交从「信号日 T 收盘 → **T+1 开盘**」换成「→ **T+1 的 14:30 print**」
> （信号/闸/仓位/出场一字不改，只换成交时点与成交价）→ 三窗全线劣化
> **Δ −38.7 / −11.1 / −12.2pt**（K1 要求每窗 ≥ −1.0）→ **REJECT**，引擎维持 `next_open`。
> **关键词**：14:30 时钟 · next_1430 · 开盘 vs 尾盘成交 · 涨停不买 · 路径放大
> 预注册：[`docs/designs/s3-clock-1430-prereg-2026-09-18.md`](../../designs/s3-clock-1430-prereg-2026-09-18.md)（冻结于实验前）

## 2. 口径（预注册 §1 冻结）

- 信号层（score/regime/flow/mainline/style/仓位）**一字不改**；成交价 = 成交日 14:30 的
  `bar_5min` **raw print** × `adj/adj_latest` 换到 `daily` 的 qfq 基期（与单测核对：
  300750 2026-08-07 raw15:00 × ratio = 386.6618 == `daily` qfq close，精确）。
- 无 14:30 print → **当日不成交**（不猜价、不回退开盘）；14:30 触涨停（买）→ 不成交，
  锚点 = 信号日收盘（同 `next_open`）；A股 T+1 锁（成交日 `holding<=1` 禁卖）不变。
- 出场腿（`exit_at_1430`）本轮**未启用**：先单独测「入场时钟」的代价（分步归因）。

## 4. 机制（逐笔实测，非猜测）

1. **14:30 print 系统性高于开盘**（同一票、同一信号）：valid 共有笔 +0.69 / +1.58 / +1.92 /
   +3.64 / **+8.25**%，仅两笔微负 → 与
   [`core-entry-execution-2026-09-10`](../core/core-entry-execution-2026-09-10.md) 的
   open→close 漂移 **+1.17/+0.60/+1.88%** 同源：**尾盘买 = 买在日内已涨之后**。
2. **「涨停不买」搬到 14:30 后杀伤放大**：valid 挡单 `limit_up` **26 vs 2**——动量策略最想要的
   当日冲板票，在 14:30 已经买不到（反向也有一例：开盘一字/14:30 开板可买，如 301183）。
3. **路径放大**：成交名单 → 持仓占用 → NAV 熔断/throttle 窗口全部沿 NAV 路径联动；逐笔均价差
   ~1–2% 不足以解释组合层 −12~−39pt，放大来自名单替换（valid 有 9 笔只在 `next_open`、
   14 笔只在 `next_1430`）与 OOS2 的熔断/节流分支差异。

## 5. 结论与对产品的含义

- **引擎维持 `next_open`**；`next_1430` 代码保留为实验变体（门控 `entry_mode`，默认不启用）。
- **「统一 14:30」对 S-3 腿不是免费的**：如果 Live 真的在 T+1 14:30 下单，相对冻结基线预期
  **系统性落后**（本窗量级 −12 ~ −39pt），必须当作**跟踪误差**显式记录；要贴近基线就应在
  T+1 开盘执行。操作纪律与引擎口径二者只能选一，或分开记账。
- 卫星腿/停车腿**不受影响**（它们本就是 14:30 口径）。
