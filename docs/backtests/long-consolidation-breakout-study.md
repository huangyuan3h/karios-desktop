# 长调整 + 突破 大涨验证（2026-08-24）

> 问题：`长箱体窄幅盘整→向上突破` 后是否 `20/60d` 大涨？方法同 `§22.7`：`ahead 20/60d` 分层，`CN liquid1500` 聚合 `2022-01~2026-08`，`n≥500` 采信。

## 口径

- **箱体**：`n=60 / 120` 日 `box_high = max(high,n)` / `box_low = min(low,n)`（`shift(1)`），`is_narrow = (box_high-box_low)/close < 20%分位`（挤压箱体，长调整）。
- **突破**：`close > box_high`（上破）；对比 `break_any`（任意箱体上破）vs `break_narrow`（窄箱上破=长调整）。
- **forward**：`10/20/60d` 持有，`cost` 未扣（`0.05%` 不改结论）；统计 `mean/median/win/>10%/>20%`。
- **base**：`CN 1500` 全票-日 `10d +0.76% win47%`（`20d ~1.5% / 60d ~3%` 隐含）

> **解读**：
> - `60d narrow` 的 `20d +4.10%` 与 `60d +6.94%` 为 `CN` 上 **形态层最强**（`excess +2.3~3.5%`、`win +6pt`、`>10% +5pt`、`n11k` 大样本），`median 0.43~0.73%` 仍远小于 `mean`（厚尾，小部分大涨拉动）。
> - `120d narrow` 同向 `60d +6.84% +3.86% excess`，证实 **“越长越窄”越强**，但 `10d +0.68%` 弱 — **大涨需 `20-60d` 持有，非 `10d` 短线**。
> - `break_any` 本身已 `+1~3%` vs `base`，窄箱额外 `+1~3%`，说明 **“长调整”是 `break` 的加成因子**，非独立。

## 与既有形态的对比

- `trackA` 的 `cup_handle n8k win12% / flag n36` 无 edge，因定义为 `形状` 而非 `窄幅+突破`；本次 `窄箱+突破` 是 **达瓦斯箱体** 的量化版，`n11k win52%` 为 `trackA` 后 **首个形态层 `>2%` excess**。
- `bollinger expand +1.88% win51.9%`、`MACD金叉+1.23%`、`KDJ J>80+1.25%` 均 `<1.5%`，**长窄突破 `+3.5%` 为形态层新高**，但 `win51-52%` 仍 **未达 `win>70%` 杠杆线**，`median 0.44%` 说明 `50%` 票仍 `±0%` 徘徊。
- `R4 油RSI>80 +3.85% win82%` 仍是跨资产最强，但 `CN` 上长窄突破是 **股票形态最强**。

## 结论（记录）

1. **长调整+突破有 `+3.5%` 弱 edge，`60d` 最优**：`60d narrow break 60d +6.94% (+3.53% vs any) win51.9% n11k`，`20d +4.10% +2.31%`，**是 `CN` 形态层首个 `>2%` excess 且 `n>10k` 大样本**，但 `win52% median0.4% >10% 34%`，**厚尾驱动，非 `70%` 高置信**，不能 `2-3×` 杠杆。
2. **持有期关键**：`10d +1.18%` 弱，`60d +3.53%` 强 — **长调整需长持有**（`60d`），`10d` 短线无大涨。
3. **不进 `S-3/sleeve`**：`excess +3.5% win52%` 不达 `>5pt` 票决（`S-3` 三窗 `>10%`）与 `win>70%`，仅作 **观察层**（`60d窄箱上破→20-60d持有` 提示），`box_high` 可作止损参考（`box_low`），与 `bollinger/macd/kdj` 同归 `backtests/` 周更。
