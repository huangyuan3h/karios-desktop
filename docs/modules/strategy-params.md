## 1b. HK 并行线参数（2026-08-10 定案 · 与 A 股完全独立）

> **定位**：港股独立策略线，与 A 股 S-3 并行互不干扰（用户拍板）。HK 数据/回测/paper
> 全链路独立；A 股结论不动。三窗 = 同一套 OOS2/train/valid 切分。
> 基线固化：`data/backtest_reports/walk_forward_hk_baseline.json`（`run_walk_forward.py --market HK`）。

| 参数 | HK 值 | A 股值 | HK 为什么不同（数据驱动） |
|------|-------|--------|---------------------------|
| gates | **regime** | full | **HK 无行业资金流数据**（SW L1/东财板块不可用）——行业闸门直接去掉，只留 regime+score+RS |
| score_threshold | 65 | 65 | HK score 无行业/资金流分量 → 顺周期偏高（入场票全在 75-100，65/70/75 门槛扫描**结果完全相同**，无区分度；保留 65 作语义锚点） |
| trailing_stop_pct | **-12%** | -8% | **港股波动显著大于 A 股**：-8% 在 train 窗被高频扫掉（144/186 笔止损类退出，-2.1% 亏损）；-12% 变 +15%（train 5% 口径）——让利润奔跑 |
| stop_loss_pct | -5% | -5% | 兜底止损不变（-7/-8 无改善，-5 与 -12 组合最优） |
| rs_rank_min | **0.6**（前40%） | 0.5 | HK 无行业闸门 → **RS 是唯一质量过滤器**；0.5 太松（高分垃圾单多），0.6 是 train 窗峰值（+23% vs 0.5 的 +15%，5% 口径） |
| max_hold_days | 60 | 60 | 40/90 均劣于 60（train 扫描） |
| 金字塔 | 开（2.5/0.5/1） | 开 | train +23.0 vs 关 +15.9（5% 口径）——同 A 股结论 |
| position_pct | 回测 10% / paper 5% | 同 | 纯杠杆线性 |
| exclude_boards | 无 | 300 | HK 无创业板概念 |
| 其他 | target100 / floor0 / mp20 / 滑点0.05 / swap 关 / panic3 | 同 | 无差异 |

**三窗（2026-08-10 固化基线 · 10%×20 口径 · 含金字塔）**：
OOS2 **+86.9%**/DD25.4/夏普2.63/328笔 · train **+45.9%**/DD19.9/2.89/166笔 ·
valid **+52.3%**/DD8.3/**5.62**/84笔

**过去一年（2025-08-01~2026-08-07 连续）**：10% 口径 **+83.8%** / DD19.9% / 夏普 2.68 / 307 笔；
paper 5% 口径 ≈ **+41.9%** / 回撤 ~10%

**HK 数据质量清单（2026-08-10 回填实况 · 用户关注稳定性）**：
1. **universe 是"成交量 top 500"代理**，不是官方恒生综合成分——东财（33.push2）被封、
   新浪成分接口返回空、csindex 无港股——**成分差异 ~5-10%（流动性 proxy 与成分高度重合但非等同）**
2. **amount（成交额）字段缺失**（HK 日线同步未带成交额）——universe 排序只能用 vol（成交量）
3. **回填修过一个 look-ahead bug**：`fetch_last_closes` 无 as-of 过滤 → HK 指数信号每个历史日
   都读到"今天"的价格（regime 全 Strong）——已修，回填重跑 2 次（第一次数据作废）
4. **HSTECH 数据到 2026-07-31**，HSI 到 08-07（略旧 5 个交易日）
5. **HK 日线最新 = 08-07**（8-10 今日盘后同步待跑）；2803 只 HK 中 2677 只有 vol 数据
6. **score 无行业分量** → 结构差异（见上表 score 行）
7. HK 实时报价三链（Sina 主 → 东财 push2 备 → tushare 兜底）——东财链被封时自动降级
8. **结论**：历史回测已固化；**实盘/paper 需验证数据新鲜度**（每日 HK 日线同步 job 是
   hk_basic_sync——8-09 曾失败，key 已补，需观察）

## 3. 参数变更流程（防漂移 · 环境变化时照此执行）

> 环境会变（量化拥挤、风格切换、监管变化），参数不是永恒的。**灵活性 = 有流程、有记录、
> 有验证的变更通道**，不是运行时随便调。

1. **观察信号**（触发复核）：季度例行复核；或出现——回撤超预期（paper 实跑 DD 显著偏离
   回测 5%/10% 口径）、超额转负、胜率跌破 35%、候选池结构变化（scores 分布漂移）
2. **提参 → 双窗验证**：候选参数必须训练窗 + 验证窗 + OOS2 三窗跑完，
   双窗一致改善才采纳（todo §19 反模式：单窗好看=过拟合）。
   **工具**：`scripts/run_walk_forward.py`（三窗固定切分 OOS2/train/valid，S-3 基线
   固化在 `data/backtest_reports/walk_forward_baseline.json`，`--param k=v` 覆盖跑
   对比，>5pt 劣化自动拒收；`--save-baseline` 重固化基线）
3. **用户拍板**：数据表交用户，用户签字式拍板（对话确认）
4. **固化**：改代码常量（`db/paper_trading.py` / `service/paper_s3.py`）+ 本文件版本历史 + 测试
5. **生效观察**：paper 实跑对照（C4：≥20 笔样本）确认，回归预期则回滚

**复核节奏**：季度（每 3 个月）双窗复核一轮，结果记版本历史"复核"列。
**基线（2026-08-09 固化 · 10%×20 口径 · 含金字塔 2.5/0.5/1 + exclude_boards=300）**：
OOS2 +124.3%/DD18.7/夏普4.21/319笔 · train +151.1%/DD9.7/5.92/211笔 ·
valid +77.2%/DD5.0/8.26/64笔（2026-08-09 晚随 A4 排除创业板重固化；
旧基线 106.9/147.5/73.9 作废——含 trailing 差异与板块排除增量）
